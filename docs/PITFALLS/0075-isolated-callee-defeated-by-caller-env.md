# 격리한 것은 피호출자뿐 — 호출자가 env 로 계약을 무효화한다

**발견**: 2026-08-27 릴리스 (`bash infra/deploy/release.sh`)
**증상**: `[1/7] 테스트 게이트` 에서 C-1 안전장치가 릴리스를 거부.

```
[1/5] 백엔드(API·스키마·시드) — pytest (DB_NAME=LOUPIT, 서빙 무접촉; SC14 RED 제외)
Exit: [C-1 안전장치] 거부: 'LOUPIT'는 서빙(운영/베타) 스키마입니다.
```

메시지 자체가 모순이다 — **"DB_NAME=LOUPIT" 이라고 찍으면서 "서빙 무접촉"이라고 말한다.**
그 문장이 진단의 전부였다: 새 판본의 문구가 옛 판본의 값과 함께 출력되고 있었다.

## 무엇이 잘못됐나

2026-08-26 격리 전환에서 `run_tests.sh` 를 고쳤다:

```bash
export DB_NAME="${DB_NAME:-loupit_test}"   # 격리 기본값
```

`:-` 는 **이미 설정된 값을 존중**한다. CI 가 `loupit_ci` 를 넘길 수 있게 하려고 일부러 그렇게 뒀다.
그런데 `release.sh` 는 그 위에서:

```bash
set -a
source "${ROOT_DIR}/server/.env"   # DB_NAME=LOUPIT 을 export 한다
set +a
...
bash "${SCRIPT_DIR}/run_tests.sh"  # ← LOUPIT 이 그대로 상속된다
```

즉 **격리 기본값은 한 번도 적용되지 않았다.** 게이트를 격리했다고 믿은 채 서빙을 향하고 있었다.

## 왜 테스트가 못 잡았나

`test_runner_backup.py` 는 `run_tests.sh` **텍스트만** 검사했다. 그 파일 안에서는
`export DB_NAME="${DB_NAME:-loupit_test}"` 가 분명히 존재하므로 가드는 초록이었다.
계약의 위반은 그 파일 안이 아니라 **호출 지점**에 있었다.

> 스크립트 하나를 격리해도, 그 스크립트를 부르는 쪽이 환경변수로 격리를 되돌릴 수 있다.
> 격리 계약의 검증 범위는 **피호출자 + 모든 호출자**다.

`release.sh` 의 머리말 주석은 이미 "게이트는 loupit_test 만 쓴다"로 갱신돼 있었다 —
**문서만 갱신되고 배선은 안 됐다.** 주석이 초록불 역할을 했다.

## 실제 피해

없다. C-1 안전장치가 `[1/7]` 에서 막았고 `[2]~[7]` 은 실행되지 않았다.
서빙 DB·정적 dist 모두 무접촉. **가드가 설계대로 동작한 사례**다.

## 고친 것

```bash
env -u DB_NAME bash "${SCRIPT_DIR}/run_tests.sh"
```

`DB_NAME` 만 지워 넘긴다 — `DB_HOST/PORT/USER/PASSWORD` 는 접속에 필요하므로 유지.
그러면 피호출자의 문서화된 기본값(`loupit_test`)이 선다(기본값의 단일 정본 유지).

가드 신설: `test_release_does_not_leak_serving_db_name_into_gate` — 게이트 호출 줄이
`DB_NAME` 을 지우거나 비서빙 이름으로 덮어쓰지 않으면 실패한다. 뮤테이션 2건으로
양방향 검증했다(제거 → red, `DB_NAME=LOUPIT` 명시 → red).

## 딸린 발견 — 시드 변경이 더는 릴리스로 반영되지 않는다

구 판본은 게이트가 서빙을 DROP→재시드했고, 그 **부작용**으로 시드 파일 변경이 서빙에
딸려 들어갔다. `[3/7]` 의 "게이트 복원이 최신 시드를 적재했음을 확인" 이라는 문구가 그
전제를 담고 있었다. 무접촉 게이트에는 그 경로가 없다.

→ 회사·복지·도메인 시드를 바꿨다면 릴리스와 **별개로** 명시적으로 적재해야 한다:

```bash
LOUPIT_ALLOW_FRESH=1 python3 db/seed/load.py --fresh
```

부작용에 기대던 일이 명시적 단계가 됐다. 이쪽이 옳지만, 모르면 "릴리스했는데 데이터가
안 바뀐다"로 나타난다.

## 교훈

1. 계약을 파일 하나에 새겼으면, **그 파일을 부르는 모든 곳**도 같은 가드에 넣어라.
2. `${VAR:-기본값}` 은 격리 장치가 아니다. 호출자가 이미 설정했으면 기본값은 죽는다.
3. 주석을 먼저 고치면 그 주석이 초록불이 된다. 배선과 함께 고쳐라.
4. 부작용을 없애면, 그 부작용에 얹혀 가던 일도 같이 사라진다. 무엇이 얹혀 있었는지 세어라.
