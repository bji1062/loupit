# 강조하려고 올린 그룹이 자기 칸들을 덮는다

히트맵의 그룹 사각형(`.hm-grp`)은 타일(`.hm-t`)보다 **먼저** 나오는 절대배치 형제다. 마우스가 닿은
그룹을 눈에 띄게 하려고 `z-index:1` 을 줬더니, 그 그룹의 타일 **전부**가 배경 뒤로 사라졌다
(2026-08-27 실측: 전기·전자 17칸이 통째로 가려짐 — 남은 것은 z-index 를 가진 hover 칸 하나뿐).

**테스트는 초록이었다.** jsdom 은 레이아웃·페인트를 하지 않아 class 토글만 검증했고, 생성기 테스트는
HTML 만 본다. 브라우저 스크린샷을 찍어 보고서야 드러났다.

- 규칙: **배치가 겹치는 형제 구조에서 강조는 z 축이 아니라 테두리로** 한다(그룹은 테두리·머리줄만
  보이면 충분하다 — prober 도 stroke 만 준다).
- 가드: `web/assets/js/heatmap.test.js` 가 `heatmap.css` 텍스트를 읽어 `.hm-grp.is-hot` 에 `z-index` 가
  없고 `.hm-t.is-hot/.is-peer` 에는 있는지 검사한다. 페인트 순서 계약은 CSS 텍스트로만 잴 수 있다.
- 교훈: **시각 기능은 시각으로 검증한다.** 호버·강조·겹침을 바꿨으면 playwright 로 스크린샷 한 장을
  찍어 봐라(헤드리스 UA 는 우리 봇 방어에 걸리니 일반 Chrome UA 를 지정할 것).
