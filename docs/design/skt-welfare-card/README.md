# 회사 복지 「스탯 카드」 시안 (SK텔레콤)

FM(풋볼 매니저) 선수 스탯 화면의 문법을 회사 복지에 옮긴 시안. 사용자 요청
(2026-09-02): "얼굴 자리에 회사 로고, 옆에 9각형 카테고리 분류, 그 아래 회사 기본
정보, 우측에 카테고리별 복지 나열".

**라이브 캔버스**: https://claude.ai/code/artifact/2be23c37-b4b2-4baf-8cfe-45a611cfdd26
(Claude Design 캔버스 아티팩트. 아트보드 2장이 나란히 놓여 있고, 링크만 있으면
어느 기기에서든 열린다. PNG·PDF 내보내기 가능.)

이 디렉터리는 **시안 보관본**이다. 라이브 사이트(`web/`)에 들어간 것은 아직 없다 —
채택 여부와 다크/라이트 선택이 정해지면 그때 `generator/` 쪽에 반영한다.

## 파일

| 파일 | 무엇 |
|---|---|
| `gen.py` | **정본 생성기.** 데이터 표(복지 27항목·금액·카테고리·금액출처, 113개사 평균)와 팔레트 2벌을 갖고 두 아트보드를 찍어낸다. 수정은 언제나 여기서. |
| `Main.dc.html` | 다크 스탯 카드 (기본안) — `gen.py` 산출물 |
| `Light.dc.html` | 라이트 변형 (현재 jobcho.wiki 토큰: 그린 GNB·그레이 캔버스·흰 카드) — `gen.py` 산출물 |
| `canvas.json` | 캔버스 배치(프레임 1440×1000 두 장 + 설명 스티커 2장) |
| `shot-Main.png` / `shot-Light.png` | 렌더 결과 스크린샷 (링크를 안 열어도 보이도록) |

## 화면 구성

- **좌측 패널** — 로고 약어 타일(`TCOMPANY.LOGO_NM`) + 9각형 레이더 + 기본 지표.
  - 9각형 축 = 복지 9카테고리 **정본 순서**(`generator/pages/company.py`
    `CATEGORY_ORDER`), 값 = **카테고리별 복지 항목 수**, 축 최대 8(= 전 회사 한
    카테고리 최댓값). 회색 점선 = 등록 113개사 평균.
  - 지표 4종: 직원수·평균연봉·평균근속(DART 2025 사업보고서) + 복지 출처.
- **우측 본문** — 3열로 9카테고리 복지 나열. 숫자 = 연간 환산 금액(만원),
  색 3단계(300↑ / 100↑ / 그 미만), `추정` 표식, `정성` = 금액 환산 없는 항목.
- **우측 사이드** — 근무형태, 항목 구성(금액 환산 11 = 공식 3 / 추정 8, 정성 16),
  출처 계보 배지, 평균 대비 배율 상위 3개 카테고리.
- **하단** — 실적 3종(매출·영업이익·순이익, 2025 연결, 전년 대비).

## 갱신 절차

```bash
# 1) 데이터·레이아웃 수정
vi docs/design/skt-welfare-card/gen.py
python3 gen.py                       # Main.dc.html · Light.dc.html 재생성

# 2) 캔버스 재시드 (design 스킬의 헬퍼. <B> = 스킬 base directory)
node "<B>/seed-canvas.mjs" --template "<B>/payload.template.html" \
  --out skt-welfare-card.html --title "SK텔레콤 복지 카드" \
  --artboard Main.dc.html --artboard Light.dc.html --canvas canvas.json
node "<B>/seed-canvas.mjs" --check skt-welfare-card.html

# 3) 같은 URL 로 재게시 — Artifact 도구에 url 을 넘긴다(안 넘기면 새 URL 이 생긴다).
#    contract 는 "0.1.31" 고정, capabilities 는 생략(생략 = 저장된 선언 유지).
```

시드 산출물(`skt-welfare-card.html`, 2.5MB)은 커밋하지 않는다 — 에디터 코드가
통째로 들어 있어 매번 통째로 바뀐다. 필요하면 위 절차로 다시 만든다. 반대로 라이브
아티팩트에서 아트보드를 되받을 수도 있다(`seed-canvas.mjs --extract <저장된 페이지>
--to <빈 디렉터리>`) — 단 `gen.py` 는 그렇게 나오지 않으므로 이 디렉터리가 정본이다.

## ⚠ 함정 — 배지 '공식'은 금액이 공식이라는 뜻이 아니다

`BADGE_CD`(출처 계보)와 `AMT_SOURCE_CD`(금액 신뢰도)는 **독립 축**이다
(`db/schema.sql` 주석, `generator/content/policy.py`: "출처가 공식이라도 금액은
추정치일 수 있습니다"). SK텔레콤 금액 11건 중 **회사 공식 수치는 3건**(소모임 24 ·
복지포인트 400 · 통신비 290)이고 **8건은 추정치**다.

첫 시안이 이걸 오독해 추정치를 맨숫자로 싣고 "회사 공식 채용·복지 안내 기준"이라고
캡션을 달았다가 재검토에서 잡혔다. 현재 반영된 수정:

1. 추정 금액 8건에 `추정` 표식, 부제·요약에 "(추정 포함)" 명시, 사이드 패널에
   "회사 공식 수치 / 추정치 = 3 / 8" 행 추가.
2. `113개사 중 2번째` → **공동 2번째** (LG CNS 도 27항목 동률).
3. `평균 대비 많은 카테고리` → **평균 대비 배율 상위 3개** + "9개 카테고리 모두
   113개사 평균 이상" (실제로 9개 전부가 평균 이상이라 원래 문구는 거짓이었다).
4. 직원수만 전년 대비가 빠져 있던 것 보충(-3.2%) — 양수 둘만 보이고 음수는 감춘
   모양이 돼 있었다(DEC-B 위반).
5. GNB 의 전역 "데이터 확인일 2026-04-15" 제거 — 복지 확인일을 DART 수치에까지
   적용하는 문구였다. 어휘도 라이브 페이지에 맞춤(건→항목, 확인→확인일,
   정량 합계→금액 합계).
6. 범례 "색이 진할수록 큰 금액" → 실제 인코딩(금액 구간)으로 교체. 라이트 테마
   GNB 대비 4.18:1 → 5.08:1.
