## 3. 이 웨이브에서 새로 생긴 규칙

1. **벤더 호스트 robots 는 구속력이 있다**(사용자 결정 2026-09-20) — 페이지 경로가 허용이어도 본문이 `Disallow: /` 인 다른 호스트(ATS 의 API·빌더·정적 호스트)에만 있으면 **불가**. 헤드리스 렌더 우회도 같다. ⚠ **웨이브 3 씨젠은 이 규칙 이전 판정이라 라이브에 있다 — 다음 재수집 때 재검토.**
2. **UA 는 그 회사 robots 가 정한다** — 농심은 `*` 에 `Disallow: /` 이고 `ClaudeBot`·`GPTBot`·`CCBot` 만 허용한다(브라우저 UA 가 위반). 파두는 반대로 엣지가 AI 봇을 403 한다(브라우저 UA, 사용자 결정 2026-09-19). **우리가 누구인지 숨기지 않는 쪽을 먼저 고른다.**
3. **요청 40회 한도에 렌더 하위요청이 포함된다** — 한국콜마 프로브가 렌더 8회로 87회를 썼고 금지 호스트에 6회 닿았다. 렌더 전에 그 페이지가 끌어올 호스트의 robots 를 먼저 받는다.
4. **금액**(감사 §3-5) — 구간 금액은 **급부 형태가 가른다**(사다리형 포상금 = 상한 / 분포형 = 중간값) · **조건부 금액은 AMT 에 넣지 않는다**(AMT 612행 전부 `QUAL_YN=FALSE` — 스키마가 조건을 지운다) · 축 최댓값의 3배를 넘는 값은 급여성 혼입을 의심한다.
5. **리드는 회사별 프롬프트에서 규칙 3 열거 목록을 늘리지 않는다** — 늘리려면 계약 본문을 고쳐 전 회사에 같이 적용한다(§5 참조).

- ⚠ effort 는 양쪽 다 세션 기본값이라 **「Fable 구성 vs Opus 구성」** 비교지 순수 모델 비교가 아니다.
