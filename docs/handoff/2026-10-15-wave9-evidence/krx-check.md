## 결론

- **고침 1행: DN오토모티브 `운송장비·부품` → `전기·전자`.** DART `induty_code` 가 **28202**(C28 축전지 제조)다. 같은 다섯 자리의 원본 줄 삼성SDI 28202 가 전기·전자이고, 같은 제품(자동차 배터리)을 만드는 세방전지 줄도 전기·전자다.
- **나머지 21행은 초안 그대로**다. 확신 낮음 2행은 올라갔다. SNT다이내믹스는 30331(C30 자동차 부품)이라 **상**이 됐고, 롯데관광개발은 75210(N75 여행사업, 카지노 R 아님)이라 **중**이 됐다. 확신 중 3행 가운데 호텔신라(47859 소매)와 롯데에너지머티리얼즈(2629 · 원본 리노공업과 같은 코드)는 **상**이 됐다. 영원무역은 **중상**이다(46800 · 원본 실리콘투와 같은 코드 · §2 남는 위험).
- **확신 낮음으로 남은 행은 0이다.** 사람이 KRX 에서 한 번 볼 만한 행은 확신 중인 롯데관광개발 1행이다. 중상인 영원무역 · DN오토모티브 · LS마린솔루션은 그다음이다.
- 시장 22/22, 종목코드 22/22 가 DART `corp_cls` · `stock_code` 와 맞는다. 새 업종 이름은 0이다(전기·전자는 파일에 이미 있다).
- KRX 공식 페이지로 직접 확인한 줄은 없다. 22행 모두 **추정**이다(웨이브 7 §1 — KIND 403 · 정보데이터시스템 로그인 · 이번에는 다시 시도하지 않았다).

## 1. 요청

- OpenDART `GET https://opendart.fss.or.kr/api/company.json?crtfc_key=<키 생략>&corp_code=<8자리>` 를 **17회**(회사마다 1회 · 간격 약 1.5초 · 2026-10-15T15:45:21Z ~ 15:45:46Z · UA `Mozilla/5.0 (compatible; loupit-check)`) 보냈다. 17회 모두 HTTP 200 · `status 000` 이었다.
- 키는 `server/.env` 의 `DART_API_KEY` 를 환경 변수로만 넘겼다. 요청 기록은 `<키 생략>` 으로 남겼다. 원 응답 17건 모두에 키 문자열과 `crtfc_key` 가 없었다(기록 `key_in_response=False`). 저장한 파일 전체에서 키 문자열을 찾아도 0건이다.
- 저장 위치는 `krx/` 이다. 회사마다 `<slug>.json`(`corp_code` · `induty_code` · `corp_cls` · `stock_code` 만), 묶음 `company-17.json`, 요청 기록 `requests.log` 를 두었다. 원 응답은 저장하지 않았다.
- 나머지 5사는 로컬 사본을 썼다(새 요청 0). 차바이오텍 `cha_biotech/dart_company.json` · 영원무역 `youngone/dart_company.json` · 대한조선 `daehan_shipbuilding/dart_company.json` · IPARK현대산업개발 `ipark_hdc/raw/dart_company.json` · LS마린솔루션 `ls_marine_solution/dart_company.json` 이다.
- 선례 코드도 로컬 사본에서만 읽었다. 웨이브 8 `audit/tmp/dart_company/*.json` · 웨이브 7 · 9-29 재수집 사본에서 기존 csv 줄 40곳의 `induty_code` 를 확인했다.

### 남는 위험(확신 중 · 중상)

- **롯데관광개발(중).** N75 는 원본 선례가 없다. 같은 N 대분류의 롯데렌탈 줄도 원본이 아니라 웨이브 7 추정이다. 원본에서 M72 엔지니어링이 건설로 간 예(삼성E&A · 포스코DX — 웨이브 8 LOW-5)가 있으니 「서비스 → 일반서비스」가 늘 맞지는 않는다. KRX 가 여행업을 오락·문화에 넣었을 수 있다. 틀려도 바뀌는 것은 히트맵 · 대문의 업종 묶음 한 칸이다.
- **영원무역(중상).** 규칙 · 같은 코드 선례로는 유통이다. 다만 실제 사업은 의류 OEM 이다(국내 법인은 해외 생산 법인의 수출 주문을 받는 도매로 등록). KRX 가 자기 기록에서 섬유·의류로 분류했을 여지가 있다. F&F(섬유·의류)는 DART 코드가 C14 라 이 줄의 반례는 아니다.
- **DN오토모티브(중상).** 지배회사 본업은 공시상 「자동차용 배터리의 제조 및 판매를 주 영업목적」이다(`dn_automotive/dart_20260814001265.txt` 연결 주석). 그런데 방진 부품(C30) 사업부도 있고, 공정거래법상 지주회사 전환이 진행 중이다(같은 공시). KRX 가 매출 기준으로 다시 분류하면 운송장비·부품이 될 수 있다. 지주회사로 전환되면 KSIC 64992(기타금융)로 바뀔 수 있다(웨이브 7 §2 지주회사 예).
- **LS마린솔루션(중상).** F42 원본 선례가 없다. 대분류 F → 건설만 근거다.
- 22행 모두에 남는 공통 위험: KRX 는 자기 KSIC 기록(해마다 다시 분류)을 쓴다. DART `induty_code` 가 그보다 늦을 수 있다(웨이브 7 §4).
