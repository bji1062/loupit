## ③ 회사 계정 ATS `hanonsystems.recruiter.co.kr` — 귀속은 맞으나 본문이 원본에 없다

- 귀속: 테넌트 이름 `hanonsystems`, `<meta name="author" content="한온시스템">`, title 「한온시스템 채용 | 복리후생」, description 「한온시스템의 복리후생을 소개하는 페이지입니다.」 — **한온시스템 법인 자기 계정**이다(그룹 공통 테넌트 아님). 자기 도메인 GNB 가 링크한다.
- ATS sitemap(200 · 1,261B · 8 URL): `/career/company` `/home` `/jobs` `/notice` `/process` `/question` `/talent` **`/welfare`**.

## 수집 설계 시 유의

1. 공식 경로 셋(ATS 본문 API · 자기 도메인 `/Kor/` 보고서 · 글로벌 포털 `careers.`→ttcportals)이 모두 robots 금지 또는 차단이다. 수집하려면 **사용자 붙여넣기(ATS `career/welfare` 화면)** 가 유일한 길이다.
2. 붙여넣기가 오면 **한국타이어앤테크놀로지(기등록) 20행과 문장 대조를 먼저** 한다 — 같은 그룹 템플릿이면 보류(「바뀐 것 4」).

5. 형제 한국타이어 시드도 같은 벤더 CSR 을 렌더해 모은 것(09-20 규칙 이전)이라, 다음 재수집 때 같은 규칙으로 다시 볼 대상이다(씨젠과 같은 유형 — 리드 참고, 이번 프로브에서 형제 ATS 는 요청하지 않았다).
