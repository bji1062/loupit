## 무엇을 왜 하는가

회사 페이지에 **평균연봉·평균근속·직원수·매출·영업이익·순이익**을 2015~2025 **11개년** 추이로
얹는다. 목적은 [[콘텐츠 얄팍함]] 해소 — 회사 페이지 본문 중앙값이 1,402자라 애드센스가 거절됐다.

**뉴스 대신 이걸 하는 이유**: 사용자가 처음 요청한 건 prober.kr 처럼 "관련 뉴스"였다. 조사해 보니
네이버 검색 API 약관 7.3③ 이 결과의 **저장·캐시를 금지**해서 정적 페이지에 구울 수 없고,
3자 콘텐츠 원문 게재라 애드센스 **scraped content 정책에 오히려 걸린다**. 반대로 DART 는 저장·
재배포가 허용(출처표시 조건)이라 정적 HTML 에 들어가고 색인된다. 그래서 방향을 틀었다.
(뉴스는 "사용자 경험용"으로 나중에 별건 검토 — 애드센스 근거로 쓰면 안 된다.)

## 함정 (이번에 밟은 것)

- **디자인 시스템은 `min-width` 분기가 768 하나뿐이고 `web/test/tokens.test.js` 가 그걸 강제한다.**
