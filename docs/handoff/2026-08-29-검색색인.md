## B 구현

- `generator/release.py::lastmod_index` — URL 마다 sha256 지문. 직전 `.manifest.json` 의 `urls` 와
  같으면 그때 날짜 유지, 다르거나 처음이면 오늘. 빌드 결정성(115/115 동일) 위에 성립한다.
- `generator/indexnow.py` — 바뀐 URL 만 `api.indexnow.org` 로 POST. 실패해도 빌드 성공, stderr 한 줄.
- `generator/pages/sitemap.py::render_indexnow_key` — `/indexnow-key.txt`(키 있을 때만). nginx location 추가.
- `build.run` 게이트: 키 · `--no-indexnow` 아님 · `--out == CFG.out_dir`. 테스트·CI·스크래치는 통보 안 함.
- 테스트 18개(`test_lastmod_indexnow.py`). 생성기 405.
- 첫 배포는 `--lastmod 2026-08-28` 로(구글이 이미 받은 사이트맵과 일치). 두 번째 빌드로 "바뀐 것 0개" 확인.
  IndexNow 113 URL **HTTP 202**, 2초 뒤 빙 봇(40.77.167.156)이 키 파일 GET 200.

## 함정

- 수동 빌드에 env 를 source 안 하면 키 파일 없이 빌드된다(RUNBOOK 참고).
- `lastmod_index` 는 **스왑 전**에 부른다 — 직전 매니페스트를 읽어야 하기 때문. 순서를 바꾸면 매번 첫 실행이 된다.
- 대문·커뮤니티 허브는 생성물이 아니라 `web/index.html`·`web/community/index.html` 지문을 쓴다.
  파일이 없는 환경(테스트)에서는 매번 오늘 — 지어내지 않는다.
