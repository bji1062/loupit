# docs/handoff/ — 세션 기록 (append-only)

한 세션 = 새 파일 하나: `YYYY-MM-DD-<슬러그>.md`. **남의 파일은 절대 고치지 않는다** —
그래서 병렬 세션이 몇 개든 여기서는 충돌이 나지 않는다.

- 재개 정본은 [`docs/STATE.md`](../STATE.md) 하나뿐이다. 세션이 끝나면 STATE.md 의
  해당 행(들)만 갱신한다(표라서 줄 단위 병합이 된다).
- 예전 방식(`docs/HANDOFF-*.md` 릴레이 + 강등 배너)은 2026-08-26 폐지. 기존 9개
  문서는 이력으로 보존한다 — 함정 ①~(66) 원문이 거기 있다.
- 내용은 자유 형식. 권장 뼈대: 한 일(커밋 순) / 알게 된 것 / 남긴 것(미결).
