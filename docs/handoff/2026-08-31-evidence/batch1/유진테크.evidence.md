## ⚠ 함정 1 — HTTPS 가 브라우저에서 안 열린다 (URL 을 http 로 쓴 이유)

- 인증서는 정상(Let's Encrypt, `CN=eugenetech.co.kr`, verify code 0).
- 그런데 서버가 지원하는 건 **TLS1.2 + DHE-RSA-AES256-GCM-SHA384 뿐**이다.
  - TLS1.3 → handshake failure
  - ECDHE 계열 전부 → handshake failure
  - 기본 OpenSSL → `error:0A00018A:SSL routines::dh key too small` (DH 파라미터가 약함)
- **크롬은 2017년(Chrome 63)에 DHE 스위트를 전부 제거**했다 → `https://` 로는 일반
  사용자 브라우저 접속이 실패한다.
- `http://` 는 리다이렉트 없이 200, 동일 바이트(12,498 bytes) 반환. 사이트 자신의
  `og:url` 도 `http://www.eugenetech.co.kr/recruit/` 다.
- → **CAREERS_BENEFIT_URL 을 `http://` 로 넣었다.** (`infra/verify/link-audit.py` 는
  `http://`·`https://` 둘 다 SKIP_SCHEMES 라 감사에는 영향 없음. 아웃링크는
  서브리소스가 아니라 링크라서 mixed-content 도 아님.)
- 회사가 나중에 TLS 를 고치면 https 로 바꾸면 된다.

### 앵커 폐기 사유 — `incentive` 100만원 (오염 판정)

구본 행: `('incentive', '인센티브', 100, 'compensation', ..., '인센티브제 (추정)')`

새 출처는 "경영성과에 따라 **최대 600%**의 특별 성과급"이라고 명시한다. 600% 는
급여 대비 배율이라 만원 단위로 환산할 수 없지만(→ 금액 없음이 정답), 그 규모는
연 100만원과 **자릿수가 어긋난다**. 100만원을 그대로 승계하면 상세 화면에서
"최대 600% 성과급"이라는 설명 옆에 "연 100만원"이 붙어 **자기모순 표시**가 된다.
금액정책 (a) 의 "기존 행이 오염 데이터로 보이면 승계 금지" 에 해당 → 금액을 버리고
`QUAL_YN TRUE` + `QUAL_DESC_CTNT` 서술 행으로 전환했다.

`child_edu` 200 · `meal` 432 는 새 서술과 모순되지 않아(고교·대학생 학자금 / 3끼 무상)
그대로 승계했다.

## 코드 선택 메모

- **신규 코드 1개: `company_event`** (leisure) — 「기타: 정기 야유회, 체육대회, 송년회」.
  정식 어휘 leisure 목록(club, leisure_room, leisure_ticket, library, resort,
  sports_ticket, welcome_kit, guest_house, culture_day) 에 사내 정기 행사에
  해당하는 코드가 없다. `club` 은 동호회, `culture_day` 는 문화의 날이라 다르다.
  `event` 는 정식 어휘상 family 소속(=경조사)이고 이미 41번 행이 쓰고 있어 중복 불가.
  → snake_case 신규 코드 부여.
- `wedding` 매핑 판단 — 「결혼기념일 선물」에 정확히 대응하는 정식 코드는 없다.
  결혼기념일 ≠ 결혼이지만 정식 어휘 family 의 `wedding` 이 결혼 관련 급부로 가장
  가깝고, 신규 코드 남발을 피하려 `wedding` 을 썼다. 정확한 의미는 BENEFIT_NM
  ('결혼기념일 선물') 과 QUAL_DESC_CTNT ('결혼기념일 축하 꽃바구니 지급') 이 담는다.
- `incentive` vs `profit_sharing` — S1「성과급 지급」과 S2「Profit Sharing」은 둘 다
  "경영 성과에 따른 특별 성과금"으로 **같은 제도**다. 두 코드로 나누면 같은 복지가
  두 줄로 보인다 → 구본과 연속성이 있고 정본 페이지(S1)의 라벨인 `incentive` 하나로
  통합하고, Profit Sharing 은 QUAL_DESC 안에 보강 서술로 넣었다.
- 코드 중복 없음(12개 전부 유니크): incentive, excellence_award, dormitory, insurance,
  child_edu, event, wedding, edu_support, resort, company_event, welfare_point, meal.
- 카테고리 9종 중 사용: compensation(2), work_env(1), health(1), family(3), growth(1),
  leisure(2), perks(2). 미사용: flexibility, time_off (근거 없음 — 경조휴가는 41번
  `event` 서술에 포함, 별도 휴가 행을 만들 근거는 페이지에 없음).
