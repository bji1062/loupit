### robots.txt

- **www.samsungcard.com/robots.txt** — 취득 완료(HTTP 200). 구조:
  ```
  User-agent: Yeti / googlebot / google-extended / GPTbot / ClaudeBot
    Allow : ... (개인·홈 경로 다수)
  User-agent: *
    Disallow: /
  Sitemap: https://www.samsungcard.com/sitemap.xml
  ```
  ClaudeBot 이 속한 그룹에는 **Disallow 지시자가 하나도 없다** → 매칭 규칙 없음 = 허용(표준 동작).
  `User-agent: *` 의 `Disallow: /` 는 더 구체적인 그룹이 매칭되므로 ClaudeBot 에 적용되지 않는다.
  (`Allow :` 는 콜론 앞 공백이 있어 엄격 파서는 무시하는 형태이나, 어느 쪽으로 해석해도 Disallow 는 없다.)

- **www.samsungcareers.com/robots.txt** — 존재하지 않음(302 → `/sub/etc/error.html`, 본문 `{"code":500}`). robots.txt 부재 = 전면 허용.

## 4. 앵커(금액) 내역 — **전건 승계 금지**

**금액정책 (a) 적용 결과: 승계 0건, 신규 금액 0건. 23행 전부 `BENEFIT_AMT NULL` + `QUAL_YN TRUE`.**

승계 금지 사유(오염 의심):

1. 구본 파일 헤더가 스스로 이렇게 적어 두었다 —
   `-- 주의: 원본 txt 파일 내용이 "에코비트"로 표기됨 (삼성 계열사 환경사업 자회사)`
   즉 구본 7행의 원본 텍스트는 **삼성카드가 아닌 다른 회사(에코비트)의 것으로 표기돼 있었다**는
   경고가 파일 안에 명시돼 있다. (덧붙여 에코비트는 삼성 계열사도 아니다 — 폐기물처리 기업.
   구본 주석의 회사 식별 자체가 틀렸다.) 회사 귀속 자체가 흔들리는 금액이다.
2. 구본의 특징적 서술("헬스장 등록비 최대 55% 할인", "창립기념 쌀", "삼성카드 임직원몰")이
   삼성카드 공식 문서 어디에도 없다 — 1의 오염 가설과 일치한다.
3. 새 출처 두 곳 모두 금액을 **일절** 공개하지 않는다. 앵커를 유지하면 근거 없는 숫자가
   "공식 페이지에서 왔다"는 착시를 만든다.

폐기한 앵커(기록용): `health_check` 100 · `insurance` 30 · `fitness` 30 · `child_edu` 200 · `event` 50 · `club` 200 (단위: 연 만원).

  - `family_day` → 카테고리 `family` (어휘 목록상 flexibility 그룹). 근거가 "가족과 함께 참여하는 프로그램"이라 휴무제도가 아닌 가족 프로그램 → `family` 가 맞다. 새 코드를 만드는 대신 기존 코드를 재사용.
  - `lounge` → 카테고리 `work_env`. "임직원 전용 사내 카페" = 사내 편의 공간.
- 컬럼 길이 확인(`db/schema.sql:74`): `BENEFIT_CD` VARCHAR(30) / `BENEFIT_NM` VARCHAR(100) / `QUAL_DESC_CTNT` VARCHAR(500) — 전 행 여유 있음.
