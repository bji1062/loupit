### ⚠ 도메인 함정 (수집기에 그대로 물리는 지점)

- DART 기업개황의 홈페이지 값은 **www.mcnex.co.kr** 인데, 이 호스트의 인증서는 `CN=*.mcnex.com` / `SAN: *.mcnex.com, mcnex.com` **하나뿐**이다. 그래서 **엄격 TLS 로는 접속 자체가 실패**한다:
  - `curl https://www.mcnex.co.kr/` → `SSL: no alternative certificate subject name matches target host name` (http=000)
  - `curl https://mcnex.co.kr/` → 동일 실패 (http=000)
  - 인증서 검증을 끄면(`-k`) `HTTP/1.1 302 → Location: https://mcnex.com/` 이 보인다.
- `http://www.mcnex.co.kr/` 는 **타임아웃**(80번 응답 없음).
- 즉 **정본 도메인은 `mcnex.com`** 이고, `mcnex.co.kr` 는 "죽은 건 아니지만 검증 가능한 방법으로는 못 여는" 상태다. DART 홈페이지 필드를 그대로 믿는 수집기는 이 회사에서 조용히 0건을 반환한다.
- 사이트맵(`/sitemap/sitemap.xml`)에는 **채용 섹션이 통째로 빠져 있다** — `01.AB07.01~04` 가 없다. 사이트맵만 순회하는 수집기도 복지 페이지를 못 찾는다. 실제 발견 경로는 `/ko/company/01.AB07.0N` 을 훑어 `<title>` 로 식별한 것.

   둘 다 포상 제도. `excellence_award` 외에 대응 코드가 없어 병기. (셀트리온 파일이 `club` 에 동호회+문화체험 클래스를, `event` 에 경조사+영빈관을 병기한 선례와 같은 처리.)
2. **`club` ← 사내동호회 활동 지원 + 워크샵 및 문화활동 지원**
   `culture_day` 를 쓰려다 **접었다** — 기존 seed 의 유일한 `culture_day` 사용례는 '컬쳐데이'(문화의 날 = 조기퇴근형 제도)라, 성격이 다른 "워크샵·문화활동 지원"에 같은 코드를 붙이면 heatmap 의 `benefit_nm` 최빈값 폴백 라벨까지 오염된다. `leisure_ticket`(티켓·이용권)도 아니다. → 같은 leisure 군의 "회사가 지원하는 단체 활동"인 `club` 에 병기.
3. **`clinic` ← 건강관리프로그램 + 사내 건강관리실**
   S1 은 "건강관리프로그램" 이라고만 쓰고 내용을 말하지 않는데, S2 본문이 "사내 건강관리실과 휴식 장소를 제공" 이라고 설명한다. 같은 제도의 이름과 실체로 보고 한 행.

## 기타 특이사항

- `CAREERS_BENEFIT_URL` 을 `NULL` → `https://www.mcnex.com/ko/company/01.AB07.03` 로 채웠다. `COMP_ENG_NM='mcnex'` · `COMP_NM='엠씨넥스'` · `COMP_TP_ID` 서브쿼리(`'mid'`) · `INDUSTRY_NM='카메라모듈'` · `LOGO_NM='M'` 은 **구본 값 그대로 보존**.
- 회사 유형은 구본대로 `mid`(중견기업)를 유지했다. 코스피 상장사지만 유형 축은 이번 작업 범위가 아니다(보존 지시).
- 카테고리는 9종 전부 유효값만 사용: compensation 4 / flexibility 1 / work_env 2 / health 4 / family 2 / growth 2 / leisure 2 / perks 1. **`time_off` 는 0행** — 두 페이지에 휴가 제도가 "경조휴가" 말고는 없다(연차·리프레시·하계휴가 언급 전무). 근거 없는 행을 만들지 않았다.
- `BENEFIT_CD` 회사 내 중복 없음(18개 전부 상이).
- `SORT_ORDER_NO` 는 10단위(10~180), 카테고리 블록 순서대로.
- 원문 HTML 사본(재검증용): 같은 스크래치패드의 `comp_01.AB07.03.html`, `esg_social.html`, `sitemap.xml`, 텍스트 추출본 `welfare.txt`.
- **DB 접속·기록 없음. 저장소는 읽기만 함.** 산출물은 이 스크래치패드 `batch1/` 에만 있다.
