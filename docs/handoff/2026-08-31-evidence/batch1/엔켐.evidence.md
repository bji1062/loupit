- `SET @comp_id = ...` → `UPDATE TCOMPANY SET CAREERS_BENEFIT_URL ...` (**필수**, 구본이 NULL 이라 INSERT IGNORE 로는 안 바뀜) → `DELETE ... BADGE_CD='est'` → `INSERT ... ON DUPLICATE KEY UPDATE` 8개 컬럼.
- 컬럼 10개 순서 동일: COMP_ID, BENEFIT_CD, BENEFIT_NM, BENEFIT_AMT, BENEFIT_CTGR_CD, BADGE_CD, NOTE_CTNT, QUAL_YN, QUAL_DESC_CTNT, SORT_ORDER_NO.
- SORT_ORDER: 섹션 기준값 10단위(10/20/30/40/50/60/70) + 섹션 내 +1 — 셀트리온 정본과 동일 방식.
- 섹션 주석 `-- ── 이름 (code) ──` 형식 동일.
- BADGE_CD 전 행 `'est'`.

## 8. 특이사항

1. **금액 0건 공개** — 3행의 금액은 전부 구본 앵커 승계이며 NOTE 에 "추정" 이 박혀 있다. `official` 승격 시 금액 3건은 근거가 없으므로 함께 재검토해야 한다.
2. **청년내일채움공제**는 공식 페이지 기재를 그대로 옮긴 것이다. 정부 사업의 현재 신규가입 가능 여부는 확인하지 않았다(공식 페이지가 갱신되지 않았을 가능성 있음) — `official` 승격 전 확인 대상.
3. 사이트는 정적 SSR 이라 JS 번들 추출이 불필요했다. 봇 차단·403 없음(일반 브라우저 UA 사용).
4. 채용공고가 0건이라 직군별 처우 정보는 얻을 수 없었다.
