## 6. SQL 을 만들지 않은 판단 근거 (요약)

1. **추출 규칙 6 직접 적용** — 공식 복지 정보가 없다.
2. **DELETE 부작용** — 정본 형식은 `DELETE ... WHERE BADGE_CD='est'` 를 먼저 실행한다.
   근거 있는 행이 0건인 상태로 SQL 을 만들면 기존 5행을 지우고 아무것도 넣지 않거나,
   법정 의무(퇴직연금) 1행만 남겨 상세 페이지를 오히려 **더 얇게** 만든다
   (AdSense 본문량 회복 작업과 정면 충돌).

   404 를 넣으면 `infra/verify/link-audit.py` 가 잡는 깨진 아웃링크를 심는 셈이다.
   (기존 파일이 `NULL` 로 둔 것이 현재로선 정확하다.)
