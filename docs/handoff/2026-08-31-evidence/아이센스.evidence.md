# 아이센스 복리후생 — 행별 근거표 (2026-08-31)

수집 방식: recruit.i-sens.com 은 Next.js(Ninehire 빌더) 사이트로 일반 마크다운 변환 시 빈 내용이 나온다.
`curl` 로 원문(약 1.08MB)을 받아 `<script id="__NEXT_DATA__" type="application/json">` 블록을 파싱했다.
사이트 전 페이지가 `props.pageProps.homepageProps.homepage.pages[]` 에 통째로 내장되어 있고,
복지 전문은 `pages[14]`(title=복리후생, pageUrl=benefits)의 `sections` 내 text 블록에 있었다.
채용공고 본문은 `/job_posting/{addressKey}` 페이지의 `props.pageProps.jobPosting` 에서 추출(금액 확인용).

인용 표기: SSR JSON 의 text 블록에서 HTML 태그만 벗긴 표시 텍스트를 그대로 옮겼다(줄바꿈은 `/`).
