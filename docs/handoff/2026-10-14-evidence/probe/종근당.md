## 수집 설계 시 유의

1. 자기 도메인 HTML 에는 복지 항목이 없다. 정본은 법인 전용 ATS `ckd.recruiter.co.kr/career/Welfare` 인데 본문이 `Disallow: /` 벤더 API 뒤라 프로브 · 수집 레인 모두 직접 받을 수 없다 — **사용자 붙여넣기**가 유일한 길.
2. 보조 정본 후보는 「2025년 종근당 지속가능경영보고서」(2026 발간, 자기 도메인 PDF)지만 `www.ckdpharm.com` · `www.ckd-holdings.com` robots 가 둘 다 `/*.pdf$` 를 막는다. 사람이 받아 주면 보고 범위(종근당 단독 여부)와 쪽 번호를 먼저 확인한다. 2022~2024 는 **종근당홀딩스** 보고서라 이 법인 근거가 아니다.
3. 붙여넣기 없이 가능한 것은 사업보고서 공시 2개(시차출퇴근제 · 원격근무제)뿐 — 「출처 없음 + 공시 후보 2행」 수준이다.
4. ATS 진입은 `/appsite/…`(robots `Disallow: /app*`)가 아니라 `/career/home` · `/career/Welfare` 로 적는다. 형제(종근당바이오 · 경보제약 · 종근당홀딩스)는 전부 미등록이라 그룹 템플릿 보류 사유는 없다.
