- **GROW-UP DAY + 하계휴가 추가 지원 → `summer_leave` 한 행**: 59쪽에서 GROW-UP DAY 설명이 「여름 휴가제도」로 확정됐고, 보고서 LEISURE 5항목 ↔ 웹 Leisure 5항목이 이 한 쌍만 빼고 1:1 대응한다. 웹이 「법정 연차 외에 별도로 부여」라고 밝혀 「하계 이름 + 회사가 더 주는 휴가」(어휘표) 조건을 만족. 둘을 따로 세우면(leave_general + summer_leave) 같은 제도를 두 번 세는 위험이 있어 합쳤다.
- **장기근속 포상 → `long_service_leave`**: 보고서는 「포상 제도」만, 웹은 「포상 및 휴가」를 한 줄에 적었다 → 휴가+포상 한 줄 = `long_service_leave`(SPEC 20 경계). 원문이 둘을 다른 항목으로 나누지 않아 `long_service_bonus` 행은 세우지 않음.
- **59쪽 「축하 선물 지급」(설날·추석 상품권 + 출산 축하금·선물)** → 복합 라벨을 `holiday_gift`(명절 상품권)와 `parenting`(출산)으로 갈랐다. 각 행은 자기 몫만 서술.
- **보육비 · 유치원 보조비 → `parenting`**: 58쪽이 「자녀 양육 지원」 라벨 아래 적었다(parenting = 자녀 양육 · 보육). 어휘표 `child_edu` 에 「유아교육비」가 있어 child_edu 로 볼 여지도 있다 — 8절.
- **원거리 지원금 → `housing_support`**: 웹이 「주거비 일부를 지원」이라 밝혀 주거비 현금. 보고서 문장(「원거리 발령되는 경우 지원금」)만 보면 `relocation`(이주 · 정착)도 가능 — 8절.
- **재해 지원 · 작은 사랑 나눔회 → `event` 서술**: 코퍼스 선례 다수가 재해경조금 · 재해부조금 · 사내 상조회를 `event` 행에 함께 둔다(grep 「재해경조금」 · 「사내 상조회」). 「작은 사랑 나눔회」는 원문에 기금 · 대출 낱말이 없어 `welfare_fund` · `welfare_fund_loan` 은 쓰지 않았다 — 8절.
- **경조휴가 = `event` 서술**(0-1 #5): 「경조금과 휴가 부여」를 event 행에 그대로.
- **이동통신비 → `telecom`**, 대상 한정(「업무상 통화할 일이 잦은 구성원」)을 이름 · 서술에. 업무 경비 성격이 있어 8절.
- **패밀리 데이 → `company_event`**(어휘표: 가족 행사는 company_event, `family_day` 는 조기퇴근).
- **자기주도 학습 → `edu_support`**(규칙 8: 학습 플랫폼 · 특강 · 사외 교육비). 같은 표의 직무 Academy · GenAI Academy · 리더십 · GS Way · 온보딩은 업무 교육이라 뺐다. 「어학 / 자격증」 지원은 lang · self_development 행과 같은 제도라 edu_support 서술에는 원문 목록 그대로 두었다.
- **New Start Program → `retirement_support`**: 퇴직 후 혜택(창업비용 · 자녀 학자금 · 대출이자 지원)이다. 같은 PDF 의 「창업교육/훈련지원(퇴직 예정자 OJT)」은 법정 재취업지원(창업 교육)과 겹칠 수 있어 서술에서 뺐다. 「대출한도 3천만~2억원」은 대출 원금 한도라 금액 아님(서술에도 넣지 않음).
- **성과급 → `incentive`**: 「회사/BU/개인 성과」로 개인 · 조직 성과를 한 줄에 → incentive(profit_sharing 아님).
- **신규 코드: 없음.** 25행 전부 어휘표 89종 안. 카테고리는 어휘표 열을 그대로 베꼈다(`_row_check.py` 카테고리 = 어휘표 통과).

## 8. 판단 요청 · 애매

1. **parenting 의 「법정 기준을 초과한 육아휴직 제도 운영」**(58쪽): 회사가 초과를 스스로 밝혔지만 초과 폭이 없다. 규칙 3-2 「원문이 법정분과 회사분을 스스로 나눠 밝힐 때만」의 경계. 남긴 이유 = 회사 원문이 상회를 단언 · 웹에 「아이 사랑 휴직」이라는 별도 이름이 있음. 걷자는 판정이면 parenting 서술에서 이 구절과 꼬리 「육아휴직 초과 기간·휴직 중 급여」만 빼면 된다(행은 유지).
2. **잔여 휴가 1.5배 보상(행 없음)**: 「75% 휴가촉진제를 실시하여 개인연차 중 25%범위 내 미사용분에 대해 1.5배 보상」. 사용 촉진을 한 회사는 미사용분 보상 의무가 없어지므로(근기법 61조) 25% 범위 1.5배는 법을 넘는 급부로 보인다. 다만 ① 연차수당과 한 몸이라 법정 경계 ② 어휘표에 맞는 코드가 없음(leave_general 은 휴가, bonus/incentive 는 성격이 다름) ③ 「연차」 낱말 금지라 서술이 어렵다. 그래서 행을 세우지 않았다. 세운다면 후보 = 신규 코드(제도 영역 이름 예: `leave_buyout`, compensation) — 코퍼스에 「1.5배」 · 「미사용」 휴가 보상 행 0건(grep: CJ 계열 「미사용 휴가 이월제도」 1건만, 성격 다름).
3. **보육비 · 유치원 보조비**: parenting(58쪽 「자녀 양육 지원」 라벨) vs child_edu(어휘표 「유아교육비」). parenting 으로 둠.
4. **원거리 지원금**: housing_support(웹 「주거비 일부」) vs relocation(보고서 「원거리 발령되는 경우 지원금」). housing_support 로 둠.
5. **금연 활동 지원**(웹 안전보건 탭 보건 관리 체계 06 — 라벨만, 보고서에는 없음): 안전보건 관리 수단 목록이고 복리후생 목록 항목이 아니라 `smoking_cessation` 행을 세우지 않음.
6. **작은 사랑 나눔회 → event 서술**: 원문은 「갑작스러운 어려움에 함께 힘을 보태는 상생 지원 제도」뿐이라 재원(회사 · 직원 갹출)도 내용도 모른다. event(재해 · 상조 선례)에 넣고 꼬리에 「나눔회 지원 내용·재원 미기재」.
7. **이동통신비 지원**: 「업무상 통화할 일이 잦은 구성원」 대상이라 업무 경비 성격도 있다. 회사가 인재경영 지표(복지 24항목)에 넣었고 코퍼스 telecom 선례(「책임급 이상·영업 외근직 등」)가 있어 대상 한정을 이름에 달아 실었다.
8. **New Start Program 출처 연식**: 제도 문서는 2018-01-01 개정 · 2021-02-19 게시로 오래됐지만 지금 사이트 인재경영 실적자료 탭에 걸려 있고, 최신 보고서 107쪽이 2025년 이용 3명을 적어 제도가 지금도 돈다. 문서의 세부(창업비용 · 자녀 학자금 · 이자 지원)가 2025년에도 같은지는 보고서가 말하지 않는다. 가맹점 창업 유도라는 사업 성격도 있다.
9. **패밀리 데이**: 58쪽은 「2025년 … 운영하였습니다」 1회 행사로 적었고 「앞으로도 … 다양한 프로그램 운영」이라 했다. 연도를 서술에 남기고 꼬리 「정례 개최 여부 미기재」.
