## 3. 코드 매핑 판단 · 어휘 함정 회피

- 「자녀 학자금·입학축하금」 한 항목 → `child_edu`(학자금) + `parenting`(입학축하금 — 어휘표 parenting 대표 명칭 「자녀 입학 축하금」). 각 행은 자기 몫만.
- 경조휴가 → `event` 서술(계약 §0-1 5). `leave_general` 에 넣지 않았다.
- 「건강검진·결혼기념일 휴가」 → 검진 휴가는 `health_check` 서술(코퍼스 선례 DB손해보험 「정밀 건강진단·건강검진 휴가」 · LG유플러스 등 「종합건강검진·검진 휴가」), 결혼기념일 휴가는 `leave_general`(경조사 밖 특별휴가 — 판단 요청 ①).
- 생일 축하금(현금) → `birthday_gift`(코퍼스 솔브레인 「생일선물·생일 축하금」 · 더블유게임즈 「…생일축하금」). `birthday_leave` 아님.
- 생수 자택 배송 → `snack_bar`(코퍼스 대한항공 「전사 커피라운지·매월 생수 지원」 = snack_bar). 보고서 「간식 지원」도 `snack_bar` 라 같은 코드로 한 행(판단 요청 ③).
- 전입여비 · 이사/이동비용 · 이사비 → 셋 다 `relocation`(이주 · 부임 이사) — 같은 코드로 귀결되어 한 행.
- 출퇴근 교통비(돈) = `transport` · 통근버스(운행) = `commute_subsidy` — 어휘표 경계대로 두 행. 원문도 다른 출처 · 다른 항목이다.
- 사내대출(용도 미기재) → `welfare_fund_loan`(규칙 12). 이름 · 서술에 「기금」 없음(원문에 없음).
- 개인연금 → `pension_support` · 회사 부담이 원문에 없어 꼬리 「회사 부담 여부·지원 금액 미기재」(웨이브 4 감사 L-1).
- 단체상해보험 → `insurance`(상품) · 의료비 · 가족 의료비 → `medical`.
- 장기근속 포상(금메달 · 여행권, 휴가 없음) → `long_service_bonus`.
- 성과격려금 「전사 목표 달성 시 등 …특별 상여」 → 회사 실적 연동 · 평가 차등 · PI 언급 없음 → `profit_sharing`(계약 §0-1 5 · 어휘표 보상 함정). 복리후생 블록 밖이지만 정본 페이지 안 보상제도 표다(판단 요청 ②).
- 기술사 자격증 취득비 → `self_development`(규칙 8 — 회사가 비용을 대는 자격증 취득비).
- 금연클리닉 운영 → `smoking_cessation`(판단 요청 ④).
- 사내식당 끼니 미기재 → `meal` 금액 NULL(4-5 「끼니가 안 적힌 사내 식당 운영」).

## 8. 판단 요청 · 애매

1. **결혼기념일 휴가 = `leave_general`** — 채용 페이지 설명이 「경조 및 건강검진 시 별도 휴가 제공」이라 회사가 결혼기념일을 「경조」로 부른다. 계약 §0-1 5 는 경조휴가를 `event` 로 보내지만, 결혼기념일은 통상의 경조사(결혼 · 사망 · 출산)가 아니고 보고서 57쪽은 「경조금 및 경조 휴가」와 「결혼기념일 휴가」를 **다른 불릿**으로 적었다 → `leave_general`. 코퍼스 대안: `birthday_leave` 「개인 기념일 휴가」(1사) · `event` 서술 흡수. 리드가 `event` 로 보내면 SORT 12 서술에 「결혼기념일 휴가」를 붙이고 SORT 60 삭제.
2. **성과격려금 = `profit_sharing`** — 근거는 채용 페이지 같은 URL 의 「인사제도 > 보상제도」 표(복리후생 섹션 밖). 「전사 목표 달성 시 **등**」의 「등」이 다른 지급 사유를 열어 두지만 평가 차등 · 개인 성과 언급은 없다. 「특별 상여」 낱말 때문에 `bonus`(11-2 — 복리후생 블록 안 정기 상여율만)로 볼 여지가 있으나 정기 상여율이 아니고 실적 연동이라 `bonus` 아님. 보도자료(2026-09-28) 「2026년 성과 격려금 600만 원 지급」은 임단협 합의 1회 금액이라 서술에 넣지 않았다 — 넣을지 리드 판단.
3. **생수 자택 배송 + 간식 → `snack_bar` 한 행** — snack_bar 는 사내 카페 · 간식 · 음료 축이고 자택 배송 생수는 사내 시설이 아니다. 코퍼스 대한항공 「매월 생수 지원」이 snack_bar 라 따랐다. 다른 코드로 가르면 `snack_bar` 는 간식만 남는다.
4. **금연클리닉 운영 = `smoking_cessation`** — 코퍼스 grep 「금연」 전부: `smoking_cessation` 3행(테크윙 · 피에스케이 「금연수당」, JYP 「금연 성공 축하금」 — 전부 현금) · 프로그램형 금연은 다른 행 서술 안(기아 · 코오롱인더 · 현대제철 · 엠씨넥스 · S-Oil = `clinic`, 두산 = `fitness`). 그 회사들은 원문이 금연을 의료시설 · 건강 프로그램 문장 안에 적었고, HJ중공업 보고서는 「사내 의무실 운영」과 「금연클리닉 운영」을 **다른 불릿**으로 적어 독립 행으로 뒀다. 코드 이름이 제도 영역(금연)이라 클리닉형도 뜻이 맞는다. 리드가 `clinic` 흡수를 택하면 SORT 43 서술에 붙이고 SORT 44 삭제.
5. ChatGPT 트렌드와 활용 과정(55쪽) — 업무 활용 교육으로 보고 뺐다. 교양 · 자율 수강이라는 표지가 원문에 없다.
6. **리드 판정 (101) — 행 세움**(SORT 90 `flex_work` 「유연근무제」 · 꼬리 「제도 유형·대상 미기재」). 아래는 처음 올린 판단 요청 원문. **「유연근무제 운영」(57쪽 가족친화 인증 문단)** — 회사가 유연근무제를 운영한다고 쓴 유일한 문장이지만, 2021년 인증을 받은 사유 나열이고 제도 종류 · 대상이 없다. 행을 만들지 않았다. 리드가 세우기로 하면 `flex_work` 「유연근무제」 · 꼬리 「제도 종류·대상·운영 방식 미기재」 · 출처 「2025 지속가능경영보고서 57쪽 가족친화 인증기업 선정 본문」. 빼 두면 근무 유연성 축이 빈다(거짓 「없음」 위험이 있으니 리드 판단).
7. 사업장 한정 가능성 — 사내식당 · 통근버스 · 의무실 · 근무복은 건설 현장 · 영도조선소 등 사업장 한정일 수 있으나 원문이 밝히지 않아 부문 표기를 달지 않고 꼬리에 「운영 사업장 미기재」류로 남겼다. 채용 페이지 항목도 부문 구분 문구 없음.
8. 채용 페이지 「현장 근무 시 이동·가족이사 비용 지원」은 현장 근무자 조건이 있는 급부라 서술에 조건을 그대로 남겼다(금액 없음).
