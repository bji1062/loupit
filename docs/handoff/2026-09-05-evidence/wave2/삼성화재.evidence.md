### 귀속 판단 (계약 규칙 6)

정본이 자기 도메인이 아니라 **그룹 채용사이트**지만, 페이지 자체가 **법인 전용**이라 그룹 공통 복지 귀속 문제가 발생하지 않는다. 근거 4가지:

1. **경로가 법인으로 좁혀진다** — `/subsid/`(관계사 소개) → 그룹 헤딩 「금융」 → 삼성화재 → `/subsid/detail/E21`. 같은 헤딩 아래 형제 링크는 삼성생명 E11 · 삼성카드 E31 · 삼성증권 E40 · 삼성자산운용 EF0 로 **관계사마다 URL 이 다르다**.
2. **본문이 법인을 명시한다** — 「삼성화재는 … 국내 1위 손해보험사 입니다」 · 주소 「서울특별시 서초구 서초대로74길 14」 · 주요 업무 「손해보험」 · 홈페이지 `https://www.samsungfire.com`.
3. **복지 섹션 제목에 법인명이 붙어 있다** — `<h2 class="slimTitle">삼성화재의 <br>근무 환경과 복지 제도</h2>`. 직무 8종(마케팅·영업관리·글로벌 사업 기획/운영·상품개발·계리·손해사정·자산운용·IT 서비스 기획/운영·디지털 서비스 기획/운영)과 인재상 3종도 전부 삼성화재 전용이다.

### 렌더 방식 · 수집 방법

- **서버 사이드 렌더**. 복지 30항목이 최초 HTML 에 그대로 있다 → 헤드리스 브라우저 불필요, `curl` + 파서로 충분.

- 마크업: `<ul class="welfareList"> <li class="col3Wrap"> … <h3>카테고리</h3> … <button class="tag tip" data-tip="설명">항목명<span>설명</span></button>`.

#### ⚠ 파싱 함정 — 이스케이프 안 된 꺾쇠

`data-tip` 속성값과 자식 `<span>` **양쪽 모두**에 이스케이프되지 않은 꺾쇠가 들어 있다.

```
data-tip="언제 어디서든 학습하고 소통할 수 있는 모바일 학습플랫폼 <Dream Campus+>을 운영하고 있습니다.">
<span>본인의 라이프스타일에 맞추어 자율적으로 유연근무가 가능한 <선택적 근로시간제>를 운영하고 있습니다.</span>
```

- **정규식 태그 제거**는 항목명을 깨뜨린다(프로브 지적 그대로).
- **BeautifulSoup `html.parser` 도 완전하지 않다.** 30항목 라벨은 전부 정상 복원하지만, `<Dream Campus+>` 는 라틴 문자로 시작해 **태그로 해석되어 설명문에서 조용히 사라진다** — 본문이 「모바일 학습플랫폼 을 운영하고 있습니다」로 나온다. 반대로 `<선택적 근로시간제>` 는 한글이라 태그명이 될 수 없어 텍스트로 살아남는다. 즉 **둘 중 하나만 오염되어 눈치채기 어렵다.**
- 그래서 최종 추출은 **버튼 블록을 원문 문자열 그대로 잘라** `data-tip="([^"]*)"` (속성값에 겹따옴표가 없어 안전) 와 `<span>(.*?)</span>` 로 뽑고 엔티티만 unescape 했다. 30항목 전부 `data-tip == span` 임을 확인했다(오탈자·비대칭 0건).

#### 법인 검증 · 갱신 감지

- 프로브 권고대로 `<h2>` 에 「삼성화재」가 들어있는지 확인했다(통과). 페이지에 `<link rel="canonical">`·`og:url` 이 없고 모든 관계사 페이지의 `<title>` 이 똑같이 `SAMSUNG CAREERS` 라 제목으로는 법인을 식별할 수 없다.
- 재수집 시 변경 감지는 `ul.welfareList` 슬라이스 해시로 — 위 sha256 을 기준값으로 쓴다.
- **soft-404 주의**: 없는 경로는 404 가 아니라 302 → `/sub/etc/error.html`(HTTP 200)로 흐른다. 정상 판정은 **최종 URL 이 `/subsid/detail/E21` 이고 `ul.welfareList` 가 존재**할 때만. 이번 수집은 `num_redirects=0` · 최종 URL 일치 · welfareList 1개로 확인했다.

## 8. 검증자가 봐야 할 지점

### ① 「글로벌&디지털 아카데미」 제외 — 이 파일에서 가장 다툴 만한 판단

원문은 「수준별 **외국어**/디지털 관련 교육과 다양한 **해외 연수** 프로그램을 **운영**하고 있습니다」다.

- **제외한 이유**: 문장의 동사가 「운영」이지 「지원」이 아니다. 같은 페이지에서 비용 지원을 명시한 세 항목(도서 구입비·취득 지원금·비용을 지원)과 문형이 명확히 다르다. 그리고 「아카데미」는 SFMI University 와 같은 **사내 교육 기관**인데, 둘 중 하나만 넣으면 자의적이다.
- **반대 논거**: 코퍼스 `lang`(어학) 은 42개사가 쓰는 큰 축이고, 현대건설의 `lang` 행(「어학교육 지원」)도 결국 회사가 제공하는 어학 과정이었다. 어학교육을 복지로 세는 것이 코퍼스 관행이라면 이 항목은 `lang` 1행이 되어야 하고, 그러면 총 **29행**이 된다.
- 판정이 뒤집히면 추가할 행은 정확히 하나다: `lang` / growth / SORT 64 / NM 「글로벌·디지털 아카데미」.

### ② 행 수 28 — 계약 목표 12~25 를 3행 초과

원문 30항목에 복합 라벨이 많아 생긴 결과지 억지로 늘린 것이 아니다(§2 수지표). 줄인다면 후보는 「사내 피트니스, 병원, 식당」 3행을 1행으로 되돌리는 것인데, `fitness`·`clinic`·`meal` 은 코퍼스에서 각각 46·22·71개사가 쓰는 별개 비교축이라 합치면 회사 간 비교가 무너진다. 「생활안정 지원」 3행도 같은 이유다. **분해를 유지하는 쪽을 권한다.**

### ③ `LOGO_NM='삼'` — 지시값과 코퍼스 관례 불일치

지시받은 값 그대로 넣었으나, 실측하면 113개사 중 **112개가 영문 이니셜**이고 한글은 효성중공업 「효」 1건뿐이다. 삼성 계열 7개사(삼성전자·삼성SDI·삼성물산·삼성바이오로직스·삼성생명·삼성전기·삼성카드)는 **전부 「S」**. 삼성화재만 「삼」이 되면 형제 법인과 배지 글자가 어긋난다. SQL 헤더에도 경고 주석을 남겼다 — 뒤집으려면 한 글자만 바꾸면 된다.

### ④ 참고 — `INDUSTRY_NM` 중복 없음

삼성생명이 이미 `'보험'` 을 쓰고 있어 삼성화재를 `'손해보험'` 으로 두면 두 법인이 업종으로 구분된다(지시값 그대로).
