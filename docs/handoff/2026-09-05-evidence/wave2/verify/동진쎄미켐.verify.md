## 수집기가 놓친 함정 (다음 웨이브에 남길 것)

1. 회사가 「복지」 페이지에 올렸다는 이유로 **급여성 수당(학위·자격 수당)** 을 복지 행으로 만들지 말 것 — 초임과 같은 급여 축이며, 코퍼스에 선례가 없어 신규 코드가 1개사 전용 열이 된다.
2. 이미지 출처(2019)와 텍스트 출처(2025)가 같은 법인이라도 **연도 표시를 행마다** 남긴 이번 방식이 정답 — 표시가 없으면 「주요 지역 무료 통근버스」 같은 옛 서술이 현재 사실로 굳는다.
3. `careerlink.kr` 계열 ATS 는 `__NEXT_DATA__` 경로가 페이지 배열 안에 있어 홈 JSON 하나로 전 페이지가 나온다 — 재수집기는 DOM 텍스트 0자를 「복지 없음」으로 오판하지 말 것.
