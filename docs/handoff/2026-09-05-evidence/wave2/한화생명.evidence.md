## 8. 배포 시 주의

- **신규 회사**이므로 `INSERT IGNORE INTO TCOMPANY` 가 실제 등록을 수행한다. 적재 후 **정적 페이지 재생성 필수**(회사 추가 시 상시 함정).
- **신규 BENEFIT_CD 0개** — 어휘 추가 작업 불필요.
- `db/seed/load.py` 의 `_split_sql_statements` 로 실제 분할을 돌려 **5문장으로 정상 분리**됨을 확인했다(주석·문자열에 ASCII 따옴표 0건).
- ⚠ **05 블록 원문은 「맘's 패키지」로 아포스트로피를 쓴다.** 분할기가 ASCII 따옴표를 문자열 경계로 보므로 SQL 안에서는 부호를 뺀 「맘s 패키지」로 적고, 그 사실을 헤더 주석과 QUAL_DESC 에 남겼다. 이 근거 문서에만 원문 표기를 그대로 보존한다.
- ⚠ **`INDUSTRY_NM='생명보험'` 은 팀 리드 지정값을 따랐다.** 다만 코퍼스의 가장 가까운 동종 회사 **삼성생명은 `'보험'`** 으로 등록돼 있고 DB손해보험도 `'보험'` 이다. 같은 업종이 두 라벨로 갈린다 — 디렉터리 업종 표시를 통일하려면 검증 단계에서 `'보험'` 으로 맞추거나 삼성생명 쪽을 나중에 세분화할지 결정해야 한다(이 파일만으로는 결정 불가라 지정값 유지).
- 재직인증 도메인은 등록하지 않는다(§1 이메일 관측 참조 — 관측값이 그룹 도메인 `hanwha.com` 하나뿐).
