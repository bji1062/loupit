### 법인 귀속 경로 (그룹 콘텐츠와의 분리 검증)

계약 §1 의 「그룹 공통이면 조건부」 조항을 실측으로 배제했다.

1. **호스트**: 그룹 공통 채용사이트가 아니라 **상장 법인 자기 도메인**이다. 페이지 푸터 `COPYRIGHT ISU PETASYS. ALL RIGHTS RESERVED.`, 본사 주소도 대구 달성(법인 일치).
2. **그룹 페이지와 항목이 다르다**: 그룹 사이트 `https://www.isu.co.kr/kor/recruit/recruit02.jsp` 의 복리후생은 **11개**뿐이고, 리드 문구가 *"이수그룹은 **각 사별로** 다양한 복리후생제도의 운영 및 제공을 통해서…"* 로 **각 사 운영을 명시**한다. 이수페타시스 페이지는 **25개**로 그룹 목록의 상위집합이며 문구도 다르다(그룹 `써클활동 운영 및 지원` ↔ 법인 `써클(동아리) 운영 및 지원`).
3. **다른 계열사는 이 경로가 없다**: `isuchemical.com` · `isuspecialtychemical.com` · `isusystem.com` · `abxis.com` 의 `/kor/recruit/recruit02.jsp` 는 전부 **404**. 즉 공통 템플릿이 뿌려진 것이 아니라 이 법인만 게시한다.
4. 법인 고유 항목 14개가 **대구 달성 생산법인의 현장 복지**와 맞물린다(기숙사 제공, 통근버스 운행, 구내식당, 휴게실·샤워실·회의실, 통신비 지원 등).

⚠ 단 하나의 약점: 복리후생 페이지 **리드 문장은 `이수그룹은 …` 이라는 그룹 화법**이다(형제 페이지 `recruit01.jsp` 인재상은 실제로 "이수그룹의 인재상"이라 항목 0). 리드 문장만 보면 그룹 보일러플레이트로 오독할 수 있으나, 위 2·3번(항목 집합 상이 + 타 계열사 404)이 법인 귀속을 결정한다. **출처 표기는 법인 도메인 URL 로 하되, 리드 문장은 인용하지 말 것.**

## ③ robots 허용 — **전면 허용, AI 봇 차단 없음**

`https://www.petasys.com/robots.txt` (HTTP 200, **21 bytes**):

```
User-agent: *
Allow:/
```

- 그룹이 `*` 하나뿐 → ClaudeBot·anthropic-ai·GPTBot·CCBot·Google-Extended **개별 차단 규칙 없음**(네패스 선례 해당 없음). `/kor/recruit/*` 허용.
- **BOM 없음**(선두 바이트 `55 73 65` = `Use`). `Allow:/` 는 콜론 뒤 공백이 없는 비표준 표기지만 파서 대부분이 허용으로 읽는다. Crawl-delay·Sitemap 지시 없음.
- 실측 교차검증: 위 AI 봇 UA 5종으로 복리후생 페이지를 직접 호출 → **전부 HTTP 200, 38,237 B, 항목 25개 그대로**. UA 기반 차별 응답 없음.
- ⚠ **`sitemap.xml` 을 발견 경로로 쓰지 말 것**: `https://www.petasys.com/sitemap.xml` 은 200(48,391 B)이지만 **`https://www.isu.co.kr/sitemap.xml` 과 바이트 동일**하고, 내부 `<loc>` 은 전부 `const.isu.co.kr`(110) · `recruit.isu.co.kr`(106+6) · `www.isu.co.kr`(40)이다. **petasys URL 은 0건.** 그룹 사이트맵이 잘못 배포된 것으로, 이걸 따라가면 타 법인 페이지로 새어나간다.

## 수집 설계 시 유의 (수집·SQL은 이번 범위 밖)

1. **apex 금지**: `petasys.com` 은 NXDOMAIN 이라 리다이렉트조차 없다. 수집기 URL 은 반드시 `https://www.petasys.com/kor/recruit/recruit02.jsp` 로 고정한다. `isupetasys.com` 을 대체 도메인으로 넣지 말 것(죽은 호스트).
2. **sitemap.xml 은 그룹 것이다**: 발견 로직이 sitemap 을 따르면 `isu.co.kr`·`const.isu.co.kr`(이수건설) 로 새어나가 **법인 불일치 오염**을 만든다. 이 회사는 경로 하드코딩으로 수집한다.
3. **리드 문장을 본문에 넣지 말 것**: `이수그룹은 …` 그룹 화법이라 법인 카드에 붙으면 귀속이 흐려진다. 항목 25개만 취한다. 형제 페이지 `recruit01.jsp`(인재상)는 순수 그룹 콘텐츠이므로 **수집 대상에서 제외**.
4. **항목명만 있고 설명·금액이 없다**(심텍과 동일). 본문 분량 기여는 작으니 콘텐츠 두께 개선 기대치는 낮게 잡는다. 특히 `주택자금대출` 은 한도·금액이 전혀 없으므로 **정성 항목**으로 넣는다(연간 환산 칸 금지 — CJ 5개사 선례 #38).
5. **갱신 감지**: URL 이 `recruit02.jsp` 고정이라 변경이 URL 에 드러나지 않는다. `<li>` 항목 집합의 해시로 비교한다. TLS 는 2027-01-14 만료이므로 그 이후 재수집 시 검증 실패 여부를 확인한다.
