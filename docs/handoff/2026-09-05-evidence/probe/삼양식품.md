## ③ robots — **호스트마다 정반대. `www` 허용 / `m` 전면 금지**

`https://www.samyangfoods.com/robots.txt` (HTTP 200, 89 bytes, **BOM 없음**):

```
User-agent: *
Allow: /

# Sitemap files
Sitemap: http://www.samyangfood.co.kr/sitemap.xml
```

- Disallow 없음, Crawl-delay 없음. `/kor/recruit/*`·`/asset/images/*` 모두 허용.
- **AI 봇 전용 그룹 없음** → ClaudeBot·anthropic-ai·GPTBot·CCBot·Google-Extended 전부 `*` 규칙 적용 = 허용.
- ⚠ Sitemap 지시가 **다른 도메인**(`samyangfood.co.kr`, 's' 없는 오타 도메인)을 가리키고 그마저 **404**다. `https://www.samyangfoods.com/sitemap.xml` 도 404. **사이트맵으로 경로를 못 찾는다.**

`https://m.samyangfoods.com/robots.txt` (HTTP 200, 27 bytes, BOM 없음):

```
User-Agent : *
Disallow : /
```

- 콜론 앞뒤에 공백이 붙은 비표준 표기지만 관용 파서는 그대로 해석한다. **보수적으로 전면 금지로 본다** → 모바일 호스트 본문 수집 금지.
- `https://samyangfoods.co.kr/robots.txt`(온라인몰)는 `Disallow: /search`, `/goods/search`뿐이나 애초에 출처가 아니다.

## 수집 설계 시 유의 (수집·SQL은 이번 범위 밖)

1. **HTML 스크래핑만 돌리면 0건**이다. `www` 의 항목 10개는 전부 `recruit_img04.png` 안이고 `alt` 도 비어 있다. 이미지 판독이 유일한 허용 경로이며, "복지 미기재 회사"로 오판하지 말 것.
2. **모바일 호스트를 쓰지 마라.** 텍스트가 있어서 유혹적이지만 `m.samyangfoods.com` 은 `Disallow: /` 다. 헤드리스 렌더를 쓸 경우 페이지 스크립트가 모바일 UA 를 그쪽으로 밀어내므로 **데스크톱 UA 고정 + 리다이렉트 차단**이 필요하다.
3. **UA 를 잘못 잡으면 200 짜리 352바이트 차단문을 본문으로 저장한다.** 수집기 UA 에 `curl`·`GPTBot`·`CCBot` 문자열이 들어가면 안 되고, 응답 크기 <2KB 또는 `Request Blocked` 키워드 가드를 반드시 걸어야 한다. 생존확인은 **HEAD 금지, GET 로만**(HEAD 는 404).
4. **10개 중 2개(`4대보험`, `퇴직금`)는 법정 제도**라 우리 규칙상 미수록 대상이다. 실적재 항목은 사실상 **8개**로 잡아야 하고, 금액 명시가 0건이라 `신협 대출 지원`·경조금류는 전부 **정성 항목**이다(연간 환산 칸에 넣지 말 것 — CJ 주택자금 선례).
5. **콘텐츠 신선도 경고**: 채용공고 게시판의 유일한 글이 2019년 공고(채용 완료)다. 복지 이미지도 갱신이 오래된 것으로 보이며, 이미지 파일명이 콘텐츠 해시가 아니라 `recruit_img04.png` 고정이므로 **갱신 감지는 URL 이 아니라 바이트 해시**로 해야 한다. TLS 인증서는 2026-11-13 만료 → 이후 재수집 시 검증 실패 여부 확인.
