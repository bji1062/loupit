### ⚠ 도메인 함정 (DART hm_url 오염 변종)

추정 도메인 `celltrionph.co.kr` 과 `celltrionpharm.com` 은 **살아 있지만 리다이렉트 껍데기**다. 그리고 껍데기가 차단처럼 보인다.

| 호스트 | 443 | 80 | 실체 |
|---|---|---|---|
| `celltrionph.co.kr` / `www.` | **연결 타임아웃 (TCP filtered)** | 200, 201 bytes | `<meta http-equiv="refresh">` → `https://www.celltrionph.com/` |
| `celltrionpharm.com` / `www.` | 연결 타임아웃 | 200, 199 bytes | meta refresh → `http://www.celltrionph.com/` |
| **`celltrionph.com` / `www.`** | **정상 200** | — | 진짜 사이트 (Azure Front Door) |

- `.co.kr` 의 80포트 `/robots.txt` 는 Spring Boot 가 `{"status":403,"error":"Forbidden","message":"Access Denied"}` 를 뱉는다. **이건 우리를 막은 게 아니라 껍데기 앱에 그 라우트가 없어서 나오는 403**이다. 이걸 보고 "봇 차단"으로 판정하면 오진이다.
- 443 타임아웃 + 403 JSON 조합이 전형적인 오판 유도 패턴이다. 반드시 80포트 meta refresh 를 따라가 실도메인을 확인할 것.

## 수집 설계 시 유의 (수집·SQL은 이번 범위 밖)

1. **도메인을 `celltrionph.com` 으로 고정하라.** `celltrionph.co.kr`·`celltrionpharm.com` 은 443이 막힌 리다이렉트 껍데기이고 80포트에서 403 JSON 을 뱉어 차단으로 오독되기 쉽다. 출처 URL 에 `.co.kr` 이 들어가면 재수집 때 통째로 실패한다.
2. **파싱 범위를 `.welfare_cont` 로 좁혀라.** 페이지 전체 `<dd>` 를 세면 스킵내비 3개가 섞여 20건이 된다. 정답은 17.
3. **금액이 0건이므로 전부 정성 항목으로 넣어야 한다.** CJ 5개사 주택자금 사례처럼 없는 수치를 연간 환산 칸에 만들어 넣지 말 것. "포인트 지급 (생일포인트, 복지포인트)"도 액수 미기재다.
4. **공백 정리 필요**: `새벽 및 심야 출/퇴근 택시 지원 ` 처럼 뒤에 공백이 붙은 `<dd>` 가 있다. trim 없이 넣으면 중복 판정·정렬이 어긋난다. 슬래시(`/`)가 포함된 항목명이 있으니 구분자로 `/` 를 쓰는 파이프라인은 피할 것.
5. **모회사 셀트리온과 섞지 마라.** 이미 등록된 셀트리온(celltrion.com)과는 도메인·법인·항목이 모두 다르다. 본문에 "셀트리온제약의"·"Celltrion Pharm employees" 가 박혀 있어 귀속 근거는 페이지 자체로 충분하다.
6. 항목이 라벨뿐이라 **본문 분량 기여는 약 300자 수준**이다. 콘텐츠 두께 개선 기여는 낮게 잡을 것.
7. 갱신 감지: sitemap·robots 가 없어 lastmod 신호가 없다. `.welfare_cont` 블록 해시로 비교해야 한다. TLS 는 2027-02-24 만료 예정.
