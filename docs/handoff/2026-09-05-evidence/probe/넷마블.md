## ③ robots 허용 — **전면 허용, AI 봇 명시 차단 없음**

`https://company.netmarble.com/robots.txt` (HTTP 200, 23 bytes) 및 `https://career.netmarble.com/robots.txt` (HTTP 200, 23 bytes) — **두 파일 내용 동일**:

```
User-agent: *
Allow: /
```

- Disallow 없음, Crawl-delay 없음, Sitemap 지시 없음. **BOM 없음**(선두 바이트 `55 73 65 72` = `User`).
- `ClaudeBot`·`anthropic-ai`·`GPTBot`·`CCBot`·`Google-Extended` 를 겨냥한 그룹이 **파일에 아예 없다** → 전부 `*` 그룹 적용 = 허용.
- 실제 UA 시험에서도 차단 없음: `ClaudeBot/1.0`·`GPTBot/1.2`·`CCBot/2.0`·`curl/8.5.0` 모두 **200**, 본문 크기 브라우저 UA 와 동일(18,394 / 38,348 bytes).
- ⚠ **`www.netmarble.com/robots.txt` 는 robots.txt 가 아니다.** 게임 포털 SPA 가 `robots` 를 언어 세그먼트로 먹어
  HTTP 200 + 4,465 bytes 의 **HTML 셸**(`var LANG = "robots";`)을 돌려준다. 전형적 soft-404 다.
  이걸 robots 로 파싱하면 규칙 0개로 읽혀 우연히 「허용」이 되지만, **근거로 삼으면 안 된다**. 정본 호스트의 robots 를 따로 봐야 한다.
- `company.netmarble.com/sitemap.xml` → **404**(14,821 bytes 짜리 HTML 오류 페이지 = soft-404). 사이트맵 경로는 `/etc/sitemap`(HTML).

## 수집 설계 시 유의 (수집·SQL은 이번 범위 밖)

1. **정본은 `company.netmarble.com/hr/system` 한 곳으로 고정한다.** 15개 항목이 `<dl>/<dt>/<dd>` 로 깔끔해
   파서 한 벌이면 끝난다. 헤드리스도, 이미지 판독도 필요 없다.
2. ⚠ **복리후생 탭은 CSS 로 숨겨져 있다.** `<div class="hr_cnt hr_cnt2">` 에 `style="display:block"` 이 없어
   **헤드리스 브라우저로 「보이는 텍스트」만 긁으면 15개가 통째로 사라진다.** 심텍과 정반대 함정이다 —
   여기서는 `curl` + 원본 HTML 파싱이 정답이고 렌더링이 오히려 손해다.
3. **`career.netmarble.com` 을 넷마블(주) 카드에 그대로 붙이지 마라.** 「넷마블컴퍼니 채용」은 넷마블네오·엔투·넥서스 등
   별개 법인을 포괄한다(처리방침의 법인별 책임자 목록이 근거). 붙이면 하나금융지주 사례와 같은 법인 불일치 = 배지 계보 오염이다.
   금액 정보(복지포인트 250만원·식대 20만원)가 탐나더라도, 쓰려면 출처 표기에 **「넷마블컴퍼니 공통」** 을 명시하고
   조건부로만 채택해야 한다.
4. ⚠ 보조 출처를 쓸 경우 **주석 제거를 파싱 전에** 해라. `ㅋㅋ프렌즈스토어 및 관계사 상품 할인` 이 주석 속 유령이고,
   Pride 섹션은 항목 0개라 카테고리 3개로 세면 빈 칸이 생긴다.
5. **HEAD 로 생존 확인하지 마라.** 정본 URL 은 HEAD 에 **405** 를 준다. 죽은 링크로 오판하기 딱 좋다 — GET 으로 판정할 것.
6. TLS 인증서가 **2027-01-17 만료** → 이후 재수집 시 검증 실패 가능성 점검. 갱신 감지는 `/hr/system` 본문 해시로 건다.
