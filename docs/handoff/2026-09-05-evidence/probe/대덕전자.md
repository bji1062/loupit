## ① 공식 채용/복지 페이지 URL (공식 도메인만)

공식 도메인 `www.daeduck.com` 의 RECRUIT 섹션 4개 페이지 확인:

| 용도 | URL | HTTP |
|---|---|---|
| **복지제도 (정본)** | `https://www.daeduck.com/ko/content/welfaresystem.do` | 200 · 95,096 B |
| 인사제도 (교육 지원 제도 — 보조 출처) | `https://www.daeduck.com/ko/content/personnelsystem.do` | 200 · 96,155 B |
| 채용정보 | `https://www.daeduck.com/ko/content/recruitmentinfo.do` | 200 · 97,645 B |
| 인재상 | `https://www.daeduck.com/ko/content/talenttype.do` | 200 · 90,408 B |

**법인 귀속 근거 (지주 ≠ 사업회사 확인 완료)**

- `www.daeduck.com` 푸터: `본사주소 : (우)15602 경기도 안산시 단원구 강촌로230 (목내동 475) 대덕전자(주)` / `Copyright© DAEDUCK ELECTRONICS Co.,Ltd.` / `og:title = 대덕전자`.
- 같은 푸터의 「관련기관사이트」 드롭다운에 **㈜대덕 → `http://www.daeduckholdings.com` 외부 링크**가 따로 있다. 즉 지주와 사업회사가 도메인 단위로 분리돼 있어 **공용 사이트가 아니다**.
- 확인차 `www.daeduckholdings.com` 도 받아봤다(HTTP 200, 23.9KB, `<title>HOME | DAEDUCK</title>`). **채용·복지 메뉴가 아예 없다.** 지주 복지가 섞여 들어올 경로 자체가 없음.
- ⚠ 다만 복지 페이지 **본문 카피는 "대덕은 …" 이라는 그룹 브랜드 표기**를 쓴다(법인명 "대덕전자" 가 아님). 문구만 보면 지주 것으로 오해할 수 있으나, 도메인·푸터·저작권·분리된 지주 사이트 3중으로 **대덕전자 귀속이 확정**된다. 인사제도 페이지는 본문에서 "대덕전자는 …" 이라고 법인명을 직접 쓴다.
- 별도 채용 전용 서브도메인 없음. `recruit.daeduck.com` 은 DNS 는 뜨지만 **모든 경로 HTTP 404**(빈 응답) — 죽은 호스트다. 3자 사이트(사람인·잡코리아 등)는 출처로 채택하지 않음.

## ② 복지 항목 명시 여부 — **명시됨, 18개 항목 / 5개 카테고리 (전부 HTML 텍스트)**

카테고리마다 아이콘 PNG 1장 + `h4` 카테고리명 + `p.sub` 한 문장 설명 + `ul.info > li` 항목 목록 구조.

| 카테고리 | 항목 수 | 항목명 |
|---|---|---|
| 주거 지원 | 3 | 주택 구입자금 대출, 생활 안정자금 대출, 주거 지원 운영 (사택, 기숙사) |
| 건강관리 | 3 | 종합건강검진(배우자포함), 단체상해 보험, 의료비 지원 |
| 교육비(학자금) 지원 | 2 | 자녀 학자금 지원, 자기 계발비 지원 |
| 워라밸 | 5 | 자율출퇴근제 운영, 연중휴가 및 휴가비 지원, 동호회 지원, 콘도 지원, 복지 포인트 지급 |
| 기타 | 5 | 기념일 선물 지급, 퇴직연금(IRP) 지원, 경조사 지원, 사내식당 운영, 장기근속자 포상 |
| **계** | **18** | |

**예시 2개**: `종합건강검진(배우자포함)`(건강관리), `자율출퇴근제 운영`(워라밸).

- **금액 명시 없음.** 18개 전부 항목명만 있고 금액·한도·대상·조건 수치가 하나도 없다. 대출 2건(주택 구입자금·생활 안정자금)도 한도 미기재.
- 카테고리 설명 문장 5개는 있으나 **항목별 설명은 없다**(라벨만).
- 보조 출처 — 인사제도 페이지 「교육 지원 제도」: 리드 문구가 `대덕전자는 다양한 복리후생 프로그램을 운영하고 있습니다` 이고, **항목 5개에 각각 1~2문장 설명이 붙는다**(기본소양교육 / 직무·역량 교육 / 외국어 교육 지원 / 임원역량 강화교육 / 인턴십 프로그램). 복지로 볼지 교육으로 볼지는 편성 판단이지만, **설명 문장이 있는 유일한 블록**이라 본문 분량 기여는 여기가 크다.
- 인재상 페이지는 항목 0개(가치관 서술) — 수집 대상 아님.
- ⚠ 이미지 안 항목 **없음**. 같은 업종 선례인 심텍(항목 16개가 전부 PNG 안)과 정반대다. 본문의 `rec05_01~05.png` 5장은 카테고리 아이콘일 뿐이고 `alt` 도 비어 있다 — **이미지 판독 단계 불필요**.
- ⚠ HTML 주석 79개를 전수 확인했으나 **주석 속 유령 복지 항목 0건**.

## ③ robots 허용 — **전면 허용 (robots.txt 부재)**

| 호스트 | robots.txt | 판정 |
|---|---|---|
| `www.daeduck.com` | **HTTP 404** (Spring Boot JSON 오류 본문 99 B) | 명시적 금지 없음 = 허용 |
| `daeduck.com` (apex) | 연결 타임아웃(20s) | — apex 자체가 죽음, ④ 참조 |

- `robots.txt` 가 없으므로 `*` 도, AI 봇 UA(ClaudeBot·anthropic-ai·GPTBot·CCBot·Google-Extended)도 **경로 제한 없음**. BOM 이슈 해당 없음(파일 자체가 없음).
- `https://www.daeduck.com/sitemap.xml` → **404**. 사이트맵 없음, robots 의 Sitemap 지시도 없음(robots 부재).
- **UA 차단 실측**: 복지 페이지를 ClaudeBot / GPTBot / CCBot / `curl/8.5.0` UA 로 각각 받아 **4건 모두 HTTP 200, 본문 95,096 B 로 일반 브라우저 UA 와 바이트 단위 동일**. 서버단 AI 봇 UA 차단 없음.

## 수집 설계 시 유의 (수집·SQL은 이번 범위 밖)

1. **호스트를 `www.daeduck.com` 으로 고정**하라. apex 타임아웃 · `daeduck.co.kr` 유령 frameset · `recruit.daeduck.com` 404 까지 오답 도메인이 3개나 붙어 있다. DART `hm_url` 이 어느 쪽을 들고 있는지 확인 후 필요하면 교정.
2. **금액 0건 → 18개 전부 정성 항목**으로 코딩한다. 특히 `주택 구입자금 대출`·`생활 안정자금 대출` 은 한도조차 없으니 **연간 환산 칸에 넣지 말 것**(CJ 5개사에서 대출 원금 한도를 환산 칸에 넣었다가 되돌린 선례 #38 과 같은 함정).
3. 본문 분량 기여는 항목 라벨만으로는 작다. **인사제도 페이지의 「교육 지원 제도」 5항목(설명 문장 포함)을 같이 뜨는 게 실익**이다. 단 이 5개는 교육 카테고리로, 복지제도 18개와 **출처 URL 을 구분해 기록**해야 한다(두 페이지가 다른 URL).
4. 카피가 `대덕은 …` 이라 **문자열만 보고 지주(㈜대덕)로 귀속하면 오염**된다. 귀속 근거는 도메인+푸터 저작권이며, 지주는 `daeduckholdings.com` 으로 완전히 분리돼 있다(그쪽엔 복지 페이지 없음). 지주 008060 을 별도 등록할 계획이면 **복지 0건**으로 잡아야 한다.
5. 갱신 감지는 `welfaresystem.do` 본문 해시로. 항목이 `<li class="on">` 고정 클래스라 파서는 `ul.info` 기준으로 짜고, 카테고리 `h4` 를 함께 잡아 5분류를 보존할 것. TLS 는 2027-01-11 만료 — 그 이후 재수집 시 검증 실패 여부 확인.
