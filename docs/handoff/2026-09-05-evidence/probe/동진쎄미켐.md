## 수집 설계 시 유의 (수집·SQL은 이번 범위 밖)

1. **정본은 A(`careerlink/welfare`) 로 잡아라.** 텍스트 JSON이라 판독 오차가 없고, 금액(초임 5,040/4,100만원)·사업장 한정(화성·시화·음성) 같은 **검증 가능한 값**이 들어 있다. 수집 경로는 `__NEXT_DATA__` → `props` 하위 페이지 배열에서 `path=="welfare"` → `sections[].blocks[].settings[]` 의 `heading`/`body`(RICHTEXT, HTML 이스케이프 `<` 형태). 홈(`/`)의 JSON에도 **전 페이지가 통째로 들어 있어** `/welfare` 를 따로 안 받아도 된다.
2. **두 출처가 충돌한다 — 합치지 말고 하나를 고르라.** B(이미지)는 "통근버스를 주요 지역에 무료 운영·기숙사는 주요 사업장마다"라고 하고, A는 "셔틀버스는 경기 화성 사업장만 + 유류비·통행료 지원·기숙사는 화성/시화/음성"이라고 한다. B 푸터는 `COPYRIGHT © 2019`, A 는 2025년 개설(`coNo CO202504082484`) → **A가 신본**. B만 있는 항목(사내 휘트니스센터, 사내동호회, 원가혁신과제 포상, 직무발명 최대 1,000만원)을 살리려면 **출처를 항목 단위로 분리 표기**해야 한다.
3. **B 를 쓸 거면 이미지 판독이 유일한 경로이고, 그 전에 `link.js` 파싱이 먼저다.** GNB가 전부 `javascript:linkXXXX()` 라 링크 그래프 크롤링으로는 `/recruit/hr02.php?pNum=1` 에 영영 도달하지 못한다. 또 `hr02.php` GNB에는 「입사지원」·「채용문의」가 **HTML 주석으로 죽어 있는데** `/main/` 의 GNB에는 살아 있다 — 페이지마다 메뉴가 달라서, 주석을 걷지 않고 파싱하면 유령 메뉴를 줍는다.
4. **CCBot 디코이 302 를 밟지 마라.** UA에 `CCBot` 이 있으면 `kuipernet.com/images/bg.png` 로 보내는데, `-L` 로 따라가면 PNG 바이트를 HTML 로 파싱해 **에러 없이 0건**이 된다. 우리 UA에는 해당 문자열이 없으니 현재는 안전하지만, 재수집기가 UA를 바꾸면 조용히 깨진다. ClaudeBot·anthropic-ai·GPTBot·Google-Extended 는 실측 200.
5. **탭 4개는 URL이 같고 쿼리만 다르다**(`hr02.php?pNum=0~3`). 서버는 `pNum` 과 무관하게 **동일한 11,693B HTML(이미지 4장 전부)** 을 돌려주고 탭 전환은 CSS/JS다 → `pNum=1` 을 받아도 복지 이미지만 따로 오지 않는다. 이미지 파일명이 콘텐츠 해시가 아니라 고정이라 **갱신 감지는 바이트 해시**로.
6. TLS 만료: `*.dongjin.com` 2026-12-05. 그 이후 재수집 시 검증 실패 여부 확인.
