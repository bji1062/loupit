## ③ robots 허용 — **양 도메인 모두 허용, AI 봇 명시 차단 없음**

| 도메인 | robots.txt | 판정 |
|---|---|---|
| `www.samsungfire.com` | HTTP 200, 23 bytes, `User-agent: *` / `Allow: /`. **BOM 없음**(`55 73 65` = "Use"). Disallow·Crawl-delay·Sitemap 지시 전무 | 전면 허용 |
| `www.samsungcareers.com` | **robots.txt 부재.** `/robots.txt` → 302 → `/sub/etc/error.html`. apex 는 301 → www 후 동일. `sitemap.xml` 도 동일하게 302 | 명시적 금지 없음 = 기본 허용 |

- AI 봇 UA(ClaudeBot·GPTBot·CCBot·Google-Extended) 를 **개별 차단하는 지시가 어느 쪽에도 없다**. 네패스식 AI 봇 선별 차단 사례 아님.
- 실측으로도 확인: ClaudeBot / GPTBot / CCBot / Googlebot / `curl/8.5.0` / `python-requests` **6종 전부 HTTP 200, 본문 102,890 bytes 동일, 복지 30항목 그대로**. UA 기반 차단·차등 응답 없음.

## 수집 설계 시 유의 (수집·SQL은 이번 범위 밖)

1. **정규식으로 파싱하면 항목명 2개가 깨진다.** `data-tip` 속성값 안에 이스케이프되지 않은 꺾쇠가 들어 있다 — `data-tip="… 모바일 학습플랫폼 <Dream Campus+>을 운영하고 있습니다."` 와 `… 가능한 <선택적 근로시간제>를 운영하고 있습니다."`. 정규식 태그 제거로 뽑으면 항목명이 `을 운영하고 있습니다."> Dream Campus+` 같은 쓰레기가 된다. **실측: BeautifulSoup `html.parser` 는 30개를 전부 정상 복원**하므로 반드시 진짜 HTML 파서를 쓸 것. 설명문은 `data-tip` 이 아니라 **자식 `<span>`** 에서 가져오면 이 오염을 우회할 수 있다.
2. **출처 도메인이 자기 도메인이 아니다.** 정본은 `samsungcareers.com`(그룹 공통 채용사이트)이며 `samsungfire.com` 에는 복지 페이지가 아예 없다. 출처 표기에 이 사실을 남기고, 「법인 전용 페이지 `/subsid/detail/E21`」임을 함께 적어 하나금융지주식 법인 불일치 오염과 구분해야 한다.
3. **그룹 공통 `/insight/welfare` 와 절대 섞지 말 것.** 그쪽 17항목은 관계사 구분이 없는 삼성 전체 서술이고(주재원·지역전문가·사내 창업 지원 등), 삼성화재 카드에 붙이면 없는 제도를 만들어낸다. 사이트 스스로 "관계사별 복지 제도는 각 회사별 페이지에서" 라고 분리해 두었다.
4. **URL 안정성은 관계사 코드에 달려 있다.** 삼성화재 = `E21`(삼성생명 E11, 삼성카드 E31, 삼성증권 E40). 페이지에 `<link rel="canonical">`·`og:url` 이 없고 모든 관계사 페이지의 `<title>` 이 똑같이 `SAMSUNG CAREERS` 라 **제목으로는 법인을 식별할 수 없다**. 갱신 감지는 URL 이 아니라 복지 섹션(`ul.welfareList`) 바이트 해시로 하고, 파싱 시 `<h2>` 에 `삼성화재` 가 들어있는지 법인 검증을 넣을 것.
5. **soft-404 주의.** samsungcareers.com 은 없는 경로를 404 가 아니라 **302 → `/sub/etc/error.html`** 로 흘리고, 그 최종 응답은 HTTP 200 에 `{"code":500,"status":999}` 본문이다. 리다이렉트를 따라가면 "성공"으로 보이므로, 수집기는 최종 URL 이 `/subsid/detail/E21` 인지와 `welfareList` 존재 여부로 판정해야 한다.
6. CDN 인증서가 **2026-11-09 만료** → 그 이후 재수집 시 검증 실패 가능성 확인. 항목 설명이 한 줄씩 붙어 있어 본문 분량 기여는 심텍보다 크다(30항목 × 설명문).
