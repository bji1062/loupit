# 웨이브 2 적대 검증 계약 (W-2) — 2026-09-05

목적: 수집 산출물(시드 SQL + evidence)을 **독립 재수집으로 반증**한다. 수집기가 옳다고 가정하지 않는다. 회사 간 비교축(BENEFIT_CD 의미)을 망치는 행 하나가 통계 전체를 오염시키므로, 「그럴듯함」이 아니라 「원문이 그렇게 말하는가」만 본다.
**리포 읽기 전용 · DB 접속 금지.** 산출물: `…/scratchpad/wave2/verify/<회사>.verify.md`.

## 입력 (회사마다)
`…/scratchpad/wave2/<회사>.sql` · `<회사>.evidence.md` · 프로브 `docs/handoff/2026-09-05-evidence/probe/<회사>.md` · 수집 계약 `docs/handoff/2026-09-05-evidence/_COLLECT-CONTRACT.md`(규칙 1~9) · 어휘표 `_VOCAB.md`.

## 절차
1. **evidence 를 읽기 전에** 프로브의 정본 URL 을 직접 가져와 **독립 항목 목록**을 만든다(이미지면 직접 판독, `__NEXT_DATA__`/번들이면 직접 추적, CSR 이면 Playwright). UA 는 일반 브라우저 문자열, 요청 간 ≥1초, 회사당 ≤40회.
2. 그 다음 SQL 행 하나하나를 독립 목록·원문과 대조해 판정한다:
   - **CONFIRMED** 원문이 그 행을 그 코드·그 조건으로 뒷받침한다.
   - **SUSPECT** 원문은 있으나 코드 선택·조건·귀속·금액이 의심스럽다(검수자 결정 필요) — 이유와 대안을 적는다.
   - **REFUTED** 원문이 없거나 반대로 말한다(유령·오독·다른 법인·임원 한정·법정 제도·커리큘럼).
   - **MISSED** 원문엔 명시적 제도가 있는데 행이 없다. 단 계약 규칙 3(법정)·8(커리큘럼)·9(억지 확장 금지)로 뺀 것이 정당하면 MISSED 가 아니다 — evidence 의 제외 목록과 대조.
3. 특히 공격할 지점: (a) **법인 귀속** — 다른 법인·그룹 공통·부문·자회사·임원/연구위원 한정, 「(그룹 통합/컴퍼니 공통 기준)」 각주 누락 (b) **법정 제도 혼입** — 4대보험·퇴직연금·법정 연차·법정 육아휴직 (c) **어휘 오염** — 코드 뜻과 다른 행(어휘표의 대표 명칭·카테고리와 대조; `family_day`=조기퇴근·`long_service_leave`=휴가·`work_tools`=IT장비·`insurance`=단체상해·`uniform`=근무복 등) (d) **금액** — 원문 명시 아닌 AMT, 연환산 오류(월×12), 대출 한도·비율·상한·1회성을 AMT 에 넣은 것, 급여(초임)를 복지로 (e) **유령 항목** — HTML 주석·샘플 템플릿·모바일/구본 잔재·캐러셀 중복 (f) 병합·분리 — 같은 코드 2행(UNIQUE 위반) 또는 다른 제도 억지 병합 (g) **등록 INSERT** — COMP_NM·COMP_TP_CD·INDUSTRY_NM·slug 가 지시와 같은가, `grep -h "VALUES ('" db/seed/benefit/sql/*.sql` 로 slug 충돌 0 인가 (h) **SQL 형식** — 주석·문자열 홑/겹따옴표, 카테고리 값 9종 밖, SORT 중복, `python3 -c "from db.seed.load import _split_sql_statements"` 식으로 실제 분할기가 문장 수를 제대로 세는지(파일 전체가 1문장이면 따옴표 사고).
4. 3자 사이트(사람인·잡코리아·잡플래닛·캐치·인크루트·블라인드·원티드) 인용 0건 확인. 검색엔진 스니펫 인용도 0건.

## 보고 형식 (`<회사>.verify.md`)
- 상단: **요약 표** `CONFIRMED n / SUSPECT n / REFUTED n / MISSED n` + 한 줄 결론(반영 가능 / 조치 후 반영 / 재수집).
- **독립 목록**(내가 직접 본 항목 n개, 출처 URL·렌더 방식·해시).
- **행별 표**: SORT · 코드 · 판정 · 근거 원문(인용) · 조치 권고(유지 / 삭제 / 재코딩→코드 / 병합 / 각주 추가 / AMT NULL).
- **MISSED 표**: 원문 항목 · 권고 코드 · 수집기 제외 사유 타당성.
- 마지막: **수집기가 놓친 함정**(재수집·다음 웨이브에 남길 것) 3줄 이내.
