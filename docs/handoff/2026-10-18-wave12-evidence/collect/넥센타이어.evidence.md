## 3. 코드 판단

- 20 `leave_general`: 「반반차 휴가 제도(하루 연차를 2시간 단위)」 = 어휘 경계 「2시간 단위 휴가(반반차 · 회사가 밝힌 시간 단위)」 — 법정 아님.
- 21 `summer_leave` / 30 `summer_vacation_subsidy`: 한 문장 「유급 휴가를 제공하며, 휴가비도 함께 지원」 → 휴가 · 현금 두 행. 휴가 일수 · 연차 사용일인지 원문에 없음(꼬리).
- 43 `medical`: 협약병원 = 코퍼스 선례 1(`'medical', '협약 병원 진료비 감면'` — 이번 세션 grep). 보고서 109쪽 운용 현황 「의료비 지원」은 지출 0 이 아닌 지표 표 이름(3-12 「지급 0」 아님) → 같은 행.
- 45 `mental`: EAP 가 인권경영 표 「감정노동 근로자 보호」 칸에 있음 — 판단 요청 3.
- 53 `welfare_point`: 「생일자에게 포인트」는 복지 사이트 포인트 지급 시기의 하나라 `birthday_gift` 로 가르지 않음(어휘 「welfare_point = 연간 배정 복지포인트(지급 시기가 명절이어도)」). 봉사활동 복지포인트도 같은 포인트라 같은 행.
- 54 `discount`: 자사 타이어 무상 제공 = 「자사 제품」 급부. 코퍼스 선례 `'discount', '자사 타이어 할인'`(한국타이어) · `'discount', '타이어 할인쿠폰'`(금호타이어) — 이번 세션 grep.
- 55 `relocation` + 90 `dormitory`: 한 줄 「근무지가 변경 시, 사원 임대 아파트 제공 또는 임차보증금 지원」을 시설(사원 아파트 = `dormitory`) · 발령 주거 지원(임차보증금 = `relocation` — 어휘 「발령 주거 지원 · housing_loan 에 넣지 않는다」)으로 두 행. 각 행은 자기 몫만, 조건 「근무지 변경 시」는 둘 다 이름에.
- 56 `housing_loan`: 공시 「주택자금 등을 대여」 = 용도가 주택 자금인 회사 대여 → `housing_loan`(원문 낱말 「대여」 그대로 · 「대출」 낱말 안 씀).
- 62 `child_edu` / 63 `parenting`: 한 문장 「육아 보육 보조비 및 자녀의 고등학교, 대학교 학자금」 → 어휘 「유아교육비 · 보육비와 한 줄이어도 가른다」대로 보육 보조비 = `parenting`, 학자금 = `child_edu`.
- 70 `excellence_award`: 퍼플 어워즈(시상) + 퍼플 포인트(동료 칭찬 포인트 선물) = 「동료 추천상 류」.
- 71 `stock_grant`: 반기보고서가 「직원에게 지급」 · 「직원 격려금 관련 자기주식 처분」이라 밝힘. 처분 주식 수 · 총액은 금액이 아님.
- 80 `edu_support` / 81 `self_development`: 한 문장 「사내 강연, 외부 교육비 지원, 자기개발비」 → 강연 · 사외 교육비 = `edu_support`, 자기개발비 = `self_development`. 「사내외 전문역량 교육」(직무 역량 강화)은 업무 교육이라 뺌.
- 83 `mba`: 서울디지털대학교(사이버대학) 학위 = 코퍼스 선례 `'mba', '사이버대학교 지원'`(이번 세션 grep) · 계약 3-9 「학위 = mba」. 「상급학교 학비 → self_development」 규칙과 갈릴 수 있음 — 판단 요청 4.
- 84 `career`: N’Career Challenge(직무 전환) · 주재원 파견 = 어휘 「사원이 스스로 지원하는 사내 이동 · 해외 파견」. 직무 전환이 본인 지원형인지 원문은 「구성원의 경력개발을 위해 직무를 전환하는 제도」까지만 밝힘(커리어 개발 페이지 머리 「구성원 누구나 자신만의 커리어를 주도적으로」) — 판단 요청 5.
- **신규 코드: 없음.**
