## 구현 계획 (generator 쪽, 1차 범위 기준)
1. **뷰모델** `generator/pages/company.py`
   - `_group_benefits` 가 행마다 `benefit_cd`·`amt_source`(stated/estimated/none)·`badge`·`verified`·`expires`·`note`·`qual_desc` 를
     넘기도록 확장 (지금 `amt_source` 는 `heatmap.py:125` 만 읽는다). ⚠ 번들 필드 추가 시 `server/models/reference.py` 도 함께(Pydantic 이 조용히 떨군다).
   - 카테고리별 항목 수·소계(공식/추정 분리)·정성 수, 회사 전체: 금액 환산 n / 공식 / 추정 / 정성 / 만료 / 재직자 손 거침.
   - **전 회사 집계**(빌드 컨텍스트에서 1회): 카테고리별 평균 항목 수(현재 113개사: 0.98/0.83/0.61/1.19/2.66/2.39/1.53/1.73/3.61), 축 최댓값(8),
     **항목 수 순위**(**동률은 '공동'** — SKT=LG CNS 27). 회사 하나 바뀌면 전체 재생성(이미 규칙).
     ⚠ **금액 합 순위는 없다** — 착수 시점 계획에는 있었으나 D-6 로 빠졌고, 2026-09-05 에 계산까지 지웠다(SPEC 07 SP-GEN-5.6).
   - 9각형 SVG 는 파이썬이 빌드 시 굽는다(`generator/charts.py` 옆에 `radar_svg`; 시안 `radar_big()` 기하: cx 200·cy 200·R 130·라벨 R+22·viewBox "0 34 400 330").
     ⚠ 프레젠테이션 속성에 `var(--x)` 금지 — SVG 색은 **클래스**로(charts.py 머리말 함정).
2. **템플릿** `generator/templates/company.html` + partials
   - 헤더: h1 · 부제("통신 · 대기업 · 복지 27항목 · 금액 합계 연 1,946만원(추정 포함)") · 비교 CTA.
   - 카드 grid `440px minmax(0,1fr)` → 좌(레이더·범례·소속 필·지표 4칸·DART 캡션·요약 상자) / 본문(3열 카테고리 행 앵커, 헤더 = 라벨·n항목·소계) /
     사이드 232px(근무형태·신뢰도 원장·출처 계보·평균 대비 배율 상위 3 + "9개 모두 평균 이상").
   - 실적 띠: 최신연도 매출·영업이익·순이익 + 전년 대비(`_metrics.html` 이 쓰는 `employ.company_metrics` 값 재사용 — 판정을 두 곳에 두지 말 것).
   - 원장: `_benefit_table.html` 승격 — `<tr id="b-{cd}">`, 1행 이름·금액·출처 문장(회사 공식 수치 ±5% / 앵커 추정치 ±20% / 금액 환산 없음)·배지·확인일·만료,
     2행 QUAL_DESC/NOTE 전문, 3행 출처 상태별 질문 링크(`/edit?comp=&benefit=`, `rel=nofollow`) + "히트맵에서 이 항목 →". `scroll-margin-top` 으로 고정 GNB 회피, 블록 끝 "↑ 카드로".
   - 텍스트의 집은 원장 하나 — 카드에는 이름·금액 토큰만(중복 최소). 카드 패널 머리에 "설명·출처는 아래 원장 ↓" 한 줄.
