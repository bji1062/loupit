## 4. 병합 근거 (32 → 25)

계약의 지시대로 **같은 BENEFIT_CD 후보로 귀결되는 항목만** 병합했다. 코드 후보가 다른 항목은 강제 병합하지 않았다 — 회사 간 비교에서 코드 의미가 오염되면 집계가 틀어지기 때문(계약 규칙 3의 취지).

| 병합 | 흡수 항목 | 귀결 코드 | 근거 |
|---|---|---|---|
| **M1** | 자녀 학자금 지원 + 자녀 대상 선물 지원 | `child_edu` | 둘 다 자녀의 **교육 단계**(성장 단계별 학업비 / 초등 입학·수능)에 연동된 자녀 지원. 두 항목 모두 단독으로도 `child_edu` 후보. |
| **M2** | 가족 경조사 지원 + 결혼·임신 축하 선물 | `event` | 원문 경조사 항목이 이미 "경조비 및 **물품** 지원"으로 축하 물품을 포함. 결혼은 전형적 경조(경사)라 두 항목의 코드 후보가 `event` 로 겹친다. `wedding`/`fertility_support` 로 쪼개면 한 원문 항목이 두 행으로 분해되어 근거가 흐려진다. |
| **M3** | 프리미엄 콘도 지원 + 주중 임직원 골프 지원 | `resort` | 동일 대분류(리프레시)의 **제휴 여가시설 이용 지원** 2건. 원문 콘도 항목에 이미 "곤지암 리조트"(골프·스키 리조트)가 포함되어 대상이 겹친다. |
| **M4** | 5월 Family Day + 프로젝트 현장 케어 + 팀 빌딩 프로그램 + 디지털 코딩농활 | `company_event` | 넷 다 **회사가 주최·운영하는 임직원 참여 프로그램**(행사형). 개별 코드로는 어휘에 대응물이 없다. ⚠ `family_day` 는 쓰지 않았다 — 본 프로젝트에서 `family_day` 는 **조기퇴근** 의미이고 LG CNS 의 "5월 Family Day" 는 가정의 달 **프로그램**이라 코드 의미가 오염된다. |
| **M5** | 복지포인트 + 명절 기념 복지 포인트 | `welfare_point` | 둘 다 원문이 **명시적으로 "복지 포인트"**. 동일 코드 후보라 병합이 가장 정확. `holiday_gift` 로 분리할 수도 있으나 지급 수단이 복지포인트로 동일해 한 행에 정리. |

**병합하지 않은 근접 쌍(사유)**
- `fitness`(피트니스 센터) / `mental`(심리상담소·헬스테라피) — 사내 시설이라는 점만 같고 코드 후보가 다르다.
- `flex_work`(자율책임근무제) / `satellite_office`(공유오피스) — 같은 "공간" 섹션이나 시간 유연성 ≠ 근무 장소. 어휘에 각각 정확한 코드가 있다.
- `discount`(LG전자 가전 할인) / `car_rental`(무료 전기차 대여) — **무상 대여를 `discount` 에 넣으면 할인 코드 의미가 오염**된다(할인율 집계 왜곡). 분리 유지.
- `edu_support`(학자금 이자) / `career`(자격증) / `library`(전자도서관) — 성장 축이라는 점만 같고 어휘상 각기 정확한 코드가 있다.

**행 수 관련 고지**: 목표는 "20행 내외"였으나 **25행**으로 마감했다. 같은 코드 후보가 아닌 항목까지 억지로 합치면 `BENEFIT_CD` 의미가 회사 간 비교에서 오염되므로(계약 규칙 3·5의 취지) 병합을 5건에서 멈췄다.

## 6. 법정 제도 미수록 확인 (계약 규칙 3)

## 11. 검증 판정 반영 (2026-09-01) — 병합 M2·M5 부분 해제 (25행 → 27행)

감사가 **코퍼스 지배 관행과 어긋나는 병합 2건**을 지적했다. 근거 원문은 §3 인용표 그대로이고,
새로 만든 문구는 없다 — 병합했던 원문을 원래의 두 문장으로 되돌린 것뿐이다.

| 조치 | 분리 결과 | 근거 원문 (§3 인용표) | 사유 |
|---|---|---|---|
| **M2 부분 해제** | `event`(family, SORT 52) + **`fertility_support`**(family, SORT 53 신규 행) | 가족 경조사 지원 — "…경조비 및 물품 지원" / 결혼·임신 축하 선물 — "**결혼 및 임신 시 축하 선물 제공**" | **코퍼스 선례**: 출산·임신 축하는 `fertility_support` 다. `event`(경조사)에 임신을 묶으면 회사 간 비교에서 임신·출산 지원 축이 사라진다. **결혼**은 전형적 경조라 `event` 에 남긴다 |
| **M5 부분 해제** | `welfare_point`(perks, SORT 80) + **`holiday_gift`**(compensation, SORT 10 신규 행) | 복지포인트 — "매년 현금성 복지포인트 지급" / 명절 기념 복지 포인트 — "**설·추석 연 2회 명절 복지 포인트 제공**" | **지배 관행 3:1** — 코퍼스는 명절 지급분을 `holiday_gift` 로 분리하는 쪽이 지배적이다. 지급 수단이 포인트라는 이유로 묶으면 명절 급부 유무 비교가 불가능해진다 |
