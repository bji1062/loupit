## 병합/분리 판단 내역

프로젝트 house rule(실리콘투 evidence §병합/분리)은 **"정식 어휘에 둘 다 존재하고 성격도 다르면 분리, 같은 제도군이면 병합"** 이다. 그대로 적용했다.

- **분리 ①**: "장기근속 및 우수/공로 포상" → `long_service_bonus` + `excellence_award`
  - 근속 보상(연차 기반, 자동 지급)과 성과·공로 포상(심사 기반)은 성격이 다른 별개 제도다. 어휘에 둘 다 존재하고 코퍼스 실사용도 각각 `long_service_bonus` 6행 · `excellence_award` 26행으로 충분하다.
  - 한 행으로 묶으면 어느 코드를 쓰든 나머지 절반이 비교축에서 사라진다(`uq_comp_benefit` 때문에 같은 코드 2행 불가).
- **분리 ②**: "콘도 및 야유회" → `resort` + `company_event`
  - 콘도(휴양시설 이용 급부)와 야유회(사내 행사)는 실체가 다르다. 어휘·코퍼스에 둘 다 존재.
- **병합 안 함**: 4개 카테고리 사이에 중복 라벨이 없어 병합 대상 자체가 없었다.
- **금액 3중 계상 위험 없음**: 분리한 4행 모두 금액 NULL 이라 예산 중복 계상이 발생하지 않는다(실리콘투에서 `self_development` 를 쪼개지 않은 사유가 여기엔 해당 없음).

## 신규 코드 (3건)

정식 어휘 9범주 전체와 **코퍼스 실사용 코드 74종**을 전수 대조한 뒤, 대응 코드가 없는 것만 신설했다.

- **`blood_bank`** (health) — 라벨 "혈액은행". 어휘의 health 군(clinic·fitness·health_check·insurance·massage·medical·mental) 어디에도 대응이 없다. `medical`(의료비 지원)은 비용 보전이라 의미가 다르고, `health_check`(건강검진)는 40행이 점유. 코퍼스 전수 검색 결과 "혈액" 언급은 알테오젠 `health_check` 서술의 "혈액종합검진" 1건뿐인데 그건 **검진 항목**이지 혈액은행이 아니다.
- ~~**`child_entrance_gift`** (family)~~ — **철회**. 초안은 심텍이 두 카드를 병렬 게시한 점을 들어 신규 코드를 만들었으나, 검증이 코퍼스 선례(기아·아이센스: `child_edu` = 자녀학자금/입학축하금 한 행)를 근거로 병합 판정했다. 아래 §검증 판정 반영 참조.
- **`summer_vacation_subsidy`** (leisure) — 라벨 "하계휴가비".
  - ⚠ **`summer_leave` 로 넣으면 안 된다.** `summer_leave` 는 코퍼스 실사용 **12행이 예외 없이 전부 `time_off`** 이고, 뜻도 전부 **휴가 일수**(하계휴가 5일, 여름휴가, 집중 휴가제 등)다. 심텍 라벨은 "하계휴가**비**" — **돈**이고, 페이지 어디에도 하계휴가 일수를 부여한다는 문장이 없다. `summer_leave` 행을 만들면 근거 없는 유급휴가를 창작하는 셈이다(과잉 해석).
  - 코퍼스에서 "휴가비"는 항상 휴가 코드 서술에 병기된 형태(한미반도체 `refresh_leave`='특별 휴가 1주일 + 휴가비')로만 등장하고, **휴가 없이 휴가비만 있는 회사는 심텍이 처음**이라 흡수할 상위 행이 없다.
  - 카테고리는 `leisure` — 우리 taxonomy 는 현금성 여부가 아니라 **목적** 기준이다(경조금이 `family` 인 것과 같은 원리). 원문 카테고리(여가문화)와도 일치.
