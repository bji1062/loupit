## ② 복지 항목 명시 여부

- **지주/그룹 공통: 항목 0개.** 예시로 뽑을 복지 문구가 존재하지 않음.
  - 교육제도 페이지에서 건질 수 있는 유사 항목 2개(복지로 보기엔 경계):
    1) 국내/해외 MBA·MS 과정 지원(연 약 40명)
    2) 금융자격증(CFA·CFP) 취득 지원 / 어학·자기계발비 지원
- **은행 전용 benefit 페이지: 항목 추출 실패(0자).** 정적 HTML 22KB 중 본문 텍스트는 `<title>` 뿐. Next.js 클라이언트 렌더로 항목 개수·예시 확인 불가(헤드리스 렌더 필요).
- 항목이 나열된 곳은 사람인/잡코리아/캐치 등 **취업포털(2차 출처)** 뿐 — 공식 출처 원칙상 채택 불가.

## ③ robots

- `https://www.hanafn.com/robots.txt` → **404** (robots.txt 부재 = 명시적 금지 없음, 기본 허용). sitemap.xml도 404.
- `https://hanabank.recruiter.co.kr/robots.txt` → **Allow: /**, Disallow는 `/*/attachFile`, `/attachFile*`, `/bbs*`, `/resources*`, `/app*`. `/career/benefit`은 **허용**이고 sitemap.xml에도 등재.
- → robots 는 두 곳 모두 걸림돌 아님. 막는 것은 robots 가 아니라 **콘텐츠 부재(지주)** 와 **렌더링(은행)**.

## ④ 접근성

- hanafn.com: HTTP 200, 서버사이드 렌더(텍스트 정상 추출). 단, 경로가 `/info/...` 와 `/hfm/mnu/info/...` 두 계열로 갈리고 일부 링크는 `:8002` 포트로 노출됨 — URL 안정성 낮음.
- hanabank.recruiter.co.kr: HTTP 200이나 **SPA**. `?_rsc` / RSC 헤더 시도 시 메타데이터만 반환("하나은행의 복리후생을 소개하는 페이지입니다"), 본문 없음. `/api/...` 추정 경로 4종 모두 404 — 엔드포인트 미확인.

## 결론

지주 법인에 대해 **공식 출처 기반 복지 수집 불가**. 은행 전용 페이지를 지주 카드에 붙이면 법인 불일치(배지 계보 오염). 재시도한다면 조건은 두 가지 중 하나:
1. hanafn.com 에 그룹 공통 복리후생 페이지가 신설될 때, 또는
2. 지주 카드가 아니라 **하나은행 법인**을 별도 등록하고, 헤드리스 렌더로 `/career/benefit` 본문을 확보할 때(그때도 도메인이 `recruiter.co.kr` 이라는 점을 출처 표기에 반영해야 함).
