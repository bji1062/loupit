### ⚠ 회사 전용 페이지 부재의 근거 (추정 아님, 실측)

  자체 홈페이지는 회사소개·사업·ESG·IR 만 있고 채용 섹션 자체가 없다. 채용은 그룹 포털로 완전히 일원화되어 있다.

- 복지 페이지 본문에 그룹측의 명시적 면책 문구가 박혀 있다:
  > **"복리후생은 계열사간 일부 상이할 수 있습니다."**

  → 즉 그룹이 스스로 "이 목록이 HD현대중공업에 그대로 적용된다고 보장하지 않는다"고 선언한 상태다.

## ② 복지 항목 명시 여부 — **명시 O · 총 18개 항목 / 3개 카테고리**

각 항목은 `benefitTitle` + 설명문(`text`) 구조로 하드코딩되어 있다. 수치가 들어간 항목이 많아 데이터 품질 자체는 좋다.

- **Work / 업무 몰입 (8개)**: 선택근로제, 유연근로, 자율좌석제, 워케이션, 아침/점심/저녁 제공, 칸틴 운영, 편안한 근무 환경, 통근버스 운영
- **Life / 생활 지원 (7개)**: 생활안정, 기숙사, 우리 아이 지원, 자유로운 휴가 문화, 그룹사 패밀리 카드 운영, 유류비 지원 혜택, 범현대 계열사 할인
- **Health / 건강 지원 (3개)**: 종합검진, 직원 휴식 지원, 건강 케어(GRC)

## ③ robots 허용 — **허용 O**

`https://recruit.hd.com/robots.txt`
```
User-agent: *
Disallow: /hdcareerAdministrator/
Allow: /
```
- 복지 페이지 `/kr/mainLayout/benefit` 및 데이터 번들 `/js/*` 모두 **명시적 허용**. 차단 경로는 관리자 콘솔 하나뿐.
- `https://recruit.hd.com/sitemap.xml` 존재하며 `/kr/mainLayout/benefit`(및 `/en/...`)이 사이트맵에 **직접 등재**되어 있다 → 사업자가 공개·색인을 의도한 페이지.
- 참고: `www.hd-hhi.com/robots.txt` 는 `Disallow: /*?*`, `/*&*`, `/uploads/`, `/siteSystemHd/` — 쿼리스트링 전면 차단. 다만 해당 도메인에는 애초에 복지 페이지가 없어 무의미.

## ④ 접근성 — **가능하되 SPA 우회 필요 (헤드리스 불필요)**

- `/kr/mainLayout/benefit` 는 **Vue SPA 셸**이다. HTML 응답은 1,781 bytes, `<div id="app"></div>` 뿐 → **WebFetch/일반 HTML 파서로는 본문 0건** (실제로 WebFetch 결과 "복리후생 항목 없음" 반환됨).
- 그러나 복지 데이터는 **API 호출이 아니라 JS 번들에 정적 하드코딩**되어 있다. `app.deed2f3e.js` → 청크 해시맵 → `/js/5869.<hash>.js` 의 `benefitList` 배열에 18개 항목이 전부 들어 있다. **curl + 정규식만으로 완전 추출 가능. 헤드리스 브라우저 불필요.**
- 응답 속도 0.06s, 접속 제한·CAPTCHA 없음. **Googlebot UA 로도 HTTP 200** (`www.hd.com` 이 CloudFront 403 인 것과 대조적).
- ⚠ **깨지기 쉬운 경로**: 청크 파일명에 콘텐츠 해시가 박혀 있어(`5869.08a09a96.js`) 사이트 재배포 시 URL이 바뀐다. 재수집 시 `app.<hash>.js` → 해시맵 파싱부터 다시 타야 한다. 하드코딩 금지.

## 수집 진행 시 지켜야 할 조건 (다음 단계용 메모)

1. **출처 표기는 반드시 "HD현대그룹 공통"** — 회사 전용이 아니다. 배지/출처 계보상 "공식"이되 주체는 HD현대(그룹)이며, 대상 회사는 계열사임을 함께 표기해야 한다.
2. 그룹의 자체 면책 문구 **"복리후생은 계열사간 일부 상이할 수 있습니다"** 를 함께 노출하지 않으면 사실상 허위 표시에 가까워진다.
3. 사무직(판교) 편향 항목(자율좌석제·허먼밀러·전 층 칸틴·수도권 통근버스)은 울산 사업장에 적용된다고 볼 근거가 없다. 그대로 적재할지 자체가 별도 결정 사항.
4. `recruit.hhi.co.kr` 는 **죽은 도메인**이다. 검색 결과에 살아 있는 것처럼 나오므로 다른 계열사 프로브에서도 함정으로 주의.
