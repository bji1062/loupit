## 수집 설계 권고 (실행은 별도)

1. 진입점 = `https://hanamicron.recruiter.co.kr/career/welfare` 단일 URL. 사이트맵으로 URL 검증 가능.
2. 파이프라인에 **헤드리스 렌더 단계**가 필요하다 — 기존 정적 fetch 수집기로는 **빈 문자열이 조용히 들어온다**(가시 텍스트 16자). 길이 하한 가드(예: 200자 미만이면 실패 처리) 없으면 무증상 실패.
3. `/career/system`(인사제도)에 급여·평가·교육 관련 서술이 더 있을 가능성 → 본문 두께 보강용 2차 후보.
4. 출처 표기는 공식 채용사이트로. 단 도메인이 `recruiter.co.kr`(위탁 ATS)이라 **"공식 도메인" 판정 기준을 `hanamicron.com` 문자열 매칭으로 하드코딩하면 이 회사는 탈락한다** — 기업 홈에서의 아웃링크 존재를 근거로 화이트리스트 등재 필요.
