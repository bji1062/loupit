### ⚠ 함정 — 인코딩 (수집 시 반드시 처리)

**페이지는 EUC-KR(cp949)인데 HTTP 헤더에 charset이 없다.**

- 응답 헤더: `Content-Type: text/html` — **charset 미표기**
- HTML 내부: `<meta ... charset=euc-kr>`

→ `requests` 의 `response.text` 나 UTF-8 가정 파서는 헤더에 charset이 없어 **ISO-8859-1로 폴백**, 한글이 통째로 모지바케가 된다(본 프로브에서 1차 추출 시 실제 재현됨). 반드시 **`raw.decode('cp949')`** 로 명시 디코딩할 것.

부수 함정: `bok_04.html` 은 **"사내 동호회 운영/지원" 블록이 2회 중복** 출력된다(원본 마크업 문제). 중복 제거 필요 → 그래서 노출 16개가 아니라 **고유 14개**.
