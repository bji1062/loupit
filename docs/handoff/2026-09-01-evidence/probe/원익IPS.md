## ① 공식 채용사이트 / 복지 페이지 URL

**⚠ 지시서의 `wonik-ips.co.kr` 은 존재하지 않는 도메인이다** — DNS NXDOMAIN
(`getaddrinfo ENOTFOUND www.wonik-ips.co.kr`). 실제 공식 도메인은 **`ips.co.kr`**.
TLS 인증서 subject 가 `O = "WONIK IPS CO., LTD.", CN = *.ips.co.kr` 로 법인 소유가 확인된다.

| 구분 | URL | 성격 |
|---|---|---|
| **1차 정본 (복지 본문)** | `https://www.ips.co.kr/ko/careers/system.php` | **자사 공식 도메인**. 「인사제도」 페이지 하단 `복리후생` 탭에 항목이 그대로 있다 |
| 보조 (조직문화 제도) | `https://www.ips.co.kr/ko/careers/culture.php` | **자사 공식 도메인**. 자율복장·문화가 있는 날 등 근무제도 9종 |
| 참고 (채용공고) | `https://wonik.recruiter.co.kr/career/home` | **원익그룹 채용 포털** (자사 도메인 아님, 그룹 공용). R&D 직군 |
| 참고 (채용공고) | `https://ips.recruiter.co.kr/` | 원익IPS CS 직군 채용 포털 |

## ③ robots 허용 여부

**허용.** `https://www.ips.co.kr/robots.txt` (HTTP 200):

```
User-agent: *
Disallow: /siteSystemWonik
Disallow: /module
```

`/ko/careers/*` 는 어느 Disallow 규칙에도 걸리지 않는다. Crawl-delay 없음, 사이트맵 선언 없음.

참고 — 그룹 포털 `wonik.recruiter.co.kr/robots.txt` 도 `Allow: /` 이며
`/bbs*`, `/attachFile*`, `/resources*`, `/app*` 만 차단. 채용 상세는 허용 범위지만
①의 이유로 수집 대상에서 제외 권고.

## ④ 접근성

| 항목 | 결과 |
|---|---|
| 렌더링 | **정적 (서버사이드 PHP)**. `curl` 단독으로 복지 15항목 전문이 raw HTML 에 들어온다. **JS 실행 불필요** |
| HTTP | 200, 약 37.7KB (`system.php`) / 28.8KB (`talent.php`) |
| 봇 차단 | **없음.** 일반 Chrome UA 로 정상 응답. Cloudflare/WAF 챌린지·403·rate limit 미관측 |
| TLS | **정상.** Sectigo Public Server Authentication CA OV R36 발급 OV 인증서, `*.ips.co.kr`, 유효기간 2026-05-06 ~ **2026-11-20** (검증 결과 `ssl_verify=0` = 통과) |
| 인코딩 | UTF-8, 한글 정상 |
| 구조 | 복지 블록이 탭 UI 안에 있으나 **DOM 에는 처음부터 존재** — 탭은 CSS 표시 전환일 뿐이라 파싱에 지장 없음 |

**주의 1 — 파일명 함정:** 복지가 `welfare.php`/`benefit.php` 에 있을 것 같지만 둘 다 **404**다.
실제 위치는 `system.php`(인사제도). 경로를 추측으로 넣으면 조용히 빈다.

**주의 2 — 인증서 만료:** 2026-11-20 만료. 그 이후 재수집 시 TLS 실패 가능성을 염두에 둘 것.

**주의 3 — 자체 검증 시 UA:** 우리 쪽 봇 방어가 헤드리스 UA 에 403 을 주므로
(MEMORY 기록) 검증은 일반 브라우저 UA 로 할 것. 상대 사이트는 UA 를 가리지 않는다.
