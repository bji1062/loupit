## ③ robots

**둘 다 허용.**

- `https://www.hankooktire.com/robots.txt` (200, Last Updated 2024-09-11): `User-agent: *` / `Allow: /` — **Disallow 라인이 단 한 줄도 없다**. Sitemap 30여 개 로케일 선언. → A·B 전면 허용.
- `https://hankooktire.recruiter.co.kr/robots.txt` (200): `Allow: /`, Disallow는 `/*/attachFile`, `/attachFile*`, `/bbs*`, `/resources*`, `/app*` 뿐. → **`/career/benefits` 는 허용 경로**. sitemap.xml에 `/career/benefits` 명시 등재.

## ④ 접근성

**A·B = 정적 (단, UA 함정 있음)**
- 기본 WebFetch UA로는 `www.hankooktire.com` 전체가 **403 Forbidden**(robots.txt 조차 403). WAF/봇 필터.
- 브라우저 UA를 붙인 curl은 **200 + 완전한 본문 HTML**. A=121,258B, B=121,584B, 복지 문구가 raw HTML에 그대로 들어있다. AEM 서버 렌더 → **JS 불필요**.
- 즉 "차단"이 아니라 **UA 조건부**. 수집기에 브라우저 UA만 세팅하면 끝.

**C = JS 필수(현 수단으로 불가)**
- Next.js App Router SPA. `/career/benefits` 응답은 23,885B **셸뿐**. `self.__next_f.push` 12개를 전부 뜯어봐도 들어있는 한글은 title/description/keywords 등 **메타 9줄**이 전부.
- `RSC: 1` 헤더 플라이트 요청도 13,036B에 본문 0건.
- 채용공고 상세(`/career/jobs/84730`)도 동일 — 셸 24KB, 본문은 클라이언트 fetch. 빌더 API 엔드포인트는 셸·페이지 청크(604B)에 노출되지 않음.
- → **헤드리스 렌더 없이는 C에서 한 항목도 못 가져온다.**
