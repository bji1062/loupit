## ② 복지 항목 명시 여부 — **명시됨 · 10개**

페이지가 카드 단위로 항목명을 그대로 적어둔다(항목명 + 한 줄 설명). 원문 그대로:

1. 사택, 기숙사(온산)
2. 자녀 학자금/취업준비금 지원
3. 정기 종합검진 및 의료비 지원
4. 휴양시설 지원(콘도, 하계휴양소)
5. 통근버스 운영(온산)
6. 주택 구입 및 전세자금 융자
7. 임직원 MBA 및 대학원 과정 지원
8. 각종 동호회 활동 지원
9. 복지포인트 지급
10. 직장 보육시설 운영(온산)

**예시 2건(설명문까지 있는 것):**
- **사택, 기숙사(온산)** — 상세 페이지에 "총 762세대의 주거시설을 비롯해 헬스장, 풋살장 등 다양한 취미생활을 즐길 수 있는 시설". 정량 수치(762세대)가 있어 본문 살로 쓸 수 있다.
- **각종 동호회 활동 지원** — "현재 고려아연에서는 골프, 등산, 축구, 봉사 등 30여개 동호회".

카테고리 축: 주거 / 교육·자녀 / 건강 / 휴양 / 통근 / 금융(융자) / 자기계발 / 문화·동호회 / 복지포인트 / 보육 — 우리 복지 카테고리 매핑에 무리 없이 들어간다.

⚠ 함정: 리스트 카드의 항목명은 index 페이지에 전부 있으나, **762세대·30여개 같은 수치는 카드 상세(모달/하위 뷰) 쪽 문구**다. 카드 텍스트만 긁으면 항목명 10개는 얻어도 설명이 빈다.

## ③ robots 허용 — **허용**

```
# careers.koreazinc.co.kr/robots.txt  (HTTP 200, 64 bytes)
# https://www.robotstxt.org/robotstxt.html
User-agent: *
Allow:/
```

- `/hrsystem/*` 에 대한 Disallow 없음. Crawl-delay 없음. 채용 서브도메인은 **전면 허용**.
- 참고 — 기업 도메인 `www.koreazinc.co.kr/robots.txt` 는 `Disallow: /wp-admin/` (+ `Allow: /wp-admin/admin-ajax.php`, sitemap `https://www.koreazinc.co.kr/wp-sitemap.xml`). 우리가 볼 경로와 무관.

| 항목 | 값 |

**정적 판정 근거** — 원본 HTML(JS 실행 전)에 항목 문자열이 그대로 존재:
`복지포인트`(5회) `사택`(8) `기숙사`(5) `학자금`(4) `종합검진`(3) `휴양시설`(4) `전세자금`(4) `동호회`(6) `보육시설`(3) `MBA`(4).
`__NEXT_DATA__` / `_nuxt` / react / vue / angular 흔적 **0건** → SPA 아님, 서버 렌더링. 헤드리스 브라우저 불필요, 단순 HTTP GET + 파싱으로 충분.

가시 텍스트 약 9,900자(GNB·푸터 포함), 복지 본문만 추리면 항목 10건 + 리드 문구 3줄.
