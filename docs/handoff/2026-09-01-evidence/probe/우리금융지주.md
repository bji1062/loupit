- `www.wooribank.com` / `spot.wooribank.com` → **robots.txt 없음(HTTP 404, 에러 HTML 반환)** = 명시적 금지 없음.

## ④ 접근성

- **woorifg.com — TLS 함정**: 기본 curl/requests 는 핸드셰이크 실패
  (`error:0A000152:SSL routines::unsafe legacy renegotiation disabled`).
  OpenSSL `Options = UnsafeLegacyRenegotiation` + `CipherString = DEFAULT@SECLEVEL=1` 을 주면 **HTTP 200 정상 취득**.
  수집기를 붙일 경우 이 옵션이 필수. (WebFetch 는 통과)
- **spot.wooribank.com — 봇 차단**: 세션 쿠키·Referer 를 넣어도 `withyou=BPHRR0011` 등 전 페이지가
  HTTP 200 + `<title>고객님 불편을 드려 죄송합니다.</title>` 에러 화면으로 고정. 본문 취득 불가.
- `recruit./job./career.wooribank.com` 서브도메인 전부 미존재(연결 실패).
