### 이번에 밟은 함정

- **`{#-` 주석이 앞줄 줄바꿈을 먹는다.** `_head_meta.html` 에 설명 주석을 `{#-` 로 달았더니 og:image 와 preload 태그가
  한 줄로 붙어 **137쪽 전부**가 한 바이트씩 달라졌다. 테스트는 전부 초록이었다 — 실데이터 빌드 diff 로만 잡혔다.
  `{#`(대시 없음)는 `trim_blocks` 가 뒤 줄바꿈만 지워 출력이 같다. 공유 partial 을 건드리면 **반드시 빌드 diff**.

## 배포 (순서가 틀리면 `/` 가 404 — 이 순서만)

1. 스냅샷: `curl -s https://jobcho.wiki/ > ~/index-before-2026-09-13-home2.html`
2. **nginx conf 먼저**(머지 전에 해도 무변화 — dist 에 index.html 이 아직 없어 수기 셸이 나간다):
   - `diff /etc/nginx/sites-available/loupit.conf <worktree 또는 main>/infra/nginx/loupit.conf` → **`location = /` 한 곳만** 달라야 한다(다르면 멈추고 드리프트부터 본다)
   - 백업 `sudo cp /etc/nginx/sites-available/loupit.conf /etc/nginx/sites-available/loupit.conf.bak-$(date +%F-%H%M)`
   - 배치 → `sudo nginx -t && sudo systemctl reload nginx` → `/` 200 이고 바이트가 `web/index.html` 과 같은지
3. PR 머지 → 메인 트리 `git pull --ff-only`(여전히 수기 셸이 나간다 — 파일을 지우지 않았으므로)
4. `RELEASE_CONFIRM=1 bash infra/deploy/release.sh` → `web/dist/index.html` 생성 순간 `/` 가 생성 대문으로 넘어간다
5. 확인: `/` 에 `naver-site-verification` · 「복지 항목 최근 확인」 · `rel="preload"` 없음 · sitemap 에 `https://jobcho.wiki/` 1회 · 스모크 PASS
6. 롤백: `web/dist/index.html` 을 치우면 즉시 수기 셸로 돌아간다(폴백). conf 까지 되돌리려면 백업 복사 + reload.
7. beta conf 는 release.sh 가 배포하지 않는다 — 필요하면 같은 방식으로 수동 배치.
