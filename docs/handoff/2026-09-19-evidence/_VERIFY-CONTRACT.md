- **행별 표**: SORT · 코드 · 판정 · 근거 원문(인용) · 조치 권고(유지 / 삭제 / 재코딩→코드 / 병합 / 각주 추가 / AMT NULL / 문안 교체).

왜: 웨이브 3 에서 회사별 검증이 207행을 전부 통과시킨 뒤, 횡단 감사의 검출어 스윕이 법정 문구 1행(포스코퓨처엠 「본인/배우자 태아 검진 휴가」 — 근로기준법 74조의2)을 잡아냈다. 읽어서 판단하는 것과 검출어로 훑는 것은 다른 일이고, 검증이 먼저 훑는 게 싸다.

- 검출은 **단서지 판정이 아니다.** 오탐이 많다(「근속 연차」의 연차, 「연차휴가 조기사용 제도」 같은 회사 제도명). 한 줄씩 판정하고 `허용 / 삭제 / 문안 교체` 를 적는다.
- 허용은 **원문이 법정분과 회사 상회분을 스스로 나눠 밝힌 경우**뿐이다(「육아휴직 자녀당 최대 2년 중 회사지원 추가 1년」은 허용, 「육아휴직 제공」은 삭제).
- 편집 주석 검출(「코퍼스」「선례」「병합」「판독」「규칙」「⚠」 등)은 사용자 노출 필드에 들어가면 안 되는 말이다 — 하나라도 남으면 대체 문안을 적는다.
