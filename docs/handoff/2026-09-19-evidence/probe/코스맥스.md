## ⑥ 예절·절차 기록

1. **등록한다면 계보는 「그룹 공통」으로 낮춰야 한다.** 16항목의 유일한 출처가 「코스맥스그룹」 이름으로 게재되고, 같은 페이지를 코스맥스비티아이·코스맥스엔비티·코스맥스바이오·코스맥스파마가 공유한다(②-4). 항목 #13 「화장품/건강기능식품/제약」은 목록 자체가 그룹을 전제한다는 본문 증거다. **전 행 각주 필수**(더존비즈온 선례). 그리고 **코스맥스비티아이(044820)·코스맥스엔비티(222040)는 이후 웨이브에서 영구 보류** 대상으로 적어 둘 것 — 같은 16행이 복제된다.
2. **16항목 전부 이미지 판독이라 텍스트 원문 근거가 없다.** 정본은 `2352×1323` JPEG 한 장(`fileName` = 「2025 코스맥스 복리후생_가로.jpg」, 업로드 2025-07-17)이다. 판독은 선명했지만 **행마다 원문 문자열을 인용할 수 없으므로** 근거표에는 이미지 URL + 크기 + 그리드 좌표(행,열)를 함께 남길 것. 갱신 감지는 **빌더 JSON 의 `fileUid`(현재 `2c7507a1-…`) 변경**으로 한다 — 파일명에 연도가 박혀 있어 다음 개정 때 URL 이 통째로 바뀐다.
3. **API 를 직접 부르지 말고 렌더 DOM 에서 이미지 URL 만 얻을 것.** 빌더 JSON URL 을 알려주는 `api-recruiter.recruiter.co.kr` 는 robots `Disallow: /` 이고, 이미지가 놓인 `infra1-static` 는 robots 가 403(서명 URL 오류)이다. 수집기는 허용 경로 `/career/welfare` 를 1회 렌더하고 `img[src*="/builder/"]` 만 집어 와야 하며, 렌더 1회에 하위 요청이 70건 넘는다는 점을 예산에 넣을 것.
4. **법정 초과분 판정을 항목 단위가 아니라 문장 단위로 하라.** #3 은 배우자 출산휴가 20일(법정) + 무급 10일(초과), #5·#6 은 「법정 … 외에 별도」 표현이 붙는다. #2 는 법정 육아휴직의 자동 신청 방식이다. SP-LEGAL 배지·집계 제외 판정을 이 네 건에 개별로 매길 것. 금액이 있는 행은 **#1 출산장려금 하나**(1천/2천/3천만원)뿐이다.
5. **자기 도메인은 출처가 아니다.** `www.cosmax.com` 은 코스맥스(주)가 운영(개인정보처리방침 명시)하지만 복지 항목이 0이고, 채용 메뉴는 포털로 나가는 버튼 한 줄이다. `cosmax.co.kr`·`www.cosmax.co.kr` 는 **HTTPS 가 없는 S3 리다이렉트 버킷**이니 출처 후보에서 영구 제외. ATS sitemap 의 `company(1)(2)…` 40개는 직무소개 중복 슬러그라 크롤 대상에서 뺄 것이고, 그 `lastmod` 는 **요청 시각**이라 신선도 신호로 쓰면 안 된다.
