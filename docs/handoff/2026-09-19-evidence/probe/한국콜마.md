## ③ robots — 호스트별로 갈린다. **핵심 경로는 허용, 진입 링크와 API 호스트는 금지**

각 호스트의 `robots.txt` 를 **본문보다 먼저, 단독으로** 받았다(예외 1건은 ⑥).

### ③-1 `www.kolmar.co.kr` — 전면 허용

HTTP 200, `text/plain`, **131B**, `Last-Modified: Wed, 16 Sep 2026`. **BOM 없음**(첫 바이트 `23 44 61 75` = `#Dau`).

```
#DaumWebMasterTool:9d3c42cf...
User-agent: *
Allow:/
```

레코드는 하나뿐이고 `Disallow`·`Crawl-delay`·`Sitemap` 지시가 없다. ClaudeBot·anthropic-ai·GPTBot·CCBot·Google-Extended 전용 그룹이 **없으므로 전부 `*` 에 흡수 → 허용**. 네패스식 AI 봇 선별 차단 아님.

### ③-2 `kolmar.recruiter.co.kr` — 레코드 1개(UA 5줄 묶음). `/career/*` 허용, **`/app*` 금지**

HTTP 200, `text/plain;charset=UTF-8`, **254B**, **BOM 없음**(`55 73 65 72` = `User`).

```
User-Agent: *
User-Agent: Googlebot
User-Agent: Yeti
User-Agent: Daumoa
User-Agent: Bingbot
Allow: /
Disallow: /*/attachFile
Disallow: /attachFile*
Disallow: /bbs*
Disallow: /resources*
Disallow: /app*
Sitemap: https://kolmar.recruiter.co.kr/sitemap.xml
```

⚠ **신한 선례 그대로다** — UA 5줄이 빈 줄 없이 이어지므로 **한 레코드**다. UA 줄마다 그룹을 끊으면 `*` 가 규칙 없는 빈 그룹이 되어 「전면 허용」으로 정반대 판정이 난다. 올바른 판정: `*` 를 포함한 다섯 UA가 **같은 5개 Disallow 를 공유**한다. AI 봇 전용 그룹은 없으므로 ClaudeBot·anthropic-ai·GPTBot·CCBot·Google-Extended 도 `*` 레코드를 따른다.

RFC 9309(가장 긴 일치 우선)로 경로 판정:

| 경로 | 판정 | 비고 |
|---|---|---|
| `/career/benefits`, `/career/*` 전부 | **허용** (`Allow: /` 만 일치) | sitemap 12개 URL 전부 `/career/*` |
| `/sitemap.xml`, `/robots.txt` | 허용 | |
| `/_next/static/**` | 허용 | 페이지 청크·CSS |
| **`/appsite/company/index`** | **금지** (`Disallow: /app*`) | ①-2 의 **유일한 채용 진입 링크가 여기다** |
| `/app/applicant/myPage/login` | 금지 | 메뉴의 마이페이지 |
| `/bbs*`, `/resources*`, `/attachFile*`, `/*/attachFile` | 금지 | |

**실행에서도 지켰다.** 헤드리스 렌더에 라우트 인터셉터를 걸어 위 금지 패턴에 매칭되는 요청을 전부 abort 하도록 했고, 실측 결과 **차단된 요청 0건**(= 렌더가 이 호스트의 금지 경로를 부르지 않는다). 계약상 `*` 가 막는 것은 **진입 링크와 지원 기능**이고 **복리후생 본문 경로는 막지 않으므로**, 「불가(robots)」가 아니다.

### ③-3 `infra1-static.recruiter.co.kr` — robots 없음(403) → 허용

`/robots.txt` 가 **HTTP 403 + `text/xml` 146B** CloudFront 오류(`<Code>MissingKey</Code> Missing Key-Pair-Id query parameter or cookie value`)다. robots 파일이 아니라 서명 URL 게이트의 오류 응답이다. RFC 9309 상 429 아닌 4xx = 규칙 없음 → **허용**. 정작 데이터 경로(`/builder/recruiter/**`)는 서명 없이 **200** 으로 열린다(실측 7,607B·60,783B).

### ③-4 `api-recruiter.recruiter.co.kr` — **전면 금지**

HTTP 200, **27B**.

```
User-agent: *
Disallow: /
```

이 호스트에 사이트 디자인 API(`/design/v2?languageType=KOR`, `/pop-up/v1`, `/brand/v1/font/design`, `/company/v1/privacy-policy`, `/design/v1/multi-language/default`, `/marketing/v1/plugin`)가 있고, **채용공고 목록도 여기서 온다고 추정**된다. 계약상 이 호스트는 한 건도 받을 수 없다. 이 때문에 ①-3 의 「공고 법인별 분포」를 끝내 확인하지 못했다.

## 수집 설계 시 유의

1. **판정은 「조건부(그룹 공통)」이고, 등록 여부는 리드 몫이다.** 막는 것은 접근성이 아니라 귀속이다 — 16항목이 한국콜마 임직원에게 적용된다는 **1차 근거가 사이트 본문에 없다**(본문 법인명 0건, 운영 주체 콜마홀딩스(주), 콜마홀딩스도 같은 페이지를 자기 채용으로 링크). 등록한다면 계보를 **「그룹 공통」으로 낮춰 표기**하고 출처를 `kolmar.recruiter.co.kr`(콜마그룹 통합 채용사이트)로 명시해야 한다. 형제 법인이 코퍼스에 하나도 없어 「계열사 상세 복제」 위험은 지금은 없지만, **HK이노엔·콜마비앤에이치가 나중에 들어오면 같은 16행을 복제하게 된다** — 그때 대비해 출처 URL 을 행마다 남길 것.
2. **수집 경로를 `/appsite/...` 로 잡으면 robots 위반이다.** 두 회사 홈페이지가 채용 링크로 쓰는 `https://kolmar.recruiter.co.kr/appsite/company/index` 는 `Disallow: /app*` 에 걸린다. 허용된 문은 sitemap 에 실린 `/career/benefits` 하나다. robots 파서는 **UA 5줄을 한 레코드로** 읽어야 한다(줄마다 끊으면 전면 허용으로 오판).
3. **렌더하지 말고 빌더 JSON 을 직접 받아라.** 헤드리스 렌더는 `api-recruiter.recruiter.co.kr`(**`Disallow: /`**)를 반드시 건드린다 — 즉 **robots 를 지키면서 이 페이지를 브라우저로 렌더할 방법이 없다.** 대신 `https://infra1-static.recruiter.co.kr/builder/recruiter/2026/06/02/3f50b82b-....json`(허용, 60,783B)을 curl 로 받아 `type=="TEXT"` 블록의 `value`(Slate JSON 문자열)를 2단 파싱하면 16항목이 그대로 나온다. ⚠ **JSON 안의 블록 순서는 화면 순서와 다르다**(절대 배치라 `parentId` 그룹 좌표로 정렬해야 화면 순서가 된다) — 순서에 의미를 두지 말 것. ⚠ 이 JSON 의 **URL 은 날짜·UUID 가 박혀 있어 페이지를 수정하면 바뀐다**. 갱신 감지를 URL 로 하면 안 되고, URL 재발견 경로가 금지 API 뿐이라 **갱신 시 URL 을 사람이 다시 확인해야 한다**. 이 취약함을 감수하기 싫으면 정본을 `/career/benefits` 로 적되 본문은 JSON 에서 뜨는 2단 구조로 설계할 것.
4. **법정 제도 제외 판단이 필요한 행이 둘.** ④ 「자유로운 연차휴가」는 **연차 자체가 법정**이다 — 수록한다면 법정분이 아니라 「반차·반반차 분할 사용」만 남겨야 한다. ⑧ 「건강 관리 — 매년 건강검진」은 법정 일반건강검진(사무직 2년 1회)과 경계라 판단이 필요하다. ①·② PC-OFF·시차출퇴근제는 법정 근로시간 준수 장치이지 급부가 아니라는 점도 함께 볼 것.
5. **한 항목에 여러 제도가 묶여 있고 거점 한정어가 붙는다.** ⑩ 「사내 복지공간」 = 카페 + 피트니스 + 여성휴게실, ⑪ 「경조사 지원」 = 경조금 + 휴가 + 용품. 분할하면 설명의 **「전 사업장」(도서관·구내식당)·「일부 사업장에 한함」(셔틀버스)** 한정어를 반드시 보존할 것 — 떼면 없는 제도를 만든다. ⑫ 출산 장려 금액(첫째 1000만·둘째 1000만·셋째 2000만)은 이 회사의 유일한 금액 명시라 **오타 없이** 옮기고 단위(만원)를 확인할 것.
6. **호출 규약**: apex `kolmar.co.kr` 는 NXDOMAIN, `recruit.kolmar.co.kr` 는 DNS 만 살아 있고 80·443 이 닫혀 있다(20초 타임아웃) — 둘 다 후보에서 빼라. 채용사이트는 진짜 404 를 주므로 soft-404 방어는 불필요. 인증서는 마이다스 ATS 공용 와일드카드(2027-01-06 만료)라 법인 검증에 쓸 수 없다. 자기 도메인 `www.kolmar.co.kr` 의 IR·PR 게시판 링크는 **이중 인코딩이 깨져 있다**(`ÃƒÂ¯Ã‚Â¿Ã‚Â½` 류) — 그쪽을 긁을 일이 있으면 URL 을 신뢰하지 말 것.
