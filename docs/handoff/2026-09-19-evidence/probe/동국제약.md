### ③-1 `dkpharm.recruiter.co.kr` robots 원문 — **UA 5줄이 한 레코드**(신한 선례 유형)

```
User-Agent: *
User-Agent: Googlebot
User-Agent: Yeti
User-Agent: Daumoa
User-Agent: Bingbot
Allow: /
Disallow: /*/attachFile
Disallow: /attachFile*
Disallow: /bbs*
Disallow: /resources*
Disallow: /app*
Sitemap: https://dkpharm.recruiter.co.kr/sitemap.xml
```

- UA 줄마다 그룹을 끊으면 `*` 가 규칙 없는 레코드가 돼 **정반대 판정**이 난다. 레코드는 하나, 규칙은 5개 UA 공통이다.
- ClaudeBot·anthropic-ai·GPTBot·CCBot·Google-Extended 를 **이름으로 막는 레코드는 없다** → 전부 `*` 규칙을 따른다.
- RFC 9309(가장 긴 일치 우선) 적용:
  - `/career/welfare` → 어떤 `Disallow` 와도 안 맞음 → `Allow: /` → **허용**
  - `/appsite/company/index`(**회사 홈 GNB 「채용공고」가 가리키는 바로 그 경로**) → `Disallow: /app*`(5옥텟) vs `Allow: /`(1옥텟) → **금지**.
    ⚠ 웨이브 3 계약 메모의 `Disallow: /` + `Allow: /appsite/`(허용) 와 **부호가 반대인 사례**다. 같은 `recruiter.co.kr` ATS 라도 테넌트마다 robots 가 다르다 — 호스트마다 새로 읽어야 한다.
  - `/sitemap.xml` → 허용. 실제로 받아 보니 200 · 2,335B · `<loc>` **16개**: `/career/` 아래 company·compensation·edu·faq·home·jobs·jobs_interview·management·map·map1·map3·process·recruit·talent·**welfare**·work.
- **이번 세션에서 `/appsite/` 경로에는 한 번도 요청하지 않았다.** robots 를 본문보다 먼저, 호스트 단독으로 받았다(웨이브 4 예절).

### ③-2 ATS 복리후생 페이지는 **법인 귀속은 되는데 본문을 합법적으로 못 가져온다**

`https://dkpharm.recruiter.co.kr/career/welfare` (robots 허용이라 1회만 GET) — 200 · 23,107B · 0.12s.

- **귀속은 확실하다**: `<title>복리후생 | 동국제약 채용</title>`, `meta description=「동국제약의 복리후생을 소개하는 페이지입니다.」`, `meta author=동국제약`, `canonical=…/career/welfare`, schema.org `publisher.name=동국제약`. 다른 회사 샘플 템플릿(KAI·티에스이 나인하이어 유형)이 **아니다**.
- **그런데 원본 HTML 에 복지 항목이 0개다.** Next.js App Router **CSR** 셸이고, `__next_f` 플라이트 페이로드(13,282자)를 전부 복원해 봐도 들어 있는 한글은 메타데이터 8종뿐(`복리후생 | 동국제약 채용`, `함께 성장할 여러분을 기다립니다.` 등). 항목 문자열은 한 줄도 없다.
- 본문은 클라이언트가 **빌더 API** 에서 받아 온다. 번들에서 환경 매핑을 확인했다(`_next/static/chunks/7414-6025158ec4ceec55.js`):
  `EDITOR.JOBFLEX.production = "https://api-builder.recruiter.co.kr"` · `RECRUITER.JOBFLEX.production = "https://api-recruiter.recruiter.co.kr"` (플랫폼 = MIDAS IN jobflex). 실제 호출 경로도 상대경로였다 — `/pop-up/v1`, `/brand/v1/font/design` (`chunks/2767-abf2faba44ccf159.js`). 페이지 본문 엔드포인트 자체는 이번 세션에서 특정하지 못했다.
- **그 두 API 호스트가 `User-agent: * / Disallow: /` 다.** 따라서
  - API 직접 호출 → **금지**
  - 헤드리스 렌더 → 렌더가 그 API 를 호출하므로 **역시 금지**(웨이브 4 예절: 「렌더가 끌어오는 하위 리소스도 robots 판정에 든다」). **그래서 이번 프로브는 렌더를 하지 않았다.**
- → ATS `/career/welfare` 의 항목 수는 **끝내 확인하지 못했다**. 「불명」이지 「0」이 아니다. 그리고 확인할 합법적 경로가 없다.
- 같은 이유로 `/career/jobs`(공고 목록)·`/career/compensation`(보상)도 본문을 못 가져온다 — 공고에서 복지를 캐는 제주반도체식 우회로는 이 회사엔 없다.

### ⚠ soft-404 — 이 사이트는 **없는 주소에도 200 을 준다**

- `robots.txt` → 302 → `http://dkpharm.co.kr/page/error_404.html` → **HTTP 200** · 2,246B · 「죄송합니다. 요청하신 페이지를 찾을 수 없습니다.」

1. **정본은 `https://www.dkpharm.co.kr/hr/welfare.php` 단 하나, 8항목이다.** `<li>` 는 7개뿐이고 3번 `<li>` 안에서 `<br>` 로 「자녀 학자금 지원」과 「단체 상해보험 가입」이 나뉜다 — **`<br>` 를 개행으로 치환한 뒤 쪼개라.** 안 쪼개면 없는 제도 1행이 생기고, 8항목이 7항목으로 줄어든다.
