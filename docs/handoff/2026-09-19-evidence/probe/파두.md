## ③ robots — 정본 경로 허용, AI 봇 이름 레코드 없음 (차단은 robots 가 아니라 WAF 에 있다)

계약대로 **호스트마다 robots.txt 를 단독으로 먼저 받고**, 판정 후에 본문을 요청했다. `fadu.recruiter.co.kr` 은 robots 판정에서 끝내고 본문을 요청하지 않았다.

## 수집 설계 시 유의

1. **정본은 `careers.fadu.io/ko/culture` 하나다.** 기업 도메인 `www.fadu.io` 에는 복지가 0이고, 로케일 없는 `/culture` 는 301 이며 `/en/culture` 는 국문과 같은 내용이라 **중복 수집 위험**이 있다(영문판이 따로 있는 게 아니다). 출처 표기는 「회사 커스텀 도메인으로 운영하는 그리팅 ATS 채용 사이트」로 남기고, 갱신 때 `customDomain` 이 유지되는지(현재 `SUCCESS`) 먼저 확인한다 — 커스텀 도메인이 풀리면 URL 이 `faduhr.career.greetinghr.com` 으로 바뀐다.
2. **한 문구가 원본 HTML 에 3번 나온다**: 가시 DOM 1회 + styled-components 가 DOM 속성으로 흘린 `content="&lt;p&gt;식대 지원&lt;/p&gt;"` 1회 + `__NEXT_DATA__` 1회. 정규식·문자열 카운트로 세면 3배가 된다. `bs4.get_text()`(속성 무시)로 뽑거나, 아예 `dehydratedState.queries[…getCareerPageDetail].page.sections` 에서 `id=f2d76050…` 섹션만 골라 `layouts → columns → blocks` 순으로 읽을 것. 설명 텍스트는 `<p>` 이중 이스케이프(`&amp;nbsp;` 포함)라 `html.unescape` 를 한 번 더 걸고 원문 보존 필드를 둔다.
