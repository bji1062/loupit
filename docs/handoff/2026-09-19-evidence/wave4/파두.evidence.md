## 4. 판단이 갈리는 곳 (검증자가 먼저 볼 3가지)

### ① 건강검진 행(SORT 70) — 카드가 아니라 요약 문장이 근거다

- 「건강검진 지원」은 **복지 혜택 카드 11개 안에 없다.** 같은 페이지 위쪽 「팀 문화」 섹션(`4bdb0ebc` L2C2)의 제도 열거 문장에만 나온다: 제목 「구성원이 일에 몰입하고 성장하도록 지원합니다.」 아래 「① 자율성: 유연근무제, 자유로운 휴가 사용 / ② 근무 환경: 강남구청역과 연결, 카페테리아 운영 / ③ 성장: 직무 교육 및 외국어 교육 지원 / **④ 건강과 행복: 건강검진 지원, 경조사 지원 등**」.
- **수록 근거**: 이 문장의 나머지 6개 항목(유연근무제·자유로운 휴가 사용·강남구청역 연결·카페테리아·직무 교육·외국어 교육·경조사 지원)이 **전부 복지 카드와 1대1로 대응한다** → 이 문장은 인재상·비전 문구가 아니라 **제도 열거 문장**임이 같은 페이지 안에서 입증된다. 건강검진만 카드가 없을 뿐이다. 정본 페이지 안의 원문 문장이므로 규칙 2 를 만족한다.
- **반대 논거(검증자용)**: 문장이 「등」으로 끝나 열거가 닫히지 않았고, 카드와 층위가 다르다. 프로브도 「카드와 같은 층위로 올리려면 별도 판단이 필요하다」고 유보했다.
- **취급**: 수록하되 **혼자 있는 카테고리 섹션(SORT 70)** 에 두었다. 검증이 제거로 판정하면 이 한 행만 지우면 되고 다른 행의 SORT 는 건드릴 필요가 없다. QUAL_DESC 에도 근거 위치를 노출 허용 문안 범위에서 밝혀 두었다 — 「공식 채용 사이트 팀 문화 섹션의 건강과 행복 항목에 건강검진 지원 명시 (복지 혜택 카드에는 별도 항목 없음 …)」.

### ② 「자유로운 휴가 사용」 — 법정 연차와 상회분의 경계

원문 설명이 두 문장이다. 「별도의 승인 절차 없는 휴가 사용」 + 「기본 연차 외 5일의 공동연차 추가 제공」.
- **기본 연차 자체는 법정**이라 행으로도 서술로도 만들지 않았다. 행의 실체는 **추가 5일**이다.
- 규칙 3 은 「회사 재량 상회분(… 추가 휴가)만, 원문이 상회 조건을 밝힐 때 수록」을 허용한다. 「기본 연차 **외**」는 원문이 스스로 밝힌 상회 기준점이라 그대로 인용했다. QUAL_DESC 에 「법정」이라는 단어는 쓰지 않았다.
- 「별도의 승인 절차 없는 휴가 사용」은 연차 부여가 아니라 **사용 절차의 회사 재량**이라 같은 행 서술에 함께 두었다. 별도 행(예: `leave_general`)으로 만들면 원문 항목 1개가 2행이 된다.
- BENEFIT_NM 을 원문 라벨 「자유로운 휴가 사용」이 아니라 **「공동연차 5일」** 로 적었다. 라벨을 그대로 쓰면 비교 화면에서 「법정 연차를 자유롭게 쓴다」로 읽혀 실체(추가 5일)가 가려진다. 원문 문구의 부분 인용이라 없는 말을 만든 것은 아니다.

### ③ 「어학 교육」·「직무 교육」 — 규칙 8 의 비용 지원/커리큘럼 경계

- 두 항목 모두 원문 어미가 「**지원**」이고 직무 교육은 「**외부** 교육」이라 명시된다 → 회사 주도 사내 커리큘럼이 아니라 비용 지원으로 읽었다.
- 같은 페이지 팀 문화 문장도 「③ 성장: 직무 교육 및 외국어 교육 **지원**」으로 같은 어미를 쓴다(독립 근거 1개 더).
- 반면 **「신규 입사자 교육」은 제외**했다 — §6 참조.

## 5. 금액

- **원 단위 금액은 원문에 1건뿐**: 「점심, 저녁(야근시) 각 15,000원 식대 별도 지원」.

1. **재수집 UA**: 브라우저 UA 필수. AI 봇 UA 는 403·25 B 가 온다(§1 렌더 방식). 크기 기반 이상 탐지로는 잡히지만 「항목 0」으로 조용히 넘어가지 않도록 할 것.

5. **사업장 범위**: 페이지에 면책 문구가 없지만 「강남구청역 연결」·「카페테리아」는 **서울 본사(강남구 학동로 343 더 피나클 강남 16-17층) 전제**다. 제2 사업장 FADU 평촌 Lab(안양)·미국 Santa Clara 오피스가 따로 있고, 평촌 계약직 공고는 「점심 식대 별도 지원」으로 복지 페이지와 조건이 다르다. 행 서술에는 원문에 없는 범위 한정을 덧붙이지 않았고(허위가 되므로), 대신 SQL 헤더 주석에 남겼다.
