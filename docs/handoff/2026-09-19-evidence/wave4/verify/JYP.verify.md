## 4. 신규 코드 `smoking_cessation` ↔ 피에스케이 `nonsmoking_bonus`

- 실측: `wave4/피에스케이.sql` SORT 53 `('nonsmoking_bonus', '금연수당', NULL, 'health', … '금연수당 지급 … (그룹 통합 채용 기준)')`. 같은 웨이브에서 같은 뜻(금연 현금 인센티브)에 신규 코드 **2개**가 생겼다 — 그대로 두면 두 회사가 서로 비교되지 않는다.
- 코퍼스 선례(표본 확인): 테크윙 `clinic` 「건강관리실 운영(정규직 간호사), 금연수당 지원」 · 엠씨넥스 `clinic` 「건강관리 프로그램·금연펀드 운영 …」 · LIG넥스원 `mental` 「… 금연/다이어트 캠페인」 — evidence 의 인용 2건은 **실재한다**. 전부 다른 행에 병기였고 독립 코드는 없었다.
- **권고: `smoking_cessation`(health) 하나로 통일.** 이유: 금연 지원은 축하금(JYP)·수당(피에스케이)·펀드(엠씨넥스)·캠페인(LIG)으로 형태가 갈리는데 `nonsmoking_bonus` 는 현금형만 뜻하고 `smoking_cessation` 은 전부 받는다. 대표 명칭 「금연 지원(축하금·수당)」. 피에스케이 SORT 53 을 `smoking_cessation` 으로 재코딩(BENEFIT_NM 「금연수당」 유지).
- 감사가 신규 코드 자체를 거부하면: JYP SORT 72 삭제 + SORT 70 서술 말미 「, 금연 성공 축하금 지급」 추가(19행). 피에스케이는 그쪽 검증 몫.
- 부수 확인: 「금연 성공 축하금」은 1회성 지급 → AMT NULL 이 맞다(웨이브 4 규칙 4 확장).
