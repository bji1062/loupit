## 집행 규칙
1. **삭제**는 행 튜플 전체 제거 후 SORT 를 다시 매기지 않는다(구멍 허용). 마지막 행의 `,`/`;` 처리로 문법을 깨지 말 것.
2. **병합**은 남는 행의 QUAL_DESC 에 흡수되는 제도의 원문 문구를 덧붙이고(「/」 구분 금지 — 「·」 또는 문장), BENEFIT_NM 은 필요하면 병기.
3. **재코딩**은 코드·카테고리·SORT 섹션을 함께 옮긴다(카테고리별 10단위 섹션 규칙).
4. **편집 주석 일소**: QUAL_DESC_CTNT·NOTE_CTNT·BENEFIT_NM 에서 「코퍼스」「선례」「어휘표」「규칙」「수집기」「검증」「병합」「미수록」「회피」「흡수」「정본」「판독」「시드」「SI-B2」「별도 행」「합쳤다」「수록」「정성 항목」「부연」「우리 판단」「⚠」 등 내부·공정 용어와 법정 제도 문구를 없앤다. 허용 문안은 **원문 라벨 + 출처 페이지명(「공식 채용 페이지 … 항목」 등) + 조건 + 미기재 사항**뿐. 감사·verify 가 준 대체 문안이 있으면 그대로, 없으면 같은 정책으로 최소 수정. 「(그룹 통합 채용 기준)」·「(… 공통 채용 기준)」 각주는 귀속의 전제라 **절대 지우지 않는다**.
5. **금지**: 새 행 추가(MISSED 반영도 감사가 「흡수」로 지시한 경우 기존 행 서술에만), 금액 변경(감사 §3 지시 외), 홑·겹따옴표(아포스트로피는 U+2019 ’), 코드 중복, 목록에 없는 개선.
