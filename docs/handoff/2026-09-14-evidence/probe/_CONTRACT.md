## 판정 기준 (전부 만족해야 「가능」)

1. **공식 출처만**: 회사 자기 도메인, 또는 회사명이 붙은 전용 채용 서브도메인(예 `hankooktire.recruiter.co.kr`, `careers.kbfg.com`).
   그룹 공통 채용사이트(예 samsungcareers·hanwhain·careers.lg.com)는 **해당 법인이 채용 주체로 식별되는 페이지**일 때만 인정하고,
   귀속 경로(어느 메뉴·필터에서 이 법인 이름이 나오는지)를 기록한다. 법인 전용 페이지라는 증거로 형제 법인 페이지와 항목이 다른지 대조한다(웨이브 2: samsungcareers E21·C60·D80 라벨 불일치로 템플릿 아님 입증).
   그룹 공통 복지만 있고 법인 구분이 없거나 「계열사별 상이」 면책이 붙으면 「조건부」로 내리고 근거를 적는다.
   사람인·잡코리아·잡플래닛·캐치·인크루트·블라인드·크레딧잡·원티드 등 3자 사이트는 **출처가 아니다**(참고 인용도 금지).
2. **법인 일치**: 등록 대상은 상장 법인 그 자체. 지주 ≠ 자회사, 계열사 ≠ 그룹. 다른 법인 페이지를 갖다 붙이면 불가.
   **금융지주**: 은행지주 3사(하나·우리·신한)는 지주가 채용 주체로 등재되지 않아 불가였다. 예외는 KB금융(그룹 채용사이트에 지주가 채용 주체로 등재). 지주는 이 조건을 먼저 확인한다.
3. **복지 항목이 명시적**: 항목명이 나열돼 있어야 한다(가치관·인재상·교육 커리큘럼만 있으면 항목 0 취급).
   개수·카테고리·예시 2개를 적고, 텍스트(HTML)인지 이미지 안인지 JS 렌더인지 표시한다. 금액 명시가 있으면 따로 적는다.
4. **robots 허용**: `robots.txt` 를 `*` 와 AI 봇 UA(ClaudeBot·anthropic-ai·GPTBot·CCBot·Google-Extended) 각각에 대해 해당 경로 기준으로 판정. 404 = 허용. BOM 유무 기록.
   `*` 가 경로를 막으면 본문을 가져오지 말고 「불가(robots)」로 끝낸다.
   ⚠ UA 줄 여러 개가 한 레코드로 묶인 robots(웨이브 2 신한)는 UA 줄마다 그룹을 끊으면 정반대 판정이 난다 — 레코드 단위로 읽는다.
5. **접근성**: HTTP 상태·본문 크기·응답시간, SSR/SPA(원본 HTML 에 복지 텍스트가 있는가 — 없으면 `__NEXT_DATA__`·JSON API·JS 번들 중 어디에 있는지),
   봇 차단(WAF·캡차·UA 차단), TLS(curl exit code·구형 TLS 여부), 인코딩(UTF-8/EUC-KR/cp949), www/apex 차이.
6. **재무·직원 3축**: 등록 기준은 복지+재무+직원 3축 전부다. DART 설립일이 최근이거나 사업보고서 이력이 짧아 보이면 판정문에 적는다(리드가 확인한다).

## 알려진 함정 (반드시 점검)

- **차단이 200 으로 온다**: 본문 <2KB 또는 「접근 차단·Access Denied·Request Blocked·deny·WAF·비정상 접근·잘못된 페이지 접근」 키워드면 차단으로 본다
  (웨이브 1: hdec.kr 939B·koreazinc EUC-KR 안내문 / 웨이브 2: 삼양식품 352B EUC-KR 「Request Blocked」·대우건설 209B 한글 안내 — 영문 키워드로는 못 잡는다).
- **UA 문자열 차단**: UA 에 `curl`·`GPTBot`·`CCBot` 이 들어가면 막거나 302 디코이로 보내는 사이트가 있다(삼양식품·동진쎄미켐) — 반드시 아래 일반 브라우저 UA 를 쓴다.
- **HEAD 를 믿지 마라**: HEAD 400·405·404 인데 GET 200 인 사이트가 여럿이다(삼성중공업·넷마블·삼양식품). 생존·판정은 GET 로만.
- **soft-404**: 200 인데 오류/빈 페이지.
- **DART hm_url 오염**: 리드가 준 hm_url 이 죽은 `.co.kr`·NXDOMAIN·거래 전용 사이트(증권사 HTS 포털 등)일 수 있다 — DNS·실응답으로 생존을 확인하고 실제 회사 소개·채용 도메인을 찾아 적는다. apex 무응답이면 `www.`, 고객 포털이 막히면 `company.`·`careers.`·`recruit.` 서브도메인도 본다(웨이브 2: 한화생명 www 는 고객 포털+TLS 실패 → company. 서브도메인).
- **SPA**: `curl` 원본에 항목이 없으면 Playwright 로 렌더해 확인(`python3 -c "from playwright.sync_api import sync_playwright"`). 렌더 후에도 없으면 번들·API 를 찾아 경로를 적는다. 헤드리스라도 UA 는 일반 브라우저 문자열.
- **CSS 로 숨긴 탭**: 가시 텍스트로는 0개인데 원본 HTML 에는 있는 경우(넷마블 복리후생 탭) — 원본 HTML 도 반드시 본다.
- **이미지 안 항목**: PNG/JPEG 안에만 있으면 이미지 URL·크기·HTTP 200 을 적고 「조건부(이미지 판독)」. 판독 가능한 해상도인지도 적는다.
- **유령 항목**: HTML 주석 속 옛 블록(LG이노텍)·ATS 의 샘플 템플릿 페이지(KAI 선례: `recruiter.co.kr/career/welfare` 가 다른 회사 샘플)·특정 직군 전용 처우 페이지(연구위원 전용)·캐러셀 중복 — 태그 제거 파싱 전에 주석을 걷어내고, 템플릿이면 회사명·고유 문구로 귀속을 확인한다.
- **그룹 sitemap**: robots 의 Sitemap 이 그룹 것이라 다른 법인 페이지로 샐 수 있다(이수페타시스).
- **robots 의 AI 봇 명시 차단**(네패스 선례): `*` 는 허용이라도 AI 봇 UA 만 차단하면 그 사실을 판정문 첫 줄에 적는다(선발 단계에서 결정).
