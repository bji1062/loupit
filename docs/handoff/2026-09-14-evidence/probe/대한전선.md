## 수집 설계 시 유의

1. **정본은 자기 도메인 `www.taihan.com/company/talentSystem` 하나다.** 「채용정보」(`/company/jobs`)에는 복지가 없고 호반그룹 채용사이트로 내보내므로, 채용 메뉴를 따라가면 그룹 공통 복지 페이지에 닿는다. **그룹 「사내 복지」 약 20개를 대한전선 카드에 붙이지 말 것** — 대한전선 언급 0회인 그룹 서술이고, 대한전선 자체 목록과 항목이 다르다(태교여행·난임시술·사내헬스장 등은 대한전선 페이지에 없다).
2. **파싱 단위는 `ul.list-summary.v2 > li > dl`** 의 `dt`(항목명)·`dd`(설명). `dt` 안의 `<span class="mo-display">01 </span>` 번호 접두를 떼야 항목명이 깨끗하고, `dd` 의 `<br>` 는 공백으로 합칠 것. 같은 `li` 안에 아이콘 `div` 가 모바일·PC 용으로 두 번 있지만 텍스트가 없어 중복 항목은 생기지 않는다.
3. **「휴양시설: 리솜리조트(계열사 혜택)」** 는 원문이 스스로 그룹 계열사 혜택이라고 표시한 항목이다. 대한전선 페이지가 자기 복지로 게재했으므로 수록은 가능하나, 설명문 원문 그대로 보존해 계열사 혜택이라는 단서를 지우지 말 것.
4. **분량 기여는 작다**(8항목·278자, 금액 0건, 카테고리 없음). 블록 주석이 `2022-10-14`·`2022-10-26` 수정 표식에서 멈춰 있어 **내용이 2022년 기준일 가능성**이 있다 — 게재일을 「현재 공식 페이지 기준」으로만 적고 시행 시점을 단정하지 말 것.
5. **TLS 인증서가 2026-09-29 만료**(프로브일 +15일). 수집이 그 이후라면 갱신 여부를 먼저 확인하고, 검증 실패 시 `-k` 로 우회하지 말고 보류할 것. 호출 규약: `www.` 로 직접 호출(apex 는 301), GET 기준, 요청 간 ≥1초. `hoban.recruiter.co.kr` 은 robots `Disallow: /` 이므로 어떤 경로도 수집 금지.
