1. **수집 경로 = `getMainView` POST 1회**. 원본 HTML 은 0건이고, 헤드리스 렌더는 robots 금지 경로(`/resources-2.0.3a/*.js`·`/app/*`)를 끌어온다. 허용 경로인 `POST /appsite/company/getMainView`(`appsiteSn=2331&settingType=B`, 쿠키 불필요)만 호출해 `menuCode=="4600" && useYn==1` 메뉴를 **코드로** 고르고(배열 인덱스 `menuList[4].childMenuList[2]` 는 메뉴 순서가 바뀌면 깨진다) `contents` 를 HTML 파서로 `h2`=카테고리 / `li`=항목으로 읽는다. 갱신 감지는 이 `contents` 해시로 — JSON 에 메뉴 수정일 필드가 없고 사이트 생성일이 `2018-08-02`, 머리 사진 경로도 `201808` 이라 게재 시점을 알 수 없다.
2. **robots 파서를 파이썬 `urllib.robotparser` 로 쓰면 「불가」로 오판**한다(첫 일치 규칙 → `Disallow: /` 우선). RFC 9309 최장 일치(`Allow: /appsite/` 승)로 판정할 것. 반대로 「어차피 허용」이라며 렌더로 가면 금지 경로를 밟는다.
3. **벤더 샘플 유령 콘텐츠가 같은 JSON 에 있다.** 비활성(`useYn 0`) 메뉴 4500 「평가 및 보상」에 「마이다스아이티의 연봉체계는 2014년 대졸 신입 기준 최소 4,000만원… 상여금」, 4400 「직급체계」에 「자동승진·종신고용」 등 **마이다스아이티(ATS 벤더) 샘플 문구**가 남아 있고, 활성 메뉴 2200 지원서 수정·2800 마이페이지 머리말에도 벤더 샘플 문장이 있다(JSON 전체 「마이다스」 17회). 메뉴 전체를 키워드로 훑으면 벤더 회사의 연봉·승진 제도를 가온전선 것으로 적게 된다 → **4600 만** 읽고, `headerContents` 에 「가온전선」이 있는지 법인 검증을 넣을 것.
4. **항목 정리**: 13개 전부 라벨만(설명·금액 없음, 조건은 「만 35세 이상」 하나)이라 본문 분량 기여는 작다. `li` 4개가 제도 두 개를 묶고 있다(`주택구입자금 및 전세자금`·`콘도미니엄, 팬션`·`하기휴가, 하기휴가비`·`경조 휴가 및 경조금`) → 쪼갤지 결정 필요. `&nbsp;` 정규화, `팬션`→펜션은 원문 보존 필드를 따로 둘 것.
5. **LS 그룹 공통(`lsholdings.com`)·LS ELECTRIC 항목과 섞지 말 것.** 그룹 페이지는 「각 계열사 별 차이」 면책이 붙은 서술이고 가온전선 항목과 다르다(② 대조). ATS 인증서 `*.recruiter.co.kr` 2027-01-06 만료, 자기 도메인은 Let's Encrypt 90일 주기.
