1. **정본은 자기 도메인 국문판 `/ko/careers` 12항목**이다. 그룹 법인 페이지(HRF102040) 13항목도 법인 전용이라 공식 출처 자격은 되지만, 두 목록이 절반쯤만 겹친다. 합칠 거라면 **항목마다 출처 URL 을 따로 달고**, 그룹 페이지에만 있는 항목(직장 어린이집·임직원 대출·우리사주제도·통근버스·선택적 복지)은 단일 출처로 표시할 것. 겹치는 항목은 표현만 다르다(사택↔기숙사 등). 중복으로 세지 말고 하나로 합칠 것.
2. **그룹 채용사이트는 TLS 체인이 불완전하다.** 기본 CA 번들로는 curl·requests 가 exit 60 으로 실패한다. `-k`/`verify=False` 로 우회하지 말고 Sectigo DV R36 중간 인증서를 번들에 넣어 검증할 것. 인증서가 2026-11-20 에 만료되니 그 뒤에 재수집한다면 다시 확인. 평문 HTTP 200 은 무결성이 보장되지 않으니 쓰지 말 것.
3. **영문판은 정본이 아니다.** 「복지몰 운영 ↔ Selective welfare system」처럼 다른 제도로 번역돼 있다. 국문 원문 오타 「반원」→「반월」은 정규화하되 원문도 보존할 것.
4. **법인 식별은 URL 코드 + `h2.name`** 으로 한다. HRF 코드(에스티팜 = HRF102040)는 목록 순서형 번호라, 계열사가 추가·삭제되면 밀릴 수 있다. 제목은 전 계열사가 같다. 파싱할 때 `h2.name == 에스티팜` 을 반드시 검증할 것.
5. **`donga.recruiter.co.kr`(그룹 ATS)는 robots 전면 금지**라 공고 본문은 수집 경로에서 뺄 것. `www.stpharm.com` 은 주차 도메인이라 출처 후보에서 영구 제외.
