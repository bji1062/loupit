## 4. 코드 매핑 판단 · 어휘 함정 회피

### 신규 코드 — 1개: `weekend_farm` (leisure)

- 원문: A 「가족 주말농장 제공」 / B 「임직원들의 가족과 이용할 수 있는 주말농장을 제공합니다.」 — 원문이 혜택 내용(가족이 이용하는 주말농장을 **제공**)을 밝힌다.
- 어휘 86종 대조: `company_event`(야유회·가족 초청 행사 — **행사**) · `resort`(휴양시설·숙박) · `leisure_room`(카지노룸 — 사내 여가실) · `guest_house`(영빈관) · `travel_support` · `culture_day` 어느 것도 「경작용 텃밭·농장 분양」 뜻이 아니다. 코퍼스 SQL 전수 `grep 주말농장` **0건**.
- 기각한 대안: **`company_event` 서술에 흡수** — 가족 친화 프로그램 행과 합치면 행 수는 22 가 되고 코드 신설이 없다. 하지만 주말농장은 회차형 행사가 아니라 상시 제공되는 시설이고, 원문도 「가족 친화 프로그램 운영」과 **별개 항목**으로 나열한다. 계약 규칙 9(병합은 같은 코드로 귀결되는 항목만)에 비춰 억지 병합이라 판단했다. 검수자가 신규 코드를 원치 않으면 SORT 74 를 지우고 SORT 73 서술에 「, 가족과 이용할 수 있는 주말농장 제공」을 붙이면 된다(비교축 영향 없음 — `company_event` 는 이미 이 회사에 있다).
- 운영 영향: 코드 → 표시명은 번들에서 파생된다(`generator/pages/find.py` 의 `derive_codes` — 별도 코드 마스터 없음, `db/schema.sql` 의 `BENEFIT_CD` 는 FK 없는 VARCHAR(30)). §9 배포 주의 참조.

### 어휘 함정 회피

- **`housing_loan`(10)** — B 가 「주택 구입 및 전세 자금 **대출**을 지원」이라 대출·이자 축. 현금 주거비(`housing_support`)가 아니다(규칙 8-2). 한도·이율 미기재.
- **`dormitory`(20) / `transport`(11) 분해** — 「사택 및 교통비 지원」은 두 제도 병기. 사택 = 주거 **시설**이라 `dormitory`(규칙 8-2, `housing_support` 아님). 교통비는 어휘표 `transport`(대표 명칭 「교통비 지원」)이지 통근버스·셔틀 축 `commute_subsidy` 가 아니다. ⚠ 라벨뿐이라 사택이 지방·원거리 발령자 한정인지, 교통비가 사택 입주자 대상인지 원문이 밝히지 않는다 — 한정이 없으니 지우지 않았고, 대상 미기재를 서술에 적었다.
- **`long_service_leave`(40) / `long_service_bonus`(50) 분리** — 규칙 5 함정 그대로: 휴가는 `long_service_leave`, 휴가비(현금)는 `long_service_bonus`. 형제 삼성화재·삼성E&A 시드와 같은 분리.
- **`event`(30) + 결혼 도움방** — 규칙 8-2: 예식장 대관은 `event` 서술(`wedding` 은 현금 축하금+휴가 축). 삼성E&A 검증 반영과 같은 처리.
- **`health_check`(60)** — 「종합 건강 검진(배우자 포함)」과 「생애주기 검진(PET-CT)」은 같은 검진 축이라 한 행.
- **`mental`(63) + 힐링 명상 교육** — B 설명이 「임직원들의 **마음 건강**을 위해 힐링캠프 등을 운영」이라 마음 건강 프로그램. `lounge`·`nap_room` 은 공간(명상**실**) 코드라 해당 없음(이건 프로그램이다). 규칙 8 의 「회사 주도 교육 커리큘럼」은 직무·자기계발 교육을 겨냥한 규칙이고 이 항목은 건강 프로그램이라 제외하지 않았다. 병합이라 비교축을 새로 세우지 않는다(`mental` 은 심리 상담 센터로 이미 성립).
- **`child_edu`(33) 4 라벨 병합** — 학자금·교복비는 자녀 교육비, 취학 축하/수능 격려 선물은 형제 삼성화재(「취학 자녀 축하 선물」)와 이수페타시스(「수능 격려품」)가 `child_edu` 에 둔 유형. ⚠ 「자녀 문화/예술 활동 경험 지원」은 라벨뿐이라 비용 지원인지 체험 행사인지 원문이 밝히지 않는다. 정본이 「자녀 교육 지원」 카테고리에 두었고 형제 삼성카드가 「자녀소양개발비」를 `child_edu` 에 둔 것을 따라 흡수했다. 대안은 `company_event` 서술 흡수(역시 행 추가 없음).
- **`parenting`(31)** — 「출산선물, 돌반지 지원」은 출산 축하 물품. `fertility_support`(난임) 아님.
- **`company_event`(73)** — 「가족 친화 프로그램」은 자녀와 함께하는 프로그램 = 행사 축. **`family_day`(조기퇴근) 안 씀**(규칙 5).
- **`leisure_ticket`(71) vs `resort`(70)** — 캐리비안베이 이용권(워터파크 티켓)과 전국 리조트 이용(휴양소)은 원문이 별개 항목. 형제 삼성화재와 같은 코드 배치.
- **`fitness`(62)** — 「휘트니스」=「피트니스」 표기 차이.
- **`edu_support`(81)** — 자격 취득 지원금. 형제 삼성화재·삼성카드가 같은 제도를 `edu_support` 로 둔 것에 코드를 맞췄다(`self_development` 아님). 행 문안은 복사하지 않고 이 회사 원문(증권업 자격 · 8종 · 45종)으로 새로 썼다.
- **`mba`(82) + 지역전문가** — 규칙 8-1: 금융석사 = 학위 → `mba`. 지역전문가 = 해외 파견형 → 이 회사에 `career` 행이 없으므로 `mba` 서술에 흡수(행 신설 금지). ⚠ 금융석사과정 설명문은 형제 E31 삼성카드와 **문구가 같다**(프로브 대조) — 금융 계열이 공유하는 교육 프로그램일 수 있다. 그러나 삼성증권 법인 전용 섹션에 삼성증권 제도로 나열돼 있어 귀속은 유지했다.
- **`lang`(80)** — B 는 「운영 및 지원」이라 비용 문구가 약하지만, 자기 도메인 C 가 「어학 학습 및 어학 등급 취득 관련 **비용 지원**」을 명시 → 규칙 8 통과.
- **`books`(83)** — 「개인 도서 구입비를 지원」 = 명시적 비용 지원. C 의 「주경야독 (직원 독서 활동 지원 프로그램)」은 프로그램이라 이 행 근거로 쓰지 않았다.
- **`meal`·`uniform`·`work_tools`·`insurance`·`pension_support`·`smart_office`·`family_day`** — 원문에 해당 제도가 없어 사용 0.

## 9. 배포 시 주의

- **신규 회사** — `INSERT IGNORE INTO TCOMPANY` 가 실제 등록. 적재 후 **정적 페이지 재생성 필수**. 회사 등록 이력 파일 `generator/data/company_registrations.json` 에 새 웨이브 항목 추가 필수 — 그 파일 `_doc` 의 경고대로 `generator/tests/test_home_page.py` 가 시드 SQL 의 회사 전부가 정확히 한 번 실렸는지 강제한다(통합 단계 소관).
- **신규 코드 `weekend_farm`** — 코드 마스터 테이블이 없어 적재 자체는 막히지 않는다. 다만 `generator/tests/data/find_label_cases.json` 은 「reference/all 2026-09-06 · 코드 86종」 스냅숏이고 `generator/tests/test_find_page.py::test_real_bundle_labels_match_the_shared_fixture` 가 `len(cases["codes"]) == 86`, `web/assets/js/find.test.js` 가 `assert.equal(entries.length, 86, …)` 을 못 박는다. 픽스처를 실번들에서 다시 뽑으면 87종이 되어 두 단언을 함께 갱신해야 한다. 표시명은 번들 파생이라 「가족 주말농장」이 그대로 라벨이 된다. `_VOCAB.md` 에도 1행 추가 필요.
- **CAREERS_BENEFIT_URL** — 자기 도메인 A(프래그먼트 없음). B 는 보조라 URL 칸에 넣지 않았다.
- **갱신 감지는 블록 해시로** — A 는 `<title>` 서버 노드 표기(`[A1]`/`[A3]`)와 CSS·JS 13자리 캐시버스터가 요청마다 바뀌고, B 는 `?v=1.MTS4W…` 캐시버스터와 채용공고 카운트다운이 바뀐다. 전체 해시가 아니라 A `div.benefit`, B `ul.welfareList` 슬라이스로 비교(§1 해시). B 는 파싱 전 h2 의 「삼성증권」과 `ss.recruit@samsung.com` 으로 법인 확인 — E40 코드가 바뀌면 다른 법인을 조용히 긁는다.
