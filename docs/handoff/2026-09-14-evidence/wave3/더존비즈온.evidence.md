## 9. 검증자가 볼 곳

1. **`fitness` 코드(SORT 12)** — 존재·거점은 B(법인 명시), 코드를 가르는 유일한 내용 단서 「필라테스」는 A(그룹 표기). 서술에서 그 세부를 「더존ICT그룹 복리후생제도 페이지는 … 헬스케어센터(필라테스)로 표기」로 출처를 붙여 분리했고 그룹 각주는 달지 않았다(존재가 법인 명시라 ① 분류). 그룹 세부를 쓰는 것 자체를 문제 삼으면 대안은 필라테스 문구 삭제 + 코드 재판단(`clinic` 후보 — 그러나 의료 서술 근거 0).
2. **「개인별 교육」 제외** — 동사가 「지원합니다」로 도서구매와 공유된다. 비용 지원으로 읽으면 `edu_support` / growth / SORT 31 / 「개인별 교육 지원」 1행 추가(15행), 그룹 각주 없음(A4 = B4).
3. **`summer_leave`(SORT 50)** — 「연차와 별도」가 명시되지 않은 하계휴가다. 같은 문장에 연차휴가와 병렬 나열된 것만이 별개 휴가라는 근거다. 엄격 판정이면 삭제(13행).
4. **`holiday_gift` 카테고리 perks** — compensation 로 뒤집으면 섹션 70 신설로 SORT 이동.
5. **공고 만료 리스크** — B 는 2026-09-16 23시 마감. 이후 사용자는 ①·② 행 출처 공고를 열 수 없다. 이미지 사본 해시(§1)가 유일한 재확인 경로. 재수집 시 새 공고의 복리후생제도 섹션으로 교체 확인 필요.
