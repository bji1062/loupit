## 알게 된 것

### 덕산네오룩스의 메일 도메인은 `dsnl.co.kr` 이 아니라 `oneduksan.com` 이다

회사 사이트에는 여전히 게시 이메일이 0건이다. 도메인은 **제3자가 재게시한 회사 문서**에서 나왔다.

- 호서대 반도체공학과 게시 PDF — 덕산네오룩스㈜ 대표이사 명의 채용 인재추천 요청 공문.
  "이메일 접수(제출처: `*******@oneduksan.com`)", 첨부 `DSNL_입사지원서_연구직`,
  발신 주소 = 천안 본사(충남 천안시 서북구 입장면 쑥골길 21-32).
  <https://semiconductor.hoseo.ac.kr/File/Download.do?dir=board&savename=20230904161137_093235043773>
- DART 대량보유상황보고서(등기임원 이수훈) 보고자 이메일 `******@oneduksan.com`, 전화 `041-59**`.
  <https://www.digitaltoday.co.kr/news/articleView.html?idxno=660679>

### 그런데 그게 **등록하지 않은 이유**다 — 그룹 공용 도메인이다

- `gw.oneduksan.com` = 덕산 **그룹웨어** 메일(`/Mail/Default.aspx`)
- `recruit.oneduksan.com` 수집동의문 = "**덕산홀딩스㈜ 및 덕산계열사**", 공고 목록에
  솔더 조성·전해도금·미립자 도금 등 **덕산하이메탈 직무**가 섞여 있다
  <https://recruit.oneduksan.com/Receipt/Recruit_Start_allTimes.aspx>
- `sd.oneduksan.com` = **덕산하이메탈** 보안파일 관리

우리 목록의 덕산 계열은 덕산네오룩스 하나뿐이라, 등록하면 덕산홀딩스·하이메탈·테코피아·
에테르씨티·현대중공업터보기계 임직원이 **전원 덕산네오룩스 재직자로 자동 인증**된다.
`cj.net` 이 계열사 1곳뿐이던 시절과 같은 구조이고, 그건 시드 주석이 "가장 심한 사례"로
기록해 둔 것이다. 이 트레이드오프는 삼성·SK·한화·CJ·LG 때 전부 **사용자 결정**으로
처리됐으므로 임의로 넣지 않았다.

### HPSP 사이트에는 함정이 있다 (다음 사람 주의)

`thehpsp.com/bbs/board.php?bo_table=contact` 는 회사 연락처 페이지가 아니라 **외부인이 글을
올리는 문의 게시판**이다(실제 글: "[키움증권 리서치센터] 컨퍼런스 콜 요청 안내"). 거기서
이메일을 발견해도 그건 증권사 애널리스트 주소지 HPSP 임직원 주소가 아니다 — 현대제철
`partners-steel.kr` 과 같은 부류다.

## ⚠ 이 세션의 조사 한계

실행 환경의 외부 egress 가 **전면 차단**됐다(회사 사이트·DART·PRNewswire 모두 CONNECT 403).
1차 출처를 직접 열지 못했고, 위 근거는 전부 검색엔진(Naver 웹검색·웹검색) 스니펫이다.
그래서 **"등록한다" 쪽으로는 한 건도 쓰지 않았다** — 스니펫은 1차 출처가 아니다.
"등록하지 않는다"는 판단에는 이 수준으로 충분하다(비가역인 쪽은 등록뿐이다).

## 남긴 것 (미결)

1. **덕산네오룩스 `oneduksan.com` 등록 여부 — 사용자 결정 대기.** 넣기로 하면 시드에 한 줄이면
   되고(SED-5 통과), 해당 SQL 은 시드 주석에 그대로 적어 뒀다. ⚠ 넣기 전에 egress 가 열린
   환경에서 위 두 근거를 **직접 열어 재확인**할 것.
2. **HPSP** — 새 채널이 열리기 전에는 진전 없음. 재조사 시 대학 취업지원센터 공문 PDF·
   ESG 보고서 문의처·DART 보고자 연락처 서식을 먼저 보라(회사 사이트는 이미 0건 확인됨).

   HPSP=근거 없음 / 덕산네오룩스=**결정 대기**. 정본 갱신 권한이 있는 쪽에서 반영해 달라.
