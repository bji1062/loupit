- **결정(사용자): 수집은 웨이브 2와 같이 xhigh 로 진행.** 다음 웨이브에서 effort 를 낮추려면 웨이브 시작 전에 사용자가 전역 설정을 바꾸거나 새 세션에서 정의 파일이 읽히게 한 뒤, 첫 투입 트랜스크립트의 `"effort":` 로 확인한다.

## 함정 (이 웨이브 신규)

- **세션 중에 만든 에이전트 정의는 읽히지 않고, 팀원 투입은 없는 유형을 조용히 일반 팀원으로 띄운다** — 위 「모델·effort」.
- **robots 와 본문을 한 배치로 보내면 금지 경로에 샌다** — 프로브 4곳(에스티팜·대한전선·포스코퓨처엠·가온전선)이 robots 판독 전에 금지 호스트·경로에 1~3회 요청(전부 오류·빈 응답, 근거 미사용). 계약에 「robots.txt 단독 선확인」 명시.
- **파이썬 `urllib.robotparser` 는 첫 일치 규칙이라 RFC 9309(가장 긴 일치)와 판정이 반대로 나온다** — 가온전선 `Disallow: /` + `Allow: /appsite/`.
- **헤드리스 렌더의 하위 리소스도 요청 수·robots 판정에 든다** — 키움증권 50회(한도 40), 가온전선 금지 경로 JS.
- **ATS JSON 의 비활성 메뉴에 벤더 샘플 문구가 남아 있다** — 가온전선 menuCode 4400·4500(「2014년 대졸 최소 4,000만원」·종신고용). 활성 메뉴만 읽는다.
- **증권사 hm_url 은 거래 포털이다** — 키움(www3 리다이렉트 껍데기)·삼성(samsungpop)·미래에셋(EUC-KR 프레임셋). 회사 도메인은 따로 찾는다(인증서 사업자번호 = 푸터 번호로 귀속 확인).
- **복지 페이지가 채용 메뉴가 아닌 곳에 있다** — SK바이오팜은 지속가능경영 > ESG, 대한전선은 COMPANY > 인재경영.
- **그룹 메일 게이트웨이 MX 는 법인 구분 근거가 아니다** — 대한전선 MX = ihoban.co.kr, 포스코퓨처엠 MX = antispam.posco.net.
- **채용공고의 복리후생 블록은 공고 템플릿의 그룹 공통 문단일 수 있다** — 더존비즈온 공고(모집회사=더존비즈온)와 키컴 공고의 복리후생 9카드가 글자·아이콘·순서까지 동일. 「모집회사」 칸만으로 법인 귀속을 확정하지 말고 형제 법인 공고 1건과 대조한다.
