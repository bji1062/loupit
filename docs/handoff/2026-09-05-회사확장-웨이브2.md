## 함정 (이 웨이브 신규)

- **세션 한도가 에이전트를 중간에 끊는다** — 수집 13 중 8, 검증·감사 각 1이 최종 보고 직전에 중단됐다. 산출물을 먼저 쓰고 보고는 나중에(「SQL 먼저, evidence 다음」) 시키면 재투입 비용이 0에 가깝다. KAI 만 SQL 전 단계에서 끊겨 재수집.
- **수집 계약의 LOGO_NM 지시가 틀렸다**(한글 초성 → 실제 관례는 영문 이니셜 K·S·L). 13건 일괄 교정. 계약은 코퍼스 실측으로 검증하고 쓸 것.
- **INDUSTRY_NM 은 자유 텍스트지만 trending.js 폴백 쌍의 그룹핑 키** — 「손해보험」「생명보험」「플랜트 엔지니어링」「조선·해양」「항공우주·방산」을 기존 값(보험·건설·조선·항공/방산)에 합류시켜야 쌍이 생긴다.
- **corp_code_map 의 DART 명은 홑따옴표 필수**(`_DART_NM_RE`) — 없으면 조용히 comp_nm 폴백. FN1 테스트에 3사 추가로 못박음.
- **CSV 두 파일은 CRLF·LF 혼재** — 텍스트 모드로 읽고 쓰면 200줄 diff 가 난다. 바이너리 append.
- **차단·소프트 404 변종**: 삼양식품 WAF 는 UA 에 `curl`·`GPTBot`·`CCBot` 문자열이 들면 200+352B EUC-KR 「Request Blocked」 · 동진쎄미켐은 `CCBot` UA 를 302 디코이로 · 삼성중공업 HEAD 400/robots 200 HTML · 넷마블 HEAD 405 · 삼양식품 HEAD 404 · 대우건설 209B 「잘못된 페이지 접근입니다」(영문 deny 키워드로 못 잡음). 생존 확인은 GET 만(`link-audit.py` 예외 필요 — L-5).
