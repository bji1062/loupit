# 체크리스트 — AdSense 승인이 나면 할 일

> **왜 별도 문서인가.** 승인은 몇 달 뒤일 수 있고, 그때 이 결정들의 맥락은 흩어진 문서 수십 곳에
> 남아 있다. 잊으면 **코드와 처리방침이 어긋난 채로 광고가 나간다** — 그 상태는 되돌리기 전까지
> 계속 허위 고지다. 이 파일 하나만 열면 순서대로 할 수 있게 모아 둔다.
>
> **현재 상태(2026-08-28)**: 애드센스 **거절**(2026-08-21 확인, 사유 = 콘텐츠 얄팍함).
> pub-ID `ca-pub-6009927622334159` 는 발급돼 있고 로더 배선도 살아 있다. **슬롯 ID 는 아직 없다.**
> 재신청 전 선행 과제는 콘텐츠 두께다 — 회사 페이지 본문 중앙값 1,402 → **1,610자**(재무 반영 후),
> 1,000자 미만 20 → 7개. 관련: `PLAN-회사정보-확장-2026-08-21.md`, 메모리 `loupit-content-thinness`.

## 0. 재신청 전 (승인과 무관하게 지금 할 수 있는 것)

- [ ] 콘텐츠 두께 추가 확보 — 뉴스 축(계획 5단계)·설명문. 재무 표는 글자 수가 적어 1,610자에서 멈췄다.
- [ ] 커뮤니티에 실제 글 유입(SC15) — UGC 는 애드센스 심사에서 양날이라 **검수 없는 상태로 광고를 붙이지 않는다**(아래 3번).

## 1. 개인화 광고를 켤 것인가 — **순서를 지켜야 한다**

지금은 동의 UI 가 없고 광고를 **항상 비개인화**로 요청한다(`applyConsentSignal` 상수 1).
배경·근거: [DECISION-동의배너-제거-2026-08-28](DECISION-동의배너-제거-2026-08-28.md).

개인화를 켜려면 **이 순서 그대로**:

1. [ ] AdSense 대시보드 → **개인정보 보호 및 메시지(Privacy & messaging)** → GDPR 메시지 활성.
       (구글 **인증 CMP** 다. 자체 배너는 TCF 신호를 못 만들어 EEA·영국 요건을 못 채운다.)
2. [ ] `web/assets/js/ads.js` `applyConsentSignal` 을 그 동의 신호에 연동(현재는 상수 1).
3. [ ] **같은 커밋에서** 처리방침 **P4**·광고고지 **A-4** 문안을 "구글 동의 메시지로 동의/거부" 로 갱신
       (`generator/content/policy.py`). 코드가 문안보다 먼저 가면 그 순간부터 허위 기재다(함정 (61) 계열).
4. [ ] 자체 배너를 되살리지 않는다 — 되살리면 `test_policy_pages` GC-24 가 빨개진다(배너 부재가 계약).
5. [ ] 재생성 + 배포 후 `/privacy#p4`·`/ads#a4` 문안과 실제 동작이 같은지 눈으로 확인.

**켜지 않아도 된다.** 비개인화 광고는 단가가 낮지만 동의 관리 부담이 없다 — 트래픽이 작은 동안은
그대로 두는 것도 합리적 선택이다.

## 2. 슬롯 ID 치환 (승인 직후 필수)

승인 전에는 슬롯 ID 가 발급되지 않아 `AD_SLOT.*` 이 전부 플레이스홀더(`XXXXXXXXXX`)이고,
`mountManualSlot` 이 **수동 슬롯을 렌더하지 않는다**(빈 '광고' 점선 박스 방지, 감사 #12).

1. [ ] AdSense 콘솔에서 광고 단위 6개 생성 → 슬롯 ID 확보.
2. [ ] `web/assets/js/adsConfig.js` 의 `AD_SLOT` 6키를 실값으로 치환
       (`landing_bottom`·`company_mid`·`company_bottom`·`combo_mid`·`combo_bottom`·`result_bottom`).
       ⚠ **여기 한 곳만** 고친다 — client id·슬롯 id 산재는 FR-70 위반이고 테스트가 잡는다.
3. [ ] `web/assets` 는 **라이브 도크루트**다(저장 즉시 프로덕션). 워크트리에서 고쳐 PR·CI 를 거쳐라.
4. [ ] 배포 후 확인: 회사·조합·랜딩·리포트에 `<ins class="adsbygoogle">` 가 실제로 뜨는가,
       무광고 페이지(히트맵·회사목록·정책·404)에는 **여전히 0** 인가.

## 3. 광고를 붙이지 않을 페이지 (지금 결정, 승인 후에도 유지)

| 페이지 | 광고 | 이유 |
|---|---|---|
| 히트맵 `/heatmap` · 회사목록 `/companies` | **없음** | 목록·시각화 페이지. `page_type` 미선언 = ads.js `default` |
| 커뮤니티 `/community/` | **없음(1차)** | 검수 없는 UGC 에 광고를 붙이는 것은 애드센스 정책 위험 |
| 정책 4종 · 404 | 없음 | 게이팅 표(FR-73) |
| 비교 입력 화면 | 없음 | 결정 6(입력 화면 최소화) |

커뮤니티에 광고를 붙이려면 **신고 처리 운영이 먼저** 돌아가야 한다(콘솔 큐·`ops digest`).

## 4. 승인 후에도 그대로 두는 것

- `DENY_FALLBACK='nonpersonalized'` — 'suppress' 로 바꾸면 동의 없는 사용자에게 광고가 아예 안 나간다.
- `AUTO_ADS: true` — 자동 광고는 대시보드 사이트 설정 + 로더가 함께 있어야 동작한다.
- `ads.txt` — 이미 생성·서빙 중(`render_ads_txt`, pub-id 소스는 `generator/config.adsense_client_id`).
